> 최종 갱신: 2026-09-09

## 0. 실행 원칙

| 원칙 | 내용 |
|---|---|
| **git 금지** | `git` 명령을 절대 실행하지 않는다. 파일 쓰기만 한다. 동기화는 obsidian-git이 담당 |
| **관측과 해석 분리** | 사실(수치·기준일)과 판정(임계값 적용)을 문단으로 분리한다 |
| **사전 임계값만 사용** | [[../onchain/metrics-glossary\|지표 사전]]에 정의된 판정 규칙만 적용. 사후 서술 금지 |
| **출처 필수** | 모든 수치에 기준일과 출처 URL |
| **불확실성 명시** | 확인 안 된 값은 비워두고 "미확인"으로 표기. 추정치로 채우지 않는다 |

## 1. 갱신 범위

템플릿: [[../_templates/onchain-note|onchain-note.md]]

### 1-2. 매주 (이벤트 감지 → 해당 노트만 부분 갱신)
각 코인 노트 7번 섹션의 **"트리거"** 항목에 변화가 있었는지만 확인한다.
변화가 있으면 해당 코인의 `coins/` 노트 5·6·7번 섹션을 갱신한다.
**변화가 없으면 건드리지 않는다.**

### 1-3. 분기 1회 또는 이벤트 발생 시
`coins/` 노트 1~4번 섹션 (기술 스택, 토크노믹스, 로드맵)
- 하드포크·메이저 업그레이드
- 토크노믹스 변경 (소각 구조, 인플레이션율, 언락 스케줄)
- 대형 언락 이벤트
- 지배구조 변경

## 6. 실패 처리

| 상황 | 대응 |
|---|---|
| PC가 꺼져 있어 볼트에 못 씀 | 요약 보고만 하고, 다음 실행 시 밀린 것 함께 처리 |
| 데이터 소스 접근 실패 | 해당 지표를 "미확인"으로 남기고 로그에 기록. **추정치로 채우지 않는다** |
| 유료 지표 필요 | 무료 대체 지표로 우회하거나 미확인 처리 |
