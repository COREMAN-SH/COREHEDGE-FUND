## 섹터 그룹과 집중도

| 섹터 | 코인 | 메모 |
|---|---|---|
| 가치저장 | BTC | 유일한 독립 자산군. 다른 코인과 상관성 낮음 |
| 범용 L1 | ETH | 디파이·스테이블코인·RWA 정산 레이어 |
| 고성능/병렬 L1 | SOL, SUI | SOL이 유동성·기관채택에서 한 체급 위 |
| 거래소 L1 | BNB | 거래소 리스크(규제·플랫폼)에 직결 |
| 커스터마이즈 L1 | AVAX | 기업·기관용 L1(구 서브넷)이 차별점 |
| 학술 L1 | ADA | 실사용 성장이 상대적으로 더딤 |
| AI 인프라 L1 | NEAR | Intents 거래량이 토크노믹스에 직결 |

| DEX | UNI | 수수료 스위치 가동 이후 현금흐름 연동 |

| RWA | ONDO | 토큰화 국채·주식. TEE 기반 전환 완료 |
