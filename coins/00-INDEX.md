## 노트 규칙

- 프로토콜 펀더멘탈 8섹션: 한줄정의 → 기술스택 → 토크노믹스 → 로드맵 → 시장현황 → 실무알림 → 투자관점요약 → 출처
- 온체인 상태 노트는 `onchain/` 아래, 템플릿은 `_templates/onchain-note.md`
- 모든 수치에 기준일 표기
- 갱신: 프로토콜 노트 분기 1회 또는 이벤트 발생 시 / 온체인 노트 주 1회(월요일)
