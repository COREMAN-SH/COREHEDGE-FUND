## 4. 경매 5단계

1. **발표** (경매 2~5영업일 전 11:00 ET) — 규모·CUSIP·신규/재개설 확정
2. **When-Issued 거래** — 선도 거래. 마감 직전 WI 호가 = 기대 낙찰금리. 딜러 숏 → **컨세션**(경매 전 금리 상승)
3. **입찰** — 경쟁입찰은 TAAPS. **단일금리 인정한도·총낙찰한도 = 발행액의 35%**(순매수포지션 포함). 비경쟁입찰은 TreasuryDirect로 개인 가능, **$100~$1,000만**, 전량 낙찰
4. **낙찰 — 단일가격(더치)** — 비경쟁 먼저 채우고 경쟁을 낮은 금리부터 배정. 소진 지점이 **스톱아웃 금리**, **낙찰자 전원 동일 금리**. 걸친 응찰은 안분비례
5. **결제** — 빌 2~3일 뒤(목), 쿠폰물 15일·말일 등. TGA 유입 = 시중 유동성 흡수

**마감 시각(ET)**: 빌 비경쟁 11:00 / 경쟁 11:30 · 쿠폰물 비경쟁 12:00 / **경쟁 13:00**. 결과는 마감 후 ~2분.

## 6. 입찰자 분류

- **Primary Dealer** — NY연준 지정. 전 경매 응찰 의무 = 백스톱. **비중↑ = 실수요 부족(나쁨)**
- **Direct** — TAAPS 직접 응찰 기관. 미국 국내 실수요
- **Indirect** — 딜러 경유. **외국 중앙은행·해외기관**으로 해석. 30년물 평균 ~67%
- **SOMA Add-on** — 연준 재투자분, 경매 외 별도 배정 (공표 사이즈보다 총액이 커 보이는 이유)
