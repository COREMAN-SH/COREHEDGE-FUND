# ELS 종합 매뉴얼 (2026-08-27)

> 아티팩트: https://claude.ai/code/artifact/84cf2783-61d8-46d1-8bf8-6b4ef77fdf90

## 0. 한 줄 정의
ELS = **증권사 무담보 사채 + 투자자의 딥 OTM 풋 매도**. 예금자보호 대상 아님.
상단은 쿠폰에서 잘리고, 하단은 원금 전액까지 열림.

## 1. 계보
| 상품 | 기초 | 원금 | 비고 |
|---|---|---|---|
| ELS | 지수·개별주 | 비보장 | 스텝다운 조건부 상환 |
| ELB | 지수·개별주 | 원금지급형(발행사 신용 조건부) | 대부분 채권 운용 |
| DLS/DLB | 금리·환율·원자재·신용 | 비보장/지급형 | ELS의 비주식 버전 |
| ELD | 지수 | 예금자보호 | 은행 발행 |
| ELF | — | 비보장 | ELS 편입 펀드 |

## 2. 쿠폰의 원천 (발행자금 분해, 3년물·금리3% 가정)
- 채권 운용 ~91% / 옵션매도 프리미엄 +α / 판매수수료 1~2% / 발행사 마진·헤지비용 1~3%
- 헤지 방식: 백투백(위험 이전, 얇은 마진) vs 자체 델타헤지(수익 크나 급변동 시 마진콜 위험 → 2020.3 사태)

## 3. 스텝다운 조건표 해독 (예: 3년/6개월/연 7.2%)
- 배리어 95-95-90-90-85-80, KI 50%, worst-of 3자산
- 6개월마다 **세 지수 전부** 배리어 이상 → 조기상환
- 3년간 미상환 + 기간 중 장중 한 번이라도 KI 하회 → 최악 자산 하락률 그대로 손실
- KI 미터치 시 만기에 원금 + 누적쿠폰(21.6%)

## 4. 쿠폰 결정 4변수와 그 의미
| 변수 | 쿠폰 | 투자자 판정 |
|---|---|---|
| 변동성 | ↑↑ | 조건부 (낙폭 동반 시에만 호재) |
| 무위험금리 | ↑ | **순수 이득** |
| 상관관계 낮음 | ↑ | **위험의 가격표 (나쁨)** |
| 배당수익률 | ↑ | 중립 |

→ "왜 이 쿠폰이 높은가"가 상품 비교의 핵심 질문.

## 5. 리스크 8종
① KI 시장위험 ② worst-of ③ 발행사 신용(2008 리먼 미니본드) ④ 유동성(중도상환 5~10% 수수료)
⑤ 재투자(조기상환 반복 → 갈수록 나쁜 조건) ⑥ 헤지/마진콜 ⑦ 환위험(Quanto 여부) ⑧ 불완전판매

비대칭: 최대 +21.6% vs 최대 -100%. 이길 확률 높고, 질 때 손실 5배.

## 6. 매수 시점론 (핵심)
**좋음**
- 급락 직후 바닥권 (VIX 30~50, 고점比 -30%) — 쿠폰↑ + 진입레벨↓ 동시 확보. 2020.3~5, 2022.10, 2016.2
- 고금리 + 중간 변동성 (금리발 쿠폰은 위험 증가 없는 이득)
- 박스권 횡보 예상 국면

**나쁨**
- 신고가 + 저변동성(VIX 12~14) → 최소 보상, 최대 위험 (2021 H지수)
- **하락 초입** (변동성만 오르고 낙폭 없음) ← 가장 흔한 함정
- 저금리 국면 / 강세장 확신 / 종목형 / 3년 내 자금 필요

**판단 지표 4개**: 5년 고점 대비 낙폭 / KI까지 실제 거리 / 쿠폰−국고3년 스프레드(3%p 미만이면 탈락) / 기초자산 상관

## 7. 사고 연표
- 2003 도입 → 2008 리먼 미니본드(신용위험) → 2015~16 1차 H지수 충격 → 2019 DLF 사태
- 2020.3 코로나 마진콜(자체헤지 증권사 유동성 위기)
- 2021 H지수 12,000선 은행 창구 대량 판매 → **2024 손실 4.6조원, 평균 배상비율 31.6%(대부분 20~50%)**
- 2025.2 제도개선: 은행 **거점점포**(전 점포 5~10%, 업계 200~400곳) 한정, 전담인력·분리공간, 6개 항목 적합성, "원금 전액 손실 감내 가능 고객"만 권유, 9월 판매 재개
- 2026 1Q: ELS 발행 5.5조(+14.6% YoY), ELB 7.3조, ELS 잔액 11.2조. 기초자산 KOSPI200·S&P500 중심. 조기상환률 96%, 평균수익률 연 8.3%

**반복 패턴**: 고점 지수 → 창구 베스트셀러 → 조기상환 연속 성공으로 안전 인식 고착 → 대량 발행 → 2~3년 뒤 만기 폭발.
"요즘 이게 잘 나갑니다" = 매도 신호.

## 8. 세금
- 배당소득 15.4% 원천징수, 연 2,000만원 초과 시 금융소득종합과세
- **손익통산 불가** — 손실 상품 공제 없음
- ISA 편입 시 비과세/분리과세 활용 가능

## 9. 체크리스트
1. 5년 고점 대비 -20% 이상 빠졌는가 (신고가면 무조건 패스)
2. "여기서 또 반토막" 시나리오가 그 지수 역사에 있었는가
3. 쿠폰 − 국고3년 ≥ 3%p
4. 기초자산 2개 이하 + 유사 시장
5. 발행사 신용등급
6. 3년 락업 가능한 자금인가
7. 총자산 20% 이내 + 같은 지수 중복 금지
8. 3~6개월 간격 시점 분산

## 10. 대안
