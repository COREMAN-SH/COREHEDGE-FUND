## 0. 이 문서를 쓰는 법

**목적**: 차트에 띄우는 선이 정확히 무엇을 계산한 값인지, 언제 거짓말을 하는지 한 곳에 고정한다. 지표를 늘리기 전에 각 지표가 **무엇의 함수인지**를 알아야, 겹치는 지표 세 개를 "세 개의 근거"로 착각하지 않는다.

### 지표를 분류하는 3개의 축

| 축 | 구분 | 의미 |
|---|---|---|
| **시점** | 후행 / 동행 / 선행 | 이동평균은 정의상 후행. 진짜 선행은 거의 없고, "선행"이라 불리는 것 대부분은 동행 + 빠른 평활 |
| **정규화** | 유계(bounded) / 무계(unbounded) | RSI·스토캐스틱은 0~100에 갇힘 → 절대 수준 비교 가능. MACD·OBV는 무계 → **종목 간·시기 간 절대값 비교 불가** |
| **입력** | 가격만 / 가격+거래량 / 외부 | 가격만 쓰는 지표를 아무리 많이 겹쳐도 정보량은 안 늘어난다. 독립 정보는 거래량·파생 포지셔닝에서만 온다 |

### 겹침 지도 — 이것만은 기억할 것

```
가격 평활 계열 ──── SMA · EMA · SMMA · WMA · VWMA · HMA · DEMA · TEMA
                     └─ MACD·TRIX·AO   (평활의 차 또는 변화율)
                     └─ 볼린저 중심선 (SMA) · 켈트너·슈퍼트렌드 중심 (EMA)
                     └─ ADX·ATR·RSI 내부 평활 (SMMA)

변화율 계열 ──────── RSI · 스토캐스틱 · CCI · Williams %R · ROC · RVI
                     └─ 거의 같은 것을 다르게 정규화한 것
                     └─ %R ≡ %K − 100  (완전한 항등)
                     └─ Puell Multiple ≈ 가격/가격의 365MA  (온체인 외피를 쓴 장기 ROC)

변동폭 계열 ──────── ATR · 표준편차 · 볼린저폭 · 켈트너폭 · HV · DVOL
                     └─ 슈퍼트렌드·도너찬도 결국 이 축

레짐 판정 계열 ───── ADX · 촙피니스 · 밴드폭
                     └─ 방향이 아니라 "추세인가 횡보인가"만 답한다

━━━━━━━━━━━━ 여기서부터가 진짜 독립 정보 ━━━━━━━━━━━━

거래량 ──────────── OBV → A/D Line → CMF → **CVD**   (정밀도 순)
                     프로파일 · VWAP · 거래량 오실레이터

파생 포지셔닝 ───── 펀딩 · OI · 베이시스 · 스큐 · DVOL · 롱숏비 · 테이커비
                     청산 히트맵

온체인 ──────────── MVRV ≡ 현재가/실현가격 ≡ NUPL(단조변환) · SOPR
                     거래소 준비금 · 스테이블 순증
                     └─ 채굴자(공급측): 해시리본(생존) · Puell(수익)
```

**RSI 과매수 + 스토캐스틱 과매수 + CCI 과매수 = 근거 3개가 아니라 근거 1개다.** 축을 넘어서 조합할 것.
**MVRV 과열 + NUPL 도취 = 근거 2개가 아니다.** NUPL = 1 − 1/MVRV, 완전한 함수 관계다.

# A. 추세 (Trend)

## A-1. SMA — 단순이동평균 (Simple Moving Average)

**정의** — 최근 n개 가격의 산술평균. 모든 지표 평활의 원형.

**계산식**

```
SMA_t(n) = (P_t + P_{t-1} + ... + P_{t-n+1}) / n
```

**파라미터** — 크립토 일봉 관행: 20 / 50 / 100 / 200. 4시간봉: 50 / 200(= 일봉 8일 / 33일). 200일선은 **기관·언론이 공통으로 인용하는 유일한 선**이라 자기실현적 성격이 있다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 > SMA200, SMA50 > SMA200 | 정배열, 추세 추종 유효 구간 |
| SMA50이 SMA200을 상향 교차 | 골든크로스 — **신호가 아니라 확인**. 평균 40~60봉 지연 |
| SMA50이 SMA200을 하향 교차 | 데드크로스 — 동일하게 후행 |
| SMA 기울기 ≈ 0 + 가격이 선을 반복 관통 | 횡보. **모든 이동평균 전략이 최악인 구간** |

**함정**
1. **드롭오프 효과(drop-off)** — SMA는 n봉 전 값이 창에서 빠질 때도 움직인다. 오늘 가격이 그대로여도 20일 전이 급등봉이었으면 SMA20이 떨어진다. **"이유 없이 선이 꺾이는" 대부분의 원인.**
2. 모든 봉에 동일 가중 → 어제 급락과 20일 전 급락을 같은 무게로 취급.
3. 골든크로스의 백테스트 성과는 대부분 **강한 추세장에서만** 나온다. 크립토 횡보 구간에서는 손실 누적.

**궁합** — 볼린저밴드(중심선이 SMA), 거래량(교차 시 거래량 동반 여부)

**심화**
- SMA는 **유한 임펄스 응답(FIR)** 필터다. 창 밖의 데이터는 완전히 잊는다 → 드롭오프의 수학적 원인.
- 지연 = 대략 `(n-1)/2` 봉. SMA200의 무게중심은 **약 100봉 전**에 있다. "200일선이 지지"라는 말은 "100일 전 평균 가격대가 지지"라는 뜻에 가깝다.
- 주파수 응답에 사이드로브(side-lobe)가 있어 특정 주기의 노이즈를 완전히 못 거른다. 이걸 개선한 것이 아래 가중 계열.
- **크립토 특수성**: 24시간·무휴장 시장이라 "일봉"의 시작점이 거래소마다 다르다(UTC 0시 vs KST 9시). 200일선 값이 소스마다 1~2% 갈리는 흔한 원인.

## A-2. EMA — 지수이동평균 (Exponential Moving Average)

**정의** — 최근 가격에 지수적으로 큰 가중을 주는 평활. 창이 없고 과거 전체를 감쇠시키며 기억한다.

**계산식**

```
α = 2 / (n + 1)
EMA_t = α·P_t + (1 - α)·EMA_{t-1}

시드: EMA_n = SMA_n (관행)
```

**파라미터** — 9 / 12 / 21 / 26 / 50 / 200. 12·26은 MACD 기본값에서 유래해 관행이 됐을 뿐 근거는 없다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| EMA9 > EMA21 > EMA50 | 단기 정배열 |
| 가격이 EMA21을 되돌림 후 반등 | 추세 내 눌림목 후보 (**단독으로는 신호 아님**) |
| EMA 간격 급확대 | 추세 가속 = 동시에 되돌림 위험 확대 |
| EMA 3개가 얽힘(리본 수축) | 방향 소멸, 진입 금지 |

**함정**
1. **α는 절대 0이 되지 않는다** — 1년 전 가격도 미세하게 남아 있다. "EMA200은 200봉만 본다"는 오해.
2. 시드값 선택(SMA 시드 vs 첫 종가 시드)에 따라 초반 수백 봉이 다르다. **거래소·차트툴 간 EMA 값 불일치의 주원인.**
3. 빠른 대신 **휩소(whipsaw)가 SMA보다 많다.** 속도와 오신호는 교환 관계이며 공짜 점심은 없다.

**궁합** — MACD(EMA로 구성), 켈트너채널(중심선이 EMA), ATR(변동성으로 휩소 필터)

**심화**
- EMA는 **무한 임펄스 응답(IIR)** 1차 저역통과 필터. 드롭오프가 없는 대신 과거를 영원히 끌고 간다.
- 지연 ≈ `(n-1)/2` 봉으로 SMA와 이론적으로 같다. **"EMA가 빠르다"는 지연이 짧아서가 아니라 최근 값 반응이 크기 때문**이다. 이 구분을 놓치면 EMA를 과신하게 된다.
- α = 2/(n+1)은 EMA의 **무게중심을 SMA(n)과 일치**시키려는 선택이다. 뒤의 SMMA는 α = 1/n을 쓰므로 같은 n이어도 훨씬 느리다 — 두 지표를 비교할 때 반드시 알아야 하는 지점.

## A-3. SMMA (RMA, Wilder's MA) — 평활이동평균 ⭐

**정의** — J. Welles Wilder Jr.가 1978년 *New Concepts in Technical Trading Systems*에서 도입한 평활. **EMA와 형태는 같고 감쇠계수만 다르다.** TradingView에서는 `RMA`, 일부 플랫폼에서는 `Wilder's Smoothing` 또는 `Modified MA`로 표기된다.

**계산식**

```
SMMA_t = ( SMMA_{t-1} × (n-1) + P_t ) / n

동치 표현:  α = 1/n  →  SMMA_t = α·P_t + (1-α)·SMMA_{t-1}

시드: SMMA_n = SMA_n
```

**⭐ 핵심 등가 관계**

```
SMMA(n)  ≡  EMA(2n - 1)

SMMA(14) = EMA(27)
SMMA(21) = EMA(41)
SMMA(50) = EMA(99)
```

**같은 숫자를 넣으면 SMMA가 EMA보다 약 2배 느리다.** SMMA(21)을 EMA(21)의 대체재로 쓰면 완전히 다른 지표를 쓰는 것이다.

**파라미터** — Wilder 원본은 전부 14. 크립토 실사용은 21 / 50 / 100 / 200(각각 EMA 41 / 99 / 199 / 399에 해당).

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격이 SMMA 위 + SMMA 기울기 상승 | 추세 유효. **되돌림이 이 선에서 멈추는지**가 관전 포인트 |
| 가격이 SMMA를 관통했으나 기울기 유지 | 아직 추세 훼손 아님 — SMMA의 최대 장점(잔노이즈 무시) |
| SMMA 기울기 반전 | 추세 전환 확인 (매우 늦음, 대신 오신호 적음) |
| SMMA 다중선 정배열 유지 중 눌림 | 크립토 스윙에서 가장 많이 쓰는 진입 틀 |

**함정**
1. **가장 흔한 실수 — EMA와 같은 기간으로 놓고 비교하는 것.** 위 등가식을 모르면 "SMMA가 왜 이렇게 둔하지?"에서 멈춘다.
2. 느린 만큼 **전환점에서 손실이 크다.** 오신호 감소는 공짜가 아니라 지연으로 지불한다.
3. 플랫폼마다 이름이 달라(SMMA / RMA / Wilder's) 같은 지표를 두 개 띄우는 사고가 잦다.

**궁합** — RSI·ATR·ADX는 **내부적으로 전부 SMMA를 쓴다.** SMMA를 이해하면 저 셋의 값이 왜 툴마다 다른지도 같이 풀린다. 빠른 EMA(9~21)와 함께 띄워 "빠른 선 = 신호, 느린 SMMA = 추세 필터" 구조로 쓰는 것이 정석.

**심화**
- Wilder가 α = 1/n을 택한 이유는 이론적 최적성이 아니라 **1978년 당시 손계산 편의**다. `(이전값 × 13 + 오늘값) / 14`는 계산기로 가능하다. 지금 우리가 쓰는 RSI·ATR·ADX의 기본 감쇠가 40년 전 계산 편의의 잔재라는 점은 기억해둘 만하다.
- 이 때문에 **"Wilder 지표군은 전부 같은 관성을 공유"**한다. RSI(14)·ATR(14)·ADX(14)가 동시에 신호를 주는 것은 독립적 확인이 아니라 **같은 필터가 같은 시점에 반응한 것**이다.
- TradingView `ta.rma()`가 정확히 이 식이며, Pine Script의 `ta.rsi`·`ta.atr` 내부도 `rma`를 호출한다. 반면 일부 거래소 내장 차트는 RSI 평활에 EMA를 쓴다 — **같은 코인 RSI(14)가 거래소마다 3~5 차이 나는 표준 원인.**
- 크립토는 무휴장이라 갭이 거의 없어 SMMA의 "갭 무시" 장점이 주식보다 덜 부각된다. 대신 **주말 저유동성 구간의 꼬리 노이즈를 잘 걸러내는** 효과가 실질적으로 크다.

## A-4. WMA · VWMA · HMA — 가중 계열

**정의** — 가중치를 다르게 배분한 이동평균 3종. SMA/EMA/SMMA로 안 되는 지점을 각각 다른 방식으로 공격한다.

**계산식**

```
WMA (선형가중)
  WMA_t(n) = Σ[ (n - i) × P_{t-i} ] / Σ(n - i),  i = 0..n-1
  분모 = n(n+1)/2

VWMA (거래량가중)
  VWMA_t(n) = Σ(P_i × V_i) / Σ(V_i),  최근 n봉

HMA (헐 이동평균, Alan Hull 2005)
  raw = 2 × WMA(n/2) − WMA(n)
  HMA = WMA( raw, √n )
```

**파라미터** — WMA 20~50, VWMA 20, HMA 9~55(√n이 정수에 가까운 9·16·25·49 선호)

**판정 규칙**

| 지표 | 언제 쓰나 |
|---|---|
| **WMA** | SMA의 드롭오프를 없애고 싶을 때. 단독 사용보다 HMA의 부품으로 더 많이 쓰임 |
| **VWMA** | **가격과 SMA를 같이 띄웠을 때 VWMA가 SMA 위** = 상승이 거래량을 동반. 아래면 거래량 없는 상승(허수) |
| **HMA** | 지연을 극단적으로 줄인 추세선. 기울기 반전 자체를 신호로 씀 |

**함정**
1. **HMA는 오버슈팅한다.** 지연을 줄인 대가로 실제 가격을 넘어서 튄다 — 지지/저항선으로 쓰면 안 된다. **기울기 판독용 전용.**
2. VWMA는 **거래소 단일 거래량**에 의존한다. 크립토는 거래량이 거래소마다 다르고 워시 트레이딩 오염이 있어, 소형 코인에서는 신뢰도가 급락한다.
3. HMA는 √n을 반올림하므로 플랫폼마다 값이 미세하게 다르다.

**궁합** — VWMA ↔ SMA 쌍(거래량 확인), HMA ↔ ADX(기울기 신호를 추세강도로 필터)

**심화**
- HMA의 `2×WMA(n/2) − WMA(n)`는 **지연 제거의 표준 트릭**이다. 짧은 평균에서 긴 평균을 빼면 지연이 상쇄되지만 노이즈가 증폭되므로, 다시 √n으로 평활해 균형을 맞춘다. DEMA·TEMA·ZLEMA도 같은 계열의 변형이다.
- VWMA는 개념적으로 **롤링 VWAP**에 가깝다. 차이는 VWAP이 세션 시작점을 앵커로 누적하는 반면 VWMA는 고정 창을 굴린다는 것 — 크립토처럼 세션 경계가 모호한 시장에서는 VWMA가 오히려 자연스럽다.

## A-5. MACD — 이동평균 수렴·확산

**정의** — Gerald Appel(1979). 두 EMA의 차이로 **추세의 변화 속도**를 본다. 추세 지표이면서 모멘텀 지표인 경계 지표.

**계산식**

```
MACD선   = EMA(12) − EMA(26)
시그널선 = EMA(MACD선, 9)
히스토그램 = MACD선 − 시그널선
```

**파라미터** — 12/26/9는 1970년대 주식 6일 거래주 기준(2주/1개월/1.5주)에서 왔다. **24시간 시장인 크립토에 이 숫자가 맞을 이유는 없다.** 크립토 4시간봉에서는 그대로 쓰고, 일봉에서는 19/39/9 등 확대 변형을 쓰는 데스크도 있다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| MACD > 시그널 (히스토 > 0) | 단기 모멘텀 우위 |
| 0선 상향 돌파 | EMA12 > EMA26 = 중기 추세 전환 확인 |
| **히스토그램 축소** | 교차보다 **빠른 경고**. 방향은 유지되나 힘이 빠짐 |
| **가격 신고가 + MACD 저점 절하 (하락 다이버전스)** | 되돌림 경고. 강한 추세에서는 여러 번 실패한다 |

**함정**
1. **무계 지표다.** BTC $120,000의 MACD 값과 $80,000의 MACD 값은 비교 불가. 시기 비교는 반드시 **비율(%) 정규화**하거나 히스토그램 형태로만.
2. 횡보에서 0선을 반복 관통하며 오신호를 양산한다. **ADX < 20이면 MACD 신호를 무시하는 게 낫다.**
3. 다이버전스는 강세장에서 3~5회 연속 실패하는 것이 정상이다. 다이버전스 단독 진입은 크립토에서 가장 비싼 습관 중 하나.

**궁합** — ADX(횡보 필터), RSI(모멘텀 교차 확인), 거래량

**심화**
- MACD는 **밴드패스 필터**다. EMA12(고주파 통과)에서 EMA26(더 낮은 주파수 통과)을 빼면 그 사이 대역만 남는다. "추세의 2차 미분에 가까운 값"이라는 직관이 여기서 나온다.
- 히스토그램은 MACD의 다시 한 번 미분에 해당해, **가격 → MACD → 히스토그램** 순으로 선행한다. 대신 노이즈도 그 순서로 커진다.
- 크립토에서의 실질 활용은 신호 발생보다 **레짐 판별**이다. 히스토그램의 절대 크기가 지속적으로 확대되는 구간 = 추세장, 0 근처에서 진동 = 박스권.

## A-6. ADX / DMI — 추세 강도와 방향

**정의** — Wilder(1978). **방향은 DMI(+DI/−DI), 강도는 ADX**가 담당한다. ADX는 방향을 말하지 않는다 — 상승이든 하락이든 강하면 올라간다.

**계산식**

```
TR  = max(H−L, |H − C_prev|, |L − C_prev|)

+DM = (H − H_prev > L_prev − L  그리고 > 0) ? H − H_prev : 0
−DM = (L_prev − L > H − H_prev  그리고 > 0) ? L_prev − L : 0

+DI = 100 × SMMA(+DM, 14) / SMMA(TR, 14)
−DI = 100 × SMMA(−DM, 14) / SMMA(TR, 14)

DX  = 100 × |+DI − (−DI)| / (+DI + (−DI))
ADX = SMMA(DX, 14)
```

**파라미터** — 14 고정이 사실상 표준. **내부 평활이 전부 SMMA(A-3)이다.**

**판정 규칙**

| ADX | 판정 |
|---|---|
| < 20 | 추세 없음. **추세추종 지표(MACD·이동평균 교차) 전면 무효 구간** |
| 20 ~ 25 | 전환 대기 |
| 25 ~ 40 | 유효한 추세. 추세추종 전략 정상 작동 |
| > 40 | 강한 추세. 다만 **역추세 진입은 여전히 금물**, 되돌림 폭만 커짐 |
| > 50~60 후 하락 반전 | 추세 소진 경고 |

| DMI | 판정 |
|---|---|
| +DI > −DI | 상승 방향 우위 |
| DI 교차 + ADX 25 상향 돌파 | 가장 신뢰도 높은 조합 신호 |

**함정**
1. **ADX 상승 = 상승장이 아니다.** 폭락 중에도 ADX는 오른다. 이 오해가 가장 흔하다.
2. ADX는 **평활을 두 번**(TR/DM 한 번, DX 한 번) 거쳐 매우 느리다. ADX가 25를 넘었을 때 추세는 이미 상당 부분 진행돼 있다.
3. ADX가 25를 넘은 상태에서의 진입은 "확인된 추세에 늦게 타는 것"이며, 손절폭 설계를 ATR로 별도 관리하지 않으면 리스크·리워드가 나쁘다.

**궁합** — **모든 추세추종 지표의 스위치**로 쓰는 것이 정석. ADX < 20이면 MACD·이동평균 교차·돌파 전략 전부 끄고, 대신 RSI·볼린저 역추세 전략을 켠다.

**심화**
- ADX의 진짜 가치는 진입 신호가 아니라 **어떤 전략을 켤지 결정하는 메타 지표**라는 데 있다. 이 관점으로 쓰면 후행성이 결점이 아니라 무해해진다.
- DX 계산의 분모가 (+DI) + (−DI)이므로 **ADX는 방향 정보를 구조적으로 버린다** — 절댓값을 취하는 순간 부호가 사라진다.
- 크립토 24시간 시장에서 TR의 첫 항 `H−L`이 지배적이다(갭이 거의 없으므로). 주식과 달리 `|H − C_prev|` 항이 거의 발동하지 않는다는 점에서, 크립토 ADX는 실질적으로 **일중 변동폭 기반 지표**에 가깝다.
- **⭐ 프로젝트 연결(2026-09-08)**: `automation/btc-desk-build.py` §5.5가 ADX(14)와 촙피니스(C-7)를 4H·1D 두 시간축에서 계산해 **"지금 어떤 전략을 켜야 하는가"**를 데스크 맨 앞에서 판정한다. ADX(느림·확인)와 CHOP(빠름·경고)이 어긋나는 조합 자체를 국면으로 삼는다 — 아래 C-7 심화 참조.

## A-7. 이치모쿠 킨코 효 — 일목균형표

**정의** — 一目均衡表. 호소다 고이치(필명 一目山人)가 1930년대에 완성한 **단일 화면 완결형 시스템**. 추세·지지저항·모멘텀·미래 투영을 5개 선 하나로 담는다. 다른 지표를 얹지 않는 것이 원설계다.

**계산식**

```
전환선 (Tenkan-sen)   = (9기간 최고 + 9기간 최저) / 2
기준선 (Kijun-sen)    = (26기간 최고 + 26기간 최저) / 2

선행스팬A (Senkou A)  = (전환선 + 기준선) / 2      → 26기간 앞으로 이동
선행스팬B (Senkou B)  = (52기간 최고 + 52기간 최저)/2 → 26기간 앞으로 이동
구름 (Kumo)           = 선행스팬A와 B 사이 영역

후행스팬 (Chikou)     = 종가                      → 26기간 뒤로 이동
```

**파라미터** — 9 / 26 / 52. **26은 1930년대 일본 주식시장의 한 달 거래일(토요일 반장 포함)**이다. 크립토는 주 7일이므로 이 숫자의 원래 의미가 사라진다 — 7/22/44 또는 10/30/60으로 조정하는 데스크가 많다. 다만 원본 숫자의 자기실현성 때문에 그대로 쓰는 쪽도 많다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격이 구름 **위** | 강세. 구름 상단이 지지 |
| 가격이 구름 **안** | 균형 = 방향 없음. **진입 금지 구간** |
| 가격이 구름 **아래** | 약세. 구름 하단이 저항 |
| 전환선 > 기준선 (골든크로스) | 단기 모멘텀 상방 |
| **구름 두께** | 두꺼우면 돌파 어려움, 얇으면 쉽게 관통 |
| **구름 색 전환(A/B 교차)** | 26기간 뒤의 추세 전환 예고 — 유일하게 미래를 그리는 부분 |
| 후행스팬이 26봉 전 가격 위 | 추세 확인. **가장 늦지만 가장 강한 확인** |
| **5요소 전부 정렬** | 산야쿠 코텐(三役好転) — 원설계상의 진짜 신호 |

**함정**
1. **구름만 보고 나머지 4선을 무시하는 것**이 압도적으로 흔한 오용이다. 이치모쿠는 5요소가 모여야 하나의 판정이며, 구름은 그중 하나일 뿐이다.
2. **선행스팬은 미래를 예측하지 않는다.** 과거 데이터를 앞으로 옮겨 그린 것뿐이다. "구름이 미래를 보여준다"는 표현은 은유이지 예측이 아니다.
3. 26봉 이동 때문에 **최근 26봉 구간의 구름은 이미 확정된 값**이다. 그 구간에서 구름이 바뀌길 기대할 수 없다.
4. 선이 5개라 화면이 복잡하고, 사후적으로는 무엇이든 설명 가능해 보인다. **진입 규칙을 미리 못 박지 않으면 사후 해석 도구가 된다.**

**궁합** — 그 자체로 완결형이라 **다른 추세 지표를 얹으면 중복**이다. 보완이 필요하면 다른 축에서 — 거래량(D), 파생 포지셔닝(F).

**심화**
- 전환선·기준선은 EMA가 아니라 **중간값(midpoint)** 이다. 평균이 아니라 범위의 중심이므로, 이상치 한 개가 26봉 내내 선을 붙들어 놓는다 — 이동평균과 근본적으로 다른 거동.
- 후행스팬의 26봉 지연은 "지금 가격이 한 달 전 참여자들에게 이익인가"를 묻는다. **개념적으로 앵커드 VWAP(D-2)과 같은 질문**을 다른 방식으로 던지는 것이다.
- 크립토 24시간 시장에서 26일은 달력 26일이다. 원본이 겨냥한 "한 달의 거래 리듬"과 대응이 깨지므로, 이치모쿠를 크립토에 그대로 쓰는 것은 **숫자만 옮기고 의미는 옮기지 않은 것**임을 알고 써야 한다.

## A-8. 파라볼릭 SAR

**정의** — Wilder(1978). Stop And Reverse. **추세 추종이 아니라 청산·역전 지점을 계산하는 도구**다. 점이 가격 반대편에 찍히며, 시간이 갈수록 가속해 가격에 다가온다.

**계산식**

```
SAR_t = SAR_{t-1} + AF × (EP - SAR_{t-1})

EP (Extreme Point) = 현 추세 중 최고가(상승) 또는 최저가(하락)
AF (Acceleration Factor) = 0.02 시작, EP 갱신마다 +0.02, 최대 0.20

상승 추세: SAR은 직전 2봉의 저가보다 높을 수 없다
하락 추세: SAR은 직전 2봉의 고가보다 낮을 수 없다
가격이 SAR을 관통 → 추세 반전, SAR = 직전 EP, AF 초기화
```

**파라미터** — AF 시작 0.02 / 증분 0.02 / 최대 0.20. 크립토 변동성에서는 0.01/0.01/0.10으로 느리게 잡는 편이 휩소가 적다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 점이 가격 아래 | 상승 추세. 그 점이 추적 손절 위치 |
| 점이 가격 위 | 하락 추세 |
| **점이 가격에 급속히 근접** | AF가 커진 상태 = 추세가 오래됨. 반전 임박 신호 |
| 반전 직후 | **횡보라면 곧 다시 반전.** 연속 반전은 무시하라는 신호 |

**함정**
1. **횡보장에서 최악이다.** SAR은 항상 포지션을 잡고 있다고 가정하므로(Stop And Reverse), 박스권에서 매 봉마다 손실을 내며 뒤집힌다.
2. **진입 신호로 쓰면 안 된다.** Wilder는 이것을 이미 잡은 포지션의 **청산 도구**로 설계했다. 진입은 ADX(A-6)로 추세를 확인한 뒤 하라는 것이 원저자의 조합이다.
3. AF 가속 구조 때문에 **강한 추세에서 너무 일찍 털린다.** 크립토의 큰 되돌림에서 특히 심하다.

**궁합** — **ADX(A-6)와 짝이 원설계**다. ADX > 25일 때만 SAR 신호를 채택하고, 그 아래에서는 SAR을 끈다. ATR(C-1)과 함께 어느 쪽 손절이 넓은지 비교해 쓰기도 한다.

**심화**
- SAR은 **시간에 대한 함수**다. 추세가 오래갈수록 AF가 커져 손절이 가격에 붙는다 — "오래된 추세일수록 방어를 좁힌다"는 명시적 철학이 식에 박혀 있다. 다른 어떤 지표에도 시간 자체가 이렇게 직접 들어가지 않는다.
- 직전 2봉 저가 제한은 **갭에 대한 방어**다. 갭이 없는 크립토에서는 이 제한이 거의 발동하지 않아, 주식보다 SAR이 더 공격적으로 붙는다.

## A-9. 슈퍼트렌드

**정의** — ATR 기반 추적 밴드. 하나의 선이 가격 아래(상승)와 위(하락)를 오가며 추세 방향과 손절 위치를 동시에 준다. **크립토 커뮤니티에서 가장 널리 쓰이는 현대 추세 지표.**

**계산식**

```
기본밴드 상 = (H+L)/2 + m × ATR(p)
기본밴드 하 = (H+L)/2 - m × ATR(p)

최종밴드 상_t = min(기본상_t, 최종상_{t-1})   단, C_{t-1} > 최종상_{t-1}이면 기본상_t
최종밴드 하_t = max(기본하_t, 최종하_{t-1})   단, C_{t-1} < 최종하_{t-1}이면 기본하_t

추세 = 종가가 최종상단을 상향 돌파하면 +1, 최종하단을 하향 돌파하면 -1
슈퍼트렌드 = 추세 +1이면 최종하단, -1이면 최종상단
```

**파라미터** — ATR 10, 배수 3.0이 표준. 크립토 일봉은 10/3 또는 7/2.5, 4시간봉은 10/2.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 선이 가격 아래(녹색) | 상승 추세. 그 선이 손절 |
| 선이 가격 위(적색) | 하락 추세 |
| 색 전환 | 추세 전환 신호 — **밴드 폭만큼 늦다** |
| 색 전환이 잦음 | 횡보. **배수를 키우거나 지표를 꺼야 함** |

**함정**
1. **밴드 폭(m×ATR)만큼 항상 늦다.** 3×ATR이면 이미 3 ATR 움직인 뒤에 신호가 난다 — 이 지연은 파라미터의 결과이지 버그가 아니다.
2. 배수를 줄이면 빨라지지만 휩소가 급증한다. **m을 낮춰서 성과가 좋아진 백테스트는 거의 예외 없이 과적합**이다.
3. 잠금(locking) 로직 때문에 **최종밴드가 이전 값을 기억한다.** 시작 시점이 다르면 값이 달라져, 다른 차트툴과 비교 시 어긋난다.

**궁합** — ADX(추세장에서만 사용), 볼린저 스퀴즈(C-2/C-3, 발사 방향 확인용). **다른 ATR 기반 지표(켈트너)와는 중복**이다.

**심화**
- 슈퍼트렌드는 사실상 **켈트너채널(C-3)에 잠금 로직과 방향 상태를 추가한 것**이다. 새로운 정보를 만들어내지 않으며, 켈트너를 "결정을 내려주는 형태"로 포장한 것에 가깝다.
- 그럼에도 유용한 이유는 **재량을 없애기 때문**이다. 선 하나가 방향과 손절을 동시에 지정하므로 감정 개입 여지가 줄어든다. 정보량이 아니라 규율 도구로서의 가치다.
- 크립토에서 널리 쓰이는 만큼 **자기실현성**이 붙는다. 10/3 슈퍼트렌드 전환 가격 근처에서 실제 매물이 나오는 것은 그 때문이다.

## A-10. DEMA · TEMA

**정의** — Patrick Mulloy(1994). EMA의 지연을 대수적으로 제거한 이중·삼중 지수이동평균. HMA(A-4)와 같은 목적, 다른 방법.

**계산식**

```
EMA1 = EMA(P, n)
EMA2 = EMA(EMA1, n)
EMA3 = EMA(EMA2, n)

DEMA = 2×EMA1 - EMA2
TEMA = 3×EMA1 - 3×EMA2 + EMA3
```

**파라미터** — 20 / 50. 같은 n에서 **DEMA는 EMA(n)보다 빠르고 TEMA는 더 빠르다.** 체감 반응 속도는 대략 TEMA(n) ≈ EMA(n/2) 수준.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 > TEMA + 기울기 상승 | 추세 확인이 EMA보다 빠름 |
| TEMA가 DEMA를 상향 교차 | 단기 모멘텀 전환 |
| **가격 급변 직후 TEMA 오버슈팅** | 정상 거동. 되돌림으로 해석하면 안 됨 |
| 횡보에서 TEMA 진동 | 노이즈 증폭 상태. 사용 중단 |

**함정**
1. **지연을 줄인 만큼 노이즈를 증폭한다.** 이것은 교환이 아니라 항등식이다 — `2×EMA1 − EMA2`는 오차항도 2배로 키운다.
2. TEMA는 오버슈팅한다. **HMA와 마찬가지로 지지·저항선으로 쓰면 안 되고 기울기 판독용**이다.
3. 3중 EMA라 시드 의존성이 EMA보다 3배 길다. 초반 수백 봉은 신뢰하지 말 것.

**궁합** — ATR(C-1, 노이즈 증폭분을 손절폭으로 흡수), ADX(A-6). **SMA·EMA·SMMA·HMA와는 전부 중복**이다 — 가격 평활 계열에서 하나만 고르라.

**심화**
- `2×EMA1 − EMA2`는 **오차 보정의 표준 형태**다. EMA1의 지연을 (EMA1 − EMA2)로 추정해 되돌려주는 것으로, HMA의 `2×WMA(n/2) − WMA(n)`과 정확히 같은 아이디어다.
- TEMA의 `3E1 − 3E2 + E3` 계수 (3, −3, 1)은 **이항계수**다. 4중·5중으로 확장하면 (4,−6,4,−1)이 되며, 차수를 올릴수록 지연은 줄고 노이즈는 지수적으로 커진다. 3중이 실용 상한인 이유.

## A-11. 선형회귀채널

**정의** — 구간의 종가에 **최소자승 직선**을 적합시키고, 잔차 표준편차의 배수로 채널을 그린다. 추세선을 손으로 긋는 대신 계산으로 확정하는 방법.

**계산식**

```
최근 n봉 (x = 0..n-1, y = 종가)에 대해
  기울기 b = ( n·Σxy - Σx·Σy ) / ( n·Σx² - (Σx)² )
  절편   a = ( Σy - b·Σx ) / n
  회귀선 ŷ_x = a + b·x

표준오차 SE = √( Σ(y - ŷ)² / n )
채널 상단 = ŷ + k·SE      채널 하단 = ŷ - k·SE

기울기 b = 봉당 평균 가격 변화 → 추세의 속도
```

**파라미터** — n = 50 / 100 / 200, k = 2. **n이 곧 "어느 추세를 보는가"**이며, 이 지표의 유일한 재량 지점이다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 기울기 b > 0, 가격이 채널 안 | 정상 상승 추세 진행 |
| 가격이 채널 하단 터치 | 추세 내 눌림 후보 |
| **가격이 채널 밖 이탈** | 추세 가속 또는 붕괴 — 어느 쪽인지는 방향으로 판정 |
| **기울기 b의 부호 전환** | 추세 전환. 이동평균 교차보다 명확 |
| SE 확대 | 추세가 흐트러지는 중(적합도 하락) |

**함정**
1. **구간 n을 바꾸면 기울기 부호까지 바뀐다.** 피보나치와 같은 자의성 문제이며, n을 먼저 고정하지 않으면 원하는 결론을 만들 수 있다.
2. 회귀선은 **구간 전체를 알아야 그려진다.** 과거 구간의 채널은 그때 실제로 보였던 채널이 아니다 — 백테스트에서 미래참조(look-ahead)가 끼기 쉬운 대표적 지표.
3. 선형 가정이다. **로그 스케일로 움직이는 크립토 장기 추세에는 종가 대신 log(종가)로 적합하는 것이 맞다.**

**궁합** — ADX(A-6, 기울기의 유의성 확인), ATR(C-1), 프로파일(D-3, 채널 경계와 매물대 겹침 확인)

**심화**
- 기울기 b는 **선형 추세의 속도**이고, SE는 **그 추세를 얼마나 잘 따르는가**다. 두 값을 나눈 `b / SE`가 사실상 t-통계량이며, **추세의 통계적 유의성**을 재는 유일한 실용 지표다. ADX가 하는 일을 회귀 언어로 하는 셈.
- 크립토 장기 분석에서는 log 회귀가 표준이다. **"로그 회귀 밴드"**로 알려진 BTC 장기 밸류에이션 모델이 이 지표의 log·전기간 버전이다.

# B. 모멘텀 (Momentum)

## B-1. RSI — 상대강도지수

**정의** — Wilder(1978). 최근 n봉의 **상승폭 평균 대비 하락폭 평균** 비율을 0~100으로 정규화.

**계산식**

```
U_t = max(C_t − C_{t-1}, 0)      (상승폭)
D_t = max(C_{t-1} − C_t, 0)      (하락폭)

AvgU = SMMA(U, 14)               ← Wilder 평활
AvgD = SMMA(D, 14)

RS  = AvgU / AvgD
RSI = 100 − 100 / (1 + RS)   =   100 × AvgU / (AvgU + AvgD)
```

**파라미터** — 14(Wilder 원본). 단기 7~9, 장기 21~25. **크립토 일봉에서는 14가 과민해 21을 쓰는 데스크가 많다.**

**판정 규칙**

| RSI | 통념 | 실제로 써야 할 방식 |
|---|---|---|
| > 70 | 과매수 | **강세장에서는 40~90 대역에서 논다.** 70은 매도 신호가 아니라 "강한 추세" 신호 |
| < 30 | 과매도 | **약세장에서는 10~60 대역.** 30 터치는 지지가 아님 |
| 50 | 중립 | **가장 실용적인 선.** 50 위 유지 = 강세 레짐, 아래 = 약세 레짐 |
| 다이버전스 | 반전 | 추세 중 다수 실패. **레인지 장에서만 유효** |

**⭐ 실전 프레임 — 대역 이동(range shift)**
```
강세 레짐:  RSI 저점이 40~50에서 지지  → 눌림목 매수 구간
약세 레짐:  RSI 고점이 50~60에서 저항  → 반등 매도 구간
레짐 전환:  기존 대역을 이탈해 반대 대역에 안착하는 순간
```
70/30보다 **이 대역 이동이 훨씬 실전적**이다.

**함정**
1. **"70이면 판다"가 RSI를 가장 크게 오용하는 방식.** 2026년 8월 ZEC가 RSI 과매수 상태로 60% 더 갔다(`coins_ZEC-zcash.md` 참조).
2. 평활 방식 차이(SMMA vs EMA vs SMA)로 **거래소마다 RSI 값이 3~5 다르다.** 알림을 걸 때 어느 소스 기준인지 반드시 고정할 것.
3. RSI(14)는 14봉만 보는 게 아니다. SMMA 특성상 과거 전체가 감쇠하며 남아 있다.

**궁합** — ADX(추세장/레인지장 분기), 볼린저(밴드 터치 + RSI 대역 확인), 다이버전스는 거래량과 함께만

**심화**
- RSI = `100 × AvgU / (AvgU + AvgD)` 형태로 보면 **"전체 움직임 중 상승이 차지하는 비중"**이라는 본질이 드러난다. 이 형태가 원식보다 직관적이다.
- RSI는 가격 변화의 **절댓값 비율**이므로, 큰 하락 한 번과 작은 하락 여러 번을 구분하지 못한다.
- **커틀러 RSI(Cutler's RSI)** 는 SMMA 대신 SMA를 쓰는 변형으로, 시드 의존성이 없어 재현성이 좋다. 백테스트 재현이 중요하면 이쪽.
- 크립토 24시간 시장에서 RSI(14) 일봉은 실질 2주를 본다. 주식(14 거래일 ≈ 3주 달력)과 **체감 기간이 다르다** — 주식 감각으로 크립토 RSI를 읽으면 계속 과민하게 느껴지는 이유.

## B-2. 스토캐스틱 · 스토캐스틱 RSI

**정의** — George Lane(1950s). **현재 종가가 최근 n봉 고저 범위 중 어디에 위치하는가**를 백분율로. RSI가 "변화량 비율"이라면 스토캐스틱은 "위치 비율"이다.

**계산식**

```
스토캐스틱 (Fast)
  %K = 100 × (C − LL_n) / (HH_n − LL_n)
       LL_n = 최근 n봉 최저가, HH_n = 최근 n봉 최고가
  %D = SMA(%K, 3)

스토캐스틱 (Slow)  ← 실무 표준
  Slow %K = SMA(Fast %K, 3)
  Slow %D = SMA(Slow %K, 3)

스토캐스틱 RSI  ← 가격이 아니라 RSI에 스토캐스틱을 적용
  StochRSI = (RSI − min(RSI, n)) / (max(RSI, n) − min(RSI, n))
  통상 n=14, 이후 %K=3, %D=3 평활
```

**파라미터** — 14,3,3 (표준) / 5,3,3 (단기) / 21,7,7 (크립토 일봉 완화)

**판정 규칙**

| 조건 | 판정 |
|---|---|
| %K > 80 | 범위 상단 = 강세. **매도 신호 아님** |
| %K < 20 | 범위 하단 |
| %K가 %D를 20 아래에서 상향 교차 | 레인지 장에서의 매수 신호 |
| **%K가 80 위에 눌러앉음** | 추세장. 스토캐스틱 신호 전면 무효 |
| StochRSI 0 또는 1 도달 | **RSI 자체가 극단**. 매우 민감, 오신호 다수 |

**함정**
1. **추세장에서 완전히 망가진다.** 상승 추세에서는 %K가 80~100에 계속 붙어 있고 그 사이 가격은 계속 오른다.
2. **StochRSI는 RSI의 제곱된 민감도**를 갖는다. 이중 정규화라 노이즈가 크다 — 단독 진입 절대 금지.
3. HH/LL이 n봉 창 기준이므로 **드롭오프 효과**가 있다(SMA와 동일 문제). 큰 봉이 창에서 빠지면 값이 점프한다.

**궁합** — ADX < 20 확인 후에만 사용. 볼린저 하단 + 스토캐스틱 20 이하 = 레인지 반등 조합.

**심화**
- Lane 본인이 "**스토캐스틱은 다이버전스를 보는 도구지 과매수/과매도 도구가 아니다**"라고 명시했다. 널리 쓰이는 방식이 원저자 의도와 반대인 대표 사례.
- %K는 정의상 **0~100에 완전히 갇힌 유계 지표**이며 분모가 0이 될 수 있다(고가 = 저가, 무거래 봉). 저유동성 알트에서 발생하며 플랫폼별로 0 또는 이전값으로 처리가 갈린다.
- Williams %R은 스토캐스틱과 **동일한 계산에 부호와 스케일만 다르다**(%R = %K − 100). 두 개를 같이 띄우는 것은 완전한 중복.

## B-3. CCI — 상품채널지수

**정의** — Donald Lambert(1980). 대표가격이 이동평균에서 **평균편차 몇 배만큼 떨어져 있는가**. 사실상 정규화되지 않은 z-score.

**계산식**

```
TP = (H + L + C) / 3
SMA_TP = SMA(TP, n)
MD = (1/n) × Σ |TP_i − SMA_TP|      ← 평균절대편차 (표준편차 아님)

CCI = (TP − SMA_TP) / (0.015 × MD)
```

**파라미터** — 20(표준). 0.015 상수는 **CCI 값의 약 70~80%를 ±100 안에 넣기 위한 경험적 스케일링**이며 이론적 근거는 없다.

**판정 규칙**

| CCI | 판정 |
|---|---|
| > +100 | 평균 대비 강한 상방 이탈 — **추세 시작 신호로 읽는 것이 원저자 의도** |
| < −100 | 강한 하방 이탈 |
| −100 ~ +100 | 정상 범위 = 추세 없음 |
| 0선 교차 | 중기 방향 전환 |

**함정**
1. **무계 지표다.** ±100을 자주 넘고 ±300도 나온다. "과매수" 해석은 틀렸다 — Lambert는 ±100 돌파를 **진입** 신호로 설계했다.
2. 표준편차가 아니라 **평균절대편차(MD)** 를 쓴다. 이 차이로 CCI는 극단값에 상대적으로 덜 민감하다.
3. 0.015 상수 때문에 정규분포 가정이 깨지는 크립토(팻테일)에서는 ±100 밖 빈도가 통계 의도보다 훨씬 높다.

**궁합** — ADX(±100 돌파가 진짜 추세인지 확인), 거래량

**심화**
- CCI = `(x − μ) / (0.015 × MAD)`. 정규분포에서 MAD ≈ 0.7979σ이므로 `0.015 × 0.7979 ≈ 0.01197` → CCI ≈ **z-score × 83.5**. 즉 **CCI 100 ≈ 1.2 표준편차**다. 이 환산을 알면 CCI를 볼린저와 직접 비교할 수 있다.
- 이름의 "Commodity"는 원 용도(상품 사이클)에서 온 것일 뿐, 자산군 제한은 없다.

## B-4. MFI — 자금흐름지수

**정의** — **거래량을 반영한 RSI.** RSI가 가격 변화만 보는 데 반해 MFI는 각 봉의 변화에 거래대금 가중을 준다.

**계산식**

```
TP = (H + L + C) / 3
자금흐름(RMF) = TP × V

TP가 전봉보다 상승 → 양의 자금흐름(PMF)
TP가 전봉보다 하락 → 음의 자금흐름(NMF)

MFR = Σ(PMF, 14) / Σ(NMF, 14)      ← 단순 합산 (SMMA 아님)
MFI = 100 − 100 / (1 + MFR)
```

**파라미터** — 14 표준

**판정 규칙**

| MFI | 판정 |
|---|---|
| > 80 | 자금 유입 극단 |
| < 20 | 자금 유출 극단 |
| **RSI는 정상인데 MFI만 극단** | 가격 대비 **거래대금이 비정상** — 가장 유용한 사용법 |
| 가격 신고가 + MFI 저점 절하 | 거래량이 안 따라오는 상승 = RSI 다이버전스보다 신뢰도 높음 |

**함정**
1. **거래량 데이터의 질에 전적으로 의존한다.** 크립토는 거래소별 거래량 편차가 크고 워시 트레이딩 오염이 있다. 소형 알트에서는 MFI를 신뢰하지 말 것.
2. 평활에 SMMA가 아니라 **단순 합산**을 쓰므로 RSI와 반응 속도가 다르다 — 나란히 놓고 비교할 때 주의.
3. TP 기준 방향 판정이라 종가 기준 RSI와 방향이 어긋나는 봉이 생긴다.

**궁합** — RSI와 **쌍으로** 볼 때 가장 강하다(가격 모멘텀 vs 자금 모멘텀의 괴리 탐지). OBV, VWMA.

**심화**
- MFI는 거래량 지표 중 **유일하게 유계(0~100)** 라서 시기 간·종목 간 비교가 가능하다. OBV·CVD 등 누적형 거래량 지표가 못 하는 일.
- 크립토에서는 MFI를 **현물 거래소 거래량**으로 계산해야 의미가 있다. 파생 거래량으로 계산하면 실제 자금 유입이 아니라 레버리지 회전을 재게 된다 — 이 구분이 주식에는 없는 크립토 고유 함정.

## B-5. Williams %R

**정의** — Larry Williams(1973). 종가가 최근 n봉 범위의 **어디에 있는가를 음수 스케일로** 표현. 스토캐스틱 %K와 계산이 사실상 동일하다.

**계산식**

```
%R = -100 × (HH_n - C) / (HH_n - LL_n)

★ 항등식:  %R = %K - 100
   스토캐스틱 %K와 완전히 같은 값의 평행이동이다.
```

**파라미터** — 14 표준. Williams 원본은 10.

**판정 규칙**

| %R | 판정 |
|---|---|
| −20 ~ 0 | 범위 상단. **매도 신호 아님** — 강세장에서는 여기 머문다 |
| −100 ~ −80 | 범위 하단 |
| **−80을 아래에서 위로 돌파** | Williams 원설계의 매수 트리거(수준이 아니라 **돌파**) |
| −20 아래로 이탈 | 매도 트리거 |
| −50 | 중립. RSI 50과 같은 역할 |

**함정**
1. **스토캐스틱과 같이 띄우는 것은 완전한 중복이다.** 위 항등식대로 평행이동일 뿐, 두 개를 근거 두 개로 세면 안 된다.
2. 평활이 전혀 없어(%K의 Fast 버전) **노이즈가 크다.** 단독 신호는 오신호 비율이 높다.
3. 추세장에서 스토캐스틱과 똑같이 무너진다 — 상승 추세에서 −20 위에 계속 붙어 있다.

**궁합** — 스토캐스틱(B-2)과는 **쓰지 말 것**. ADX(A-6)로 레인지 확인 후 사용, 거래량(D)으로 독립 확인.

**심화**
- 이 지표의 실질 가치는 **"수준이 아니라 돌파를 보라"**는 원저자 규칙에 있다. −80 아래에 머무는 것은 약세 확인이고, −80을 위로 뚫는 것이 신호다. 대부분의 사용법이 이 구분을 놓친다.
- 유계 지표를 하나만 고른다면 RSI(B-1)가 낫다. %R은 창 밖 데이터를 완전히 버리는(FIR) 반면 RSI는 감쇠하며 기억(IIR)해 극단값에 덜 흔들린다.

## B-6. ROC · 모멘텀

**정의** — 가장 단순한 모멘텀 측정. n봉 전 대비 변화율(ROC) 또는 변화량(Momentum). 모든 모멘텀 지표의 원형.

**계산식**

```
ROC      = (C_t / C_{t-n} - 1) × 100        [%]
Momentum = C_t - C_{t-n}                     [가격 단위]

관계:  MACD·RSI·TRIX 전부 이 아이디어에 평활을 씌운 것
       Puell Multiple(G-8)도 발행 스케줄을 걷어내면 이 계열이다
```

**파라미터** — 9 / 12 / 25. 크립토 일봉은 30/90일 ROC로 **레짐 판정**에 쓰는 쪽이 실용적이다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| ROC > 0 | n봉 전보다 상승 |
| **0선 교차** | 모멘텀 방향 전환. 평활이 없어 가장 빠르지만 오신호도 최다 |
| ROC 고점 절하 + 가격 신고가 | 모멘텀 다이버전스(가장 순수한 형태) |
| ROC 절대값 급확대 | 추세 가속 = 과열 구간 진입 |

**함정**
1. **드롭오프 효과가 지표 전체를 지배한다.** n봉 전 값 하나가 기준이므로, 그 봉이 급등봉이었다면 오늘 가격이 그대로여도 ROC가 급락한다. SMA의 드롭오프보다 훨씬 심하다 — 창 전체가 아니라 **점 하나**에 의존하기 때문.
2. **Momentum(차이)은 가격 수준에 비례**해 시기 간 비교가 불가능하다. 반드시 ROC(비율)를 쓸 것.
3. ROC 극단값 자체는 과매수/과매도가 아니다. 유계가 아니므로 임계선을 고정할 수 없다.

**궁합** — 이동평균(A, 방향 확인), 거래량(D). **RSI·스토캐스틱·CCI와는 같은 축**이므로 겹치는 의미가 없다. **Puell Multiple(G-8)과도 같은 축**이라는 점을 잊지 말 것.

**심화**
- ROC는 **이산 미분**이다. 가격을 한 번 미분한 것이 모멘텀, 그것을 평활한 것이 MACD, 다시 미분한 것이 MACD 히스토그램 — 이 계층을 알면 모멘텀 지표군이 하나의 가족임이 보인다.
- 크립토에서 유용한 실제 용법은 신호가 아니라 **레짐 라벨링**이다. 90일 ROC가 +50% 이상이면 강세장, −40% 이하면 약세장 식으로 구간을 나눈 뒤 그 안에서 다른 지표의 임계를 바꾸는 방식.

## B-7. TRIX

**정의** — Jack Hutson(1980s). **삼중 지수평활한 가격의 변화율.** 평활을 세 번 해서 노이즈를 걷어낸 뒤 모멘텀을 본다.

**계산식**

```
EMA1 = EMA(C, n)
EMA2 = EMA(EMA1, n)
EMA3 = EMA(EMA2, n)

TRIX = (EMA3_t / EMA3_{t-1} - 1) × 10,000     [bp 단위]
시그널 = EMA(TRIX, 9)
```

**파라미터** — 14 / 15 / 18. 단위가 bp(1/10,000)인 것은 삼중 평활 후 변화율이 매우 작기 때문이다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| TRIX > 0 | 삼중 평활 추세가 상승 중 |
| **0선 교차** | 중기 추세 전환. 노이즈가 걷혀 오신호가 적다 |
| 시그널선 교차 | 단기 진입 트리거 |
| TRIX 다이버전스 | **평활이 강해 다이버전스 신뢰도가 RSI보다 높다** |

**함정**
1. **매우 느리다.** 삼중 EMA(15)는 실질적으로 EMA 40~45봉급 관성이다. 전환점에서 큰 폭을 내준다.
2. 무계 지표이고 단위가 bp라 **자산 간 비교 시 변동성 차이를 반드시 감안**해야 한다.
3. DEMA/TEMA(A-10)와 부품이 같지만 목적이 반대다. TEMA는 지연을 **빼서** 빠르게, TRIX는 지연을 **남겨서** 깨끗하게 만든다. 혼동하면 파라미터 감각이 어긋난다.

**궁합** — 빠른 지표(RSI·StochRSI)와 **속도 대비 쌍**으로 쓰면 좋다. TRIX는 레짐, 빠른 지표는 타이밍.

**심화**
- 삼중 평활은 **주파수 응답에서 고주파를 3제곱으로 감쇠**시킨다. 그래서 일봉 노이즈가 거의 남지 않고, 남은 진동은 실제 사이클일 가능성이 높다 — 다이버전스 신뢰도가 높은 이유가 여기 있다.
- 크립토 주말 저유동 노이즈가 TRIX에서는 사실상 사라진다. **주말 왜곡에 가장 강한 모멘텀 지표**이며, 이 점은 24시간 시장에서 실질적 장점이다.

## B-8. Awesome Oscillator

**정의** — Bill Williams. 중간가격(median price)의 **단기 SMA와 장기 SMA의 차이**를 막대로 표시. MACD를 종가 대신 중간가격으로, EMA 대신 SMA로 만든 것.

**계산식**

```
MP = (H + L) / 2                 ← 종가가 아니라 중간가격

AO = SMA(MP, 5) - SMA(MP, 34)

막대 색: 직전 막대보다 크면 녹색, 작으면 적색 (값의 부호가 아니라 변화 방향)
```

**파라미터** — 5 / 34 고정(피보나치 수). Bill Williams는 파라미터 변경을 권하지 않았다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| AO > 0 | 단기 모멘텀이 장기 위 |
| **0선 교차** | 추세 전환 |
| **트윈 픽(Twin Peaks)** | 0 아래에서 두 번째 저점이 첫 저점보다 높고 그 사이 막대가 0을 안 넘으면 매수 — AO 고유 패턴 |
| 접시(Saucer) | 0 위에서 적색 두 개 뒤 녹색 — 눌림 종료 |
| 막대 색 전환 | 값이 아니라 **변화율**의 전환 — MACD 히스토그램과 같은 의미 |

**함정**
1. **MACD와 거의 같은 것을 잰다.** 둘 다 띄우면 근거 두 개가 아니다. 차이는 입력(중간가격 vs 종가)과 평활(SMA vs EMA)뿐.
2. 막대 색이 **값의 부호가 아니라 전봉 대비 증감**이다. AO가 크게 양수인데 적색일 수 있다 — 가장 흔한 오독.
3. 5/34는 피보나치라서 선택된 것이지 최적화 결과가 아니다. 신비주의적 근거에 기대지 말 것.

**궁합** — 프랙탈·Alligator(Bill Williams 시스템 내 조합). 외부에서는 거래량(D)이나 파생(F)으로 확인.

**심화**
- 종가 대신 **중간가격**을 쓰는 것이 유일한 실질적 차별점이다. 종가는 마감 시점 한 순간이고 중간가격은 봉 전체의 중심이므로, **마감 물량 조작(closing print manipulation)에 덜 흔들린다.** 24시간 무휴장이라 "마감"이 임의인 크립토에서는 이 선택이 오히려 더 합리적이다.
- 트윈 픽은 사실상 **정형화된 다이버전스 규칙**이다. 다이버전스를 눈으로 찾는 대신 조건을 못 박았다는 점에서, 재량을 줄이는 장치로서 가치가 있다.

## B-9. RVI — 상대활력지수

**정의** — Relative Vigor Index. **종가가 시가 대비 어디서 마감했는가**를 봉 범위로 정규화. "상승장은 시가보다 높게, 하락장은 낮게 마감한다"는 관찰을 지표화한 것.

**계산식**

```
분자 = [ (C-O) + 2(C-O)_{t-1} + 2(C-O)_{t-2} + (C-O)_{t-3} ] / 6   ← 대칭가중 평활
분모 = [ (H-L) + 2(H-L)_{t-1} + 2(H-L)_{t-2} + (H-L)_{t-3} ] / 6

RVI    = SMA(분자, n) / SMA(분모, n)
시그널 = ( RVI + 2·RVI_{t-1} + 2·RVI_{t-2} + RVI_{t-3} ) / 6
```

**파라미터** — 10 표준. 가중치 (1,2,2,1)/6은 4봉 대칭 평활로, 위상 지연을 최소화하려는 선택이다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| RVI > 0 | 평균적으로 시가보다 높게 마감 = 매수 우위 |
| **RVI가 시그널 상향 교차** | 매수 트리거(주 신호) |
| RVI 다이버전스 | 가격은 신고가인데 마감 강도가 약해짐 |
| RVI ≈ 0에서 진동 | 시가·종가 관계가 무의미한 구간 |

**함정**
1. **시가에 전적으로 의존한다.** 크립토는 시가가 직전 종가와 사실상 같으므로(무휴장·무갭), `C−O`가 봉 내 순수 방향이 되어 주식과 의미가 달라진다.
2. **거래소·기준시각에 따라 시가가 달라진다.** UTC 기준 일봉과 로컬 기준 일봉의 RVI가 크게 다르다 — 이 프로젝트는 UTC로 고정할 것.
3. 분모가 0이 될 수 있다(H = L). 저유동 알트에서 발생.

**궁합** — 거래량(D-1 OBV, D-5 A/D Line)과 같이 보면 "마감 강도 + 물량 방향"이 맞는지 교차 확인이 된다. 순수 가격 모멘텀(RSI·ROC)과는 축이 다르므로 조합에 의미가 있다.

**심화**
- RVI가 재는 것은 **봉 내부의 승부**다. 대부분의 모멘텀 지표가 봉과 봉 사이(종가 대 종가)를 보는 반면, RVI는 봉 안에서 매수·매도가 어떻게 갈렸는지를 본다 — 이 점에서 A/D Line(D-5)의 가격 버전에 가깝다.
- 24시간 무휴장인 크립토에서 "시가"는 임의의 시각 스냅샷이다. RVI를 쓸 거라면 **일봉보다 4시간봉 이하**에서 쓰는 편이 원래 의미에 가깝다.

# C. 변동성 (Volatility)

## C-1. ATR — 평균진폭

**정의** — Wilder(1978). **방향이 아니라 폭만** 재는 지표. 손절·포지션 사이징의 표준 단위.

**계산식**

```
TR_t = max( H_t − L_t,
            |H_t − C_{t-1}|,
            |L_t − C_{t-1}| )

ATR = SMMA(TR, 14)              ← Wilder 평활

정규화(비교용):  ATR% = ATR / C × 100
```

**파라미터** — 14 표준. 손절용 14, 변동성 레짐 판정용 20~30.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| ATR% 상승 | 변동성 확대 — 포지션 크기를 **줄여야** 하는 구간 |
| ATR% 역사적 저점 | 변동성 압축. **방향은 모르나 큰 움직임이 임박** |
| 손절 배치 | 진입가 ± (1.5 ~ 3) × ATR. 크립토는 2~3배가 실용적 |
| 포지션 사이징 | `수량 = 허용손실액 / (k × ATR)` — 변동성이 커지면 자동으로 수량이 준다 |

**함정**
1. **ATR은 방향을 모른다.** 급등에서도 급락에서도 오른다.
2. **절대값은 비교 불가.** BTC ATR $2,000과 SOL ATR $5를 직접 비교하는 것은 무의미 — 반드시 ATR%로 정규화.
3. 크립토는 갭이 거의 없어 TR ≈ H−L이 지배적이다. 주식의 ATR과 **의미가 미묘하게 다르다**(갭 리스크 미포함).

**궁합** — 모든 진입 지표의 **손절·사이징 짝**. 켈트너채널(ATR 기반), 볼린저(폭 비교로 스퀴즈 탐지).

**심화**
- ATR은 **분산이 아니라 평균 절대 진폭**이다. 표준편차 기반 변동성(볼린저)보다 극단값에 덜 민감하고, 팻테일 자산에서 더 안정적이다.
- ATR%를 쓰면 **자산 간·시기 간 변동성 레짐 비교**가 가능해진다. BTC ATR%는 대략 1.5%(저변동)~6%(패닉) 대역에서 움직인다 — 이 대역을 몸으로 익혀두면 "지금이 어떤 장인가"를 한 숫자로 판정할 수 있다.
- 샹들리에 엑싯(Chandelier Exit) = `최고가 − 3×ATR(22)`. ATR을 추적 손절로 쓰는 표준 구현.
- **프로젝트 연결**: `automation/btc-desk-build.py` §5.5가 4H ATR을 그대로 손절폭 힌트(2~3×ATR)로 출력한다 — 레짐 판정과 사이징을 한 자리에서 묶기 위해서다.

## C-2. 볼린저밴드

**정의** — John Bollinger(1980s). 이동평균 위아래로 **표준편차의 배수**만큼 밴드를 그린다. 변동성에 따라 폭이 자동 조절된다.

**계산식**

```
중심선 = SMA(20)
σ = 표준편차(C, 20)              ← 모집단 표준편차(n으로 나눔)
상단 = 중심선 + 2σ
하단 = 중심선 − 2σ

%B        = (C − 하단) / (상단 − 하단)
밴드폭(BW) = (상단 − 하단) / 중심선
```

**파라미터** — 20, 2σ 표준. 단기 10,1.5 / 장기 50,2.5. **크립토 팻테일에서는 2σ가 이론(95.4%)보다 훨씬 자주 뚫린다.**

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **밴드 스퀴즈**(BW 역사적 저점) | 변동성 압축 → **방향 불문 큰 움직임 임박.** 볼린저의 가장 신뢰도 높은 신호 |
| 밴드 상단 터치 | **매도 신호 아님.** 강세장에서는 상단을 타고 오른다("워킹 더 밴드") |
| %B > 1 상태 지속 | 강한 추세 |
| 상단 돌파 후 **밴드 밖에서 못 버팀** | 되돌림 확률 상승 |
| 중심선(SMA20) 지지/저항 | 추세 중 눌림목 기준선 |

**함정**
1. **"밴드 터치 = 반전"은 볼린저 본인이 명시적으로 부정한 해석이다.** 밴드는 상대적 고가/저가를 정의할 뿐, 방향 신호가 아니다.
2. 크립토 수익률 분포는 정규분포가 아니다(첨도 높음). **2σ 밖 사건이 이론 4.6%보다 훨씬 잦다** — 자산·기간에 따라 다르지만 대체로 이론값의 2~3배로 관측된다. 2σ를 "거의 안 뚫리는 선"으로 대하면 안 된다.
3. 표준편차를 n으로 나눌지 n−1로 나눌지 플랫폼마다 다르다(TradingView는 n). 소수점 차이지만 알림 임계에서는 문제가 된다.

**궁합** — 켈트너채널(스퀴즈 판정, C-3), RSI(밴드 터치 + 대역 확인), ADX(추세장이면 밴드 반전 전략 끄기)

**심화**
- 볼린저는 밴드를 **"상대적 고가·저가의 정의"** 로 설계했다. 신호가 아니라 **좌표계**다. 이 관점으로 옮기면 오용이 대부분 사라진다.
- %B는 밴드를 0~1로 정규화한 것으로, **스토캐스틱과 구조가 같다**(고정 창 대신 변동성 창을 쓴다는 점만 다름).
- BW(밴드폭)는 **실현변동성의 대리 지표**다. 옵션의 DVOL(내재변동성)과 나란히 보면 "시장이 매긴 변동성 vs 실제 변동성"의 괴리를 읽을 수 있다 — `automation/btc-desk-template.html` 8절과 직결.

## C-3. 켈트너채널 · TTM 스퀴즈

**정의** — Chester Keltner(1960) 원형, Linda Raschke 개정(1980s). 볼린저와 같은 밴드 구조지만 **폭을 표준편차가 아니라 ATR로** 잡는다.

**계산식**

```
중심선 = EMA(20)
상단   = EMA(20) + 2 × ATR(10)
하단   = EMA(20) − 2 × ATR(10)

TTM 스퀴즈 (John Carter)
  볼린저밴드가 켈트너채널 안으로 완전히 들어감  →  스퀴즈 ON
  볼린저가 켈트너 밖으로 다시 나감              →  스퀴즈 해제 = 발사
```

**파라미터** — EMA 20, ATR 10 또는 20, 배수 1.5~2.0

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **스퀴즈 ON** | 표준편차 < ATR = 방향성 없이 폭만 좁아진 상태. **에너지 축적** |
| 스퀴즈 해제 | 발사. **방향은 스퀴즈 자체가 알려주지 않는다** — MACD 히스토그램·CVD·OI 방향으로 판정 |
| 가격이 켈트너 상단 밖 지속 | 추세 확정 |
| 켈트너는 뚫었는데 볼린저 안 | 변동성 없는 상승 = 약한 돌파 |

**함정**
1. **스퀴즈는 방향 지표가 아니다.** 해제 후 방향을 미리 안다고 착각하는 것이 이 지표의 유일하고 치명적인 오용.
2. ATR 기반이라 볼린저보다 밴드가 **부드럽고 덜 민감하다** — 반전 신호로는 볼린저보다 못하다.
3. 크립토 주말 저유동성 구간에서 ATR이 인위적으로 줄어 **가짜 스퀴즈**가 뜬다. 주말 스퀴즈는 월요일 아시아 개장까지 판정 보류.

**궁합** — 볼린저(스퀴즈 판정에 필수 쌍), MACD 히스토그램(발사 방향), OI·펀딩(F 카테고리 — 발사 전 포지션 편향 확인)

**심화**
- 스퀴즈의 본질은 **σ(표준편차)와 ATR의 비율 변화**다. σ는 종가 기준이고 ATR은 고저 범위 기준이므로, **종가는 모이는데 장중 진폭은 유지되는 상황**에서 스퀴즈가 뜬다 — 즉 "장중에는 흔들지만 결국 제자리로 돌아오는" 흡수 구간을 잡아낸다. 이것이 대형 물량 흡수의 전형적 흔적이다.
- 크립토 파생 맥락에서 스퀴즈 ON + OI 증가 + 펀딩 상승 = **한쪽으로 쏠린 레버리지가 좁은 박스에 갇힌 상태**. 해제 시 청산 캐스케이드로 증폭될 확률이 가장 높은 세팅이다.

## C-4. 표준편차

**정의** — 모든 변동성 지표의 원자재. 볼린저밴드(C-2)의 부품이며, 단독으로도 변동성 레짐 판정에 쓴다.

**계산식**

```
σ = √( Σ(P_i - μ)² / n )        μ = SMA(P, n),  모집단(n으로 나눔)

표본 표준편차는 n-1로 나눈다 — 플랫폼마다 갈리는 지점
정규화:  σ% = σ / C × 100       ← 자산 간 비교에는 필수
```

**파라미터** — 20(볼린저와 동일). 레짐 판정용은 30~60.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| σ% 역사적 저점 | 변동성 압축. 방향 불문 확장 임박 |
| σ% 급등 | 이미 사건이 발생한 뒤 — **후행 확인이지 예측 아님** |
| σ% 고점 후 하락 | 패닉 소화 국면 |
| ATR%와 σ%가 벌어짐 | **종가는 모이는데 장중 진폭은 유지** = 흡수 구간 (스퀴즈의 원리) |

**함정**
1. **정규분포를 가정한 해석은 크립토에서 깨진다.** 2σ가 95%를 담는다는 전제가 성립하지 않는다.
2. 종가만 쓰므로 **장중 진폭을 전혀 반영하지 않는다.** 하루에 10% 왕복하고 제자리 마감한 봉의 σ 기여는 0이다 — ATR(C-1)과의 근본적 차이.
3. n vs n−1 분모 차이로 값이 다르다. 알림 임계에서 문제가 된다.

**궁합** — ATR(C-1)과 **쌍으로 볼 때가 진짜 용도**다. 둘의 비율이 스퀴즈·흡수를 판정한다.

**심화**
- σ와 ATR의 비율 `σ / ATR`은 **"움직임이 방향적인가 왕복적인가"**를 재는 값이다. 비율이 낮으면 장중에 흔들고 제자리(왕복), 높으면 방향을 만들며 이동. TTM 스퀴즈(C-3)가 하는 판정을 한 숫자로 압축한 형태.
- 표준편차는 제곱을 쓰므로 **큰 움직임 하나가 작은 움직임 여럿보다 훨씬 크게 반영**된다. 팻테일 자산에서 σ가 불안정한 근본 이유이며, ATR이 더 안정적인 이유이기도 하다.

## C-5. 히스토리컬 볼러틸리티

**정의** — 로그수익률의 표준편차를 **연율화**한 값. 옵션의 내재변동성(IV)과 직접 비교하기 위한 표준 형태다.

**계산식**

```
r_i = ln( C_i / C_{i-1} )                 ← 로그수익률

HV = √( Σ(r_i - r_avg)² / (n-1) ) × √(연간 기간수) × 100   [%]

연율화 계수
  크립토 일봉: √365   ← 무휴장
  주식 일봉:   √252   ← 거래일
  4시간봉:     √(365×6)
```

**파라미터** — 10 / 30 / 90일. **30일 HV가 옵션 30일 IV와 비교하는 표준 짝**이다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **IV(DVOL) > HV 크게** | 옵션이 비싸다 = 공포 프리미엄. 옵션 매도 우위 |
| **IV < HV** | 옵션이 싸다 = 시장이 방심. 옵션 매수 우위 |
| HV 30일 역사적 저점 | 변동성 압축 |
| HV 급등 후 정체 | 새 변동성 레짐 정착 |
| 단기 HV > 장기 HV | 변동성 확대 국면 |

**함정**
1. **연율화 계수를 틀리는 것이 최대 실수다.** 크립토에 √252를 쓰면 HV가 약 17% 과소평가된다. 무휴장이므로 √365가 맞다.
2. **HV는 후행이고 IV는 선행이다.** 둘을 직접 비교할 때 이 비대칭을 잊으면 안 된다 — HV 30일은 지나간 30일, IV 30일은 앞으로의 30일이다.
3. 로그수익률을 쓰는 이유는 대칭성 때문이다(+50%와 −33%가 같은 크기). **단순수익률로 계산하면 하락 구간에서 체계적으로 왜곡**된다.

**궁합** — **DVOL(F-5)과 쌍이 본체**다. ATR%(C-1)와도 비교 가능하나 단위가 달라 직접 비교는 불가.

**심화**
- HV와 IV의 차 `IV − HV`가 **변동성 위험 프리미엄(VRP)** 이다. 장기적으로 양수인 것이 정상이며(보험료), 이것이 옵션 매도 전략의 이론적 근거다. 음수로 뒤집히는 구간은 시장이 실현 변동성을 과소평가하는 드문 상태다.
- 크립토는 주말 변동성이 평일보다 낮은 편이라, 365일 연율화가 실제 변동성을 다소 과대평가하는 경향이 있다. 정밀 비교가 필요하면 **거래소가 쓰는 연율화 규약(Deribit은 365)**에 맞출 것.

## C-6. 도너찬채널

**정의** — Richard Donchian. 최근 n봉의 **최고가와 최저가**를 그대로 밴드로 쓴다. 계산이 가장 단순한 변동성 채널이자, 터틀 트레이딩 시스템의 핵심 부품.

**계산식**

```
상단 = 최근 n봉의 최고 고가
하단 = 최근 n봉의 최저 저가
중심 = (상단 + 하단) / 2

※ 평균도 표준편차도 쓰지 않는다. 극값 그 자체.
```

**파라미터** — 20(진입) / 10(청산)이 터틀 규칙. 크립토 일봉은 20/55를 병용.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **종가가 20일 상단 돌파** | 터틀 매수 진입 |
| **종가가 10일 하단 이탈** | 터틀 청산 |
| 채널 폭 축소 | 변동성 압축(볼린저 스퀴즈와 같은 의미, 다른 계산) |
| 가격이 중심선 부근 | 방향 없음 |
| 상단이 계속 갱신 | 추세 지속 |

**함정**
1. **돌파 전략은 승률이 낮다.** 터틀 시스템의 실제 승률은 30~40%대이고, 소수의 큰 추세로 수익을 낸다. **승률을 기대하고 쓰면 반드시 중도 포기**한다.
2. 극값 기반이라 **드롭오프가 계단식**이다. 큰 봉이 창에서 빠지는 순간 채널이 점프한다.
3. 크립토의 잦은 위꼬리 스파이크가 상단을 밀어올려 **가짜 돌파를 만든다.** 종가 기준 돌파만 채택할 것.

**궁합** — ATR(C-1, 터틀 원본이 ATR로 사이징), ADX(A-6, 횡보 필터). 볼린저(C-2)와는 같은 축이므로 중복.

**심화**
- 도너찬채널의 진짜 가치는 **완전한 무재량성**이다. 평활도 파라미터 튜닝도 없이 "최근 20일 신고가"라는 사실만 쓴다. 백테스트 과적합 여지가 가장 적은 지표 중 하나.
- 터틀 시스템은 채널 돌파(진입) + ATR 사이징(리스크) + 피라미딩(증분 진입)의 **3부작**이다. 채널만 떼어 쓰면 원 시스템의 성과와 무관하다 — 이 프로젝트의 `framework/btc-pyramid-plan-*` 문서와 연결되는 지점.

## C-7. 촙피니스 인덱스

**정의** — Choppiness Index. E.W. Dreiss. **시장이 추세 중인가 횡보 중인가만** 판정한다. ADX와 목적이 같지만, 프랙탈 기하에 기반한 완전히 다른 계산.

**계산식**

```
CHOP = 100 × log10( Σ(TR, n) / (n기간 최고 - n기간 최저) ) / log10(n)

분자 = n봉 동안 실제로 이동한 총 거리
분모 = n봉 동안 순수하게 이동한 순거리(범위)

→ 같은 거리를 왕복했으면 분자만 커진다 = CHOP 상승
```

**파라미터** — 14 표준. 값은 구조적으로 **0~100에 유계**다.

**판정 규칙**

| CHOP | 판정 |
|---|---|
| **> 61.8** | 횡보 확정. **추세추종 전략 전면 정지** |
| 38.2 ~ 61.8 | 중립 |
| **< 38.2** | 강한 추세 진행 중 |
| CHOP 고점 후 하락 반전 | 횡보 종료 = **돌파 임박** (가장 유용한 사용법) |
| CHOP 저점 후 상승 반전 | 추세 소진 |

**⭐ ADX × CHOP 2×2 — 어긋남 자체가 정보다**

| | CHOP < 38.2 (추세) | CHOP > 61.8 (횡보) |
|---|---|---|
| **ADX ≥ 25** | **추세 확정** — 둘 다 확인. 추세추종 ON | **추세 소진** — ADX는 지나간 추세의 잔상. 신규 진입 OFF, 이익 실현 |
| **ADX < 20** | **추세 태동** — CHOP이 먼저 알림. 소액 선진입, ADX 25 돌파가 확인 트리거 | **횡보 확정** — 둘 다 확인. 레인지 전략 ON |

**함정**
1. **방향을 전혀 말하지 않는다.** ADX와 동일한 성격이며, CHOP이 낮다고 상승장이 아니다.
2. 38.2 / 61.8 임계는 **피보나치 수를 가져다 쓴 것**이며 통계적 근거가 없다. 자산별로 실측해 조정하는 편이 낫다.
3. **후행이 아니라 동행에 가깝지만, 극단에서 반전을 예고하는 성격이 있어 선행처럼 보인다.** 이 착각으로 과신하기 쉽다.

**궁합** — **ADX(A-6)의 대체재이자 교차검증**이다. 둘이 같은 방향을 가리키면 레짐 판정 신뢰도가 크게 오른다. 볼린저 밴드폭(C-2)과 조합하면 "횡보 + 압축" 상태를 정밀하게 잡는다.

**심화**
- 분자/분모 비율은 **경로 길이 ÷ 변위**, 즉 물리학의 곡률 개념이다. 직선으로 가면 1에 가깝고, 왕복하면 커진다. log를 씌워 n에 대해 정규화한 것이 CHOP이며, 이 때문에 **다른 기간끼리도 비교 가능**하다 — ADX가 못 하는 일.
- ADX는 SMMA를 두 번 거쳐 매우 느린 반면, CHOP은 평활이 없어 **훨씬 빠르게 레짐 전환을 알린다.** 대신 노이즈가 있다. 실무에서는 **CHOP으로 먼저 알아채고 ADX로 확인**하는 순서가 잘 맞는다.
- **⭐ 프로젝트 연결(2026-09-08)**: `automation/btc-desk-build.py` §5.5가 위 2×2를 그대로 코드로 옮겼다. 4H·1D 두 시간축에서 판정하고, 두 축이 갈리면 4H를 우선하되 사이즈를 줄이라고 명시한다. 데스크 출력의 **맨 첫 줄**이 이 판정이다 — 포지셔닝 얘기를 꺼내기 전에 "어떤 전략을 켤 것인가"부터 답하게 만든 것.

# D. 거래량 (Volume)

## D-1. OBV — 온밸런스볼륨

**정의** — Joseph Granville(1963). 종가가 오른 봉의 거래량은 더하고 내린 봉의 거래량은 빼서 누적. **"거래량은 가격에 선행한다"**는 가설의 가장 단순한 구현.

**계산식**

```
        OBV_{t-1} + V_t     (C_t > C_{t-1})
OBV_t = OBV_{t-1}           (C_t = C_{t-1})
        OBV_{t-1} − V_t     (C_t < C_{t-1})
```

**파라미터** — 없음(누적형). 통상 OBV 위에 EMA(20)를 얹어 방향을 읽는다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 신고가 + OBV 신고가 | 추세 건강 |
| **가격 신고가 + OBV 저점 절하** | 거래량 미확인 상승 = 분산(distribution) 의심 |
| 가격 횡보 + OBV 상승 | 조용한 매집 가능성 |
| 가격 하락 + OBV 유지 | 매도 소진 |

**함정**
1. **봉 전체 거래량을 종가 방향으로 몰아준다.** 장중에 크게 밀렸다가 +0.01%로 마감한 봉의 거래량 전부가 "매수"로 계상된다 — OBV의 근본적 결함.
2. **절대값이 무의미하다.** 시작점에 따라 값이 달라지므로 **형태와 다이버전스만** 본다.
3. 크립토는 거래소별 거래량이 다르고 워시 트레이딩이 섞인다. **단일 거래소 OBV는 그 거래소 사정만 반영**한다.

**궁합** — MFI(유계 버전), CVD(체결 방향 기반 정밀 버전), 가격 다이버전스

**심화**
- OBV의 결함을 고친 계열이 있다: **A/D Line**(봉 내 종가 위치로 가중), **CMF**(기간 정규화), 그리고 크립토의 **CVD**(실제 테이커 매수/매도 체결로 계산 — 봉 방향 추정이 아예 필요 없다). 정밀도 순서는 `CVD > A/D > OBV`.
- 그럼에도 OBV가 살아남은 이유는 **계산이 투명해 왜곡 지점을 정확히 알 수 있기** 때문이다. 정교한 지표가 어디서 틀리는지 모르는 것보다, 단순한 지표가 어디서 틀리는지 아는 편이 낫다.

---

## D-2. VWAP · 앵커드 VWAP

**정의** — 거래량가중평균가격. **실제로 체결된 평균 단가**. 지표라기보다 사실의 기록에 가깝다.

**계산식**

```
VWAP = Σ(TP_i × V_i) / Σ(V_i)          TP = (H+L+C)/3

밴드:  VWAP ± k × σ_vw
       σ_vw = √( Σ V_i(TP_i − VWAP)² / ΣV_i )   ← 거래량가중 표준편차

앵커드 VWAP: 누적 시작점을 임의 시점으로 지정
             (사상 최고점, 폭락 저점, 반감기, ETF 승인일 등)
```

**파라미터** — 앵커 위치가 유일한 파라미터이자 전부다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 > 세션 VWAP | 그 세션 매수자 평균이 이익 중 |
| 가격 < VWAP | 매수자 평균이 손실 중 — **되돌림 시 본전 매물 저항** |
| VWAP 회귀 | 일중 트레이딩의 기준 평균 회귀 대상 |
| **앵커드 VWAP 지지/저항** | 특정 사건 이후 진입한 전체 참여자의 평균 단가 = 심리적 임계 |
| VWAP 밴드 ±2σ | 일중 과열/침체 |

**함정**
1. **일중(intraday) 지표다.** 일봉 이상에서 세션 VWAP은 의미가 없다 — 그때는 앵커드 VWAP을 써야 한다.
2. **크립토에는 "세션"이 없다.** 어디를 0시로 잡느냐(UTC/KST/거래소 자체)에 따라 값이 전부 달라진다. **이 프로젝트는 UTC 기준으로 고정할 것.**
3. 거래소 단일 거래량 기반이므로 파편화된 크립토 시장에서는 전체 시장 평균 단가가 아니다.

**궁합** — 거래량 프로파일(POC와 VWAP은 다른 개념 — 아래 참조), 앵커드 VWAP ↔ 온체인 실현가격(realized price)

**심화**
- **VWAP ≠ POC.** VWAP은 거래량가중 *평균*, POC는 거래량이 가장 많이 쌓인 *최빈 가격*이다. 분포가 치우치면 둘은 크게 갈린다. **평균과 최빈값의 차이 자체가 매물 분포의 비대칭을 알려주는 정보다.**
- 앵커드 VWAP은 크립토에서 유난히 잘 듣는다. 사상 최고점($126,198 · 2025-10-06)에서 앵커한 VWAP은 **그 고점 이후 진입한 모든 자금의 평균 단가**이며, 이 선의 탈환 여부는 "물린 물량이 본전에 왔는가"와 정확히 같은 질문이다.
- 온체인의 **실현가격(Realized Price)** 이 개념적으로 전체 시장의 앵커드 VWAP이다 — G-3 참조.

## D-3. 거래량 프로파일 — POC · VA · HVN/LVN

**정의** — 시간축이 아니라 **가격축**으로 거래량을 집계한다. "언제 얼마나 거래됐나"가 아니라 **"어느 가격에서 얼마나 거래됐나"**.

**계산식**

```
가격을 티크 구간으로 분할 → 각 구간의 체결 거래량 누적

POC (Point of Control)  = 거래량 최대 가격대
VA  (Value Area)        = POC에서 위아래로 확장하며 총 거래량의 70%를 포함하는 구간
VAH / VAL               = Value Area 상단 / 하단
HVN (High Volume Node)  = 국소 거래량 봉우리 → 자석·저항
LVN (Low Volume Node)   = 국소 거래량 골짜기 → 빠르게 통과하는 구간
```

**파라미터** — 집계 구간(가시 범위 / 세션 / 고정 범위), 가격 분할 수(통상 24~100), VA 비율 70%(정규분포 1σ 근사에서 유래)

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격이 POC 접근 | 자석 효과. 매물이 가장 두꺼운 곳 |
| **가격이 LVN 구간 진입** | 매물 공백 → **빠르게 통과.** 이 구간에 손절을 두면 안 된다 |
| VA 밖 → VA 안 재진입 | 평균 회귀 시나리오 (POC 목표) |
| VA 밖에서 안착 | 새로운 가치 영역 형성 = 추세 이동 |

**함정**
1. **집계 범위를 어디로 잡느냐가 결과를 지배한다.** 자의성이 가장 큰 지표 — 범위를 먼저 정하고 프로파일을 보는 것이 아니라, 원하는 결론에 맞춰 범위를 고르게 되기 쉽다.
2. 크립토는 거래량이 여러 거래소에 흩어져 있어 **단일 거래소 프로파일은 전체 매물 분포가 아니다.**
3. 현물 프로파일과 파생 프로파일은 다른 것을 잰다. 파생 POC는 **청산 밀집대**에 가깝고 현물 POC는 **실제 보유 원가대**에 가깝다.

**궁합** — VWAP(평균 vs 최빈), 피봇포인트(둘 다 레벨 지표 — 겹치면 신뢰도 상승), 청산 히트맵(D-8)

**심화**
- 이론적 뿌리는 J. Peter Steidlmayer의 **Market Profile**(1980s, CBOT)이다. 원형은 시간·가격 분포(TPO)를 알파벳으로 그렸고, 거래량 프로파일은 그 거래량 버전이다.
- VA 70%는 **정규분포 1σ(68.3%)의 근사**다. 크립토 팻테일에서는 이 가정이 약하지만, 실무에서는 "대부분의 거래가 여기서 일어났다"는 기술(descriptive) 목적이라 큰 문제는 아니다.
- **이 프로젝트 실사용 이력**: `automation/coin-alert-state.md`의 UNI 항목에 "6.121 POC"가 라인 후보로 기록돼 있다(현재 알림 제외 상태). 프로파일 기반 레벨이 이미 알림 체계에 들어와 있었다는 뜻이다.

## D-4. CVD — 누적 거래량 델타 ⭐

**정의** — Cumulative Volume Delta. **실제 체결에서 테이커 매수와 테이커 매도의 차이를 누적**한다. OBV가 봉의 방향으로 거래량을 추정하는 반면, CVD는 체결 하나하나의 공격 방향을 직접 센다. **거래량 지표 중 가장 정밀하며, 크립토에서만 제대로 구할 수 있다.**

**계산식**

```
각 체결(trade)마다
  테이커가 매수 주문 → 델타 += 수량
  테이커가 매도 주문 → 델타 -= 수량

봉 델타 = Σ(테이커 매수) - Σ(테이커 매도)
CVD_t   = CVD_{t-1} + 봉 델타_t

★ 현물 CVD와 퍼프 CVD를 반드시 분리한다.
   현물 CVD = 실제 자금의 방향
   퍼프 CVD = 레버리지 포지션의 방향
```

**파라미터** — 없음(누적형). 앵커(누적 시작점)를 어디로 잡느냐가 유일한 선택. 통상 7일/30일 롤링 또는 사건 앵커.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격↑ + 현물 CVD↑ | **건강한 상승.** 실제 매수가 밀어올림 |
| **가격↑ + 현물 CVD↓** | **흡수(absorption).** 매도가 나오는데 가격이 버팀 = 대형 매수벽이 받는 중. 강세 신호 |
| **가격↓ + 현물 CVD↑** | 역흡수. 매수가 들어오는데 가격이 밀림 = 대형 매도벽. 약세 신호 |
| 현물 CVD↑ + 퍼프 CVD↓ | **현물이 사고 파생이 파는 중** — 통상 바닥권 구조 |
| 현물 CVD↓ + 퍼프 CVD↑ | 레버리지만 롱. 가장 취약한 조합 |
| 가격 신고가 + CVD 저점 절하 | 다이버전스. **OBV 다이버전스보다 신뢰도가 훨씬 높다** |

**함정**
1. **거래소 단일 데이터다.** 크립토는 시장이 파편화돼 있어, 한 거래소 CVD는 그 거래소의 주문 흐름일 뿐이다. 최소 현물 3~4개 + 퍼프 2~3개를 합산해야 시장 전체에 가깝다.
2. **절대값은 무의미하다.** 앵커 시점에 의존하므로 형태와 다이버전스만 본다.
3. 테이커 방향은 **공격성이지 의도가 아니다.** 대형 기관은 메이커 지정가로 조용히 채우므로 CVD에 반대 부호로 잡히거나 아예 안 잡힌다 — 흡수 신호가 유효한 이유이자, CVD를 "스마트머니 추적기"로 오해하면 안 되는 이유.
4. 무기한선물 CVD는 **청산 물량이 섞인다.** 강제청산은 자발적 의사가 아니므로, 캐스케이드 구간의 CVD 급변은 심리가 아니라 기계적 결과다.

**궁합** — **OI(F-2)와 함께가 본체다.** CVD는 방향, OI는 포지션 증감 — 둘을 겹치면 "누가 무엇을 새로 열었나"가 나온다. 프로파일(D-3)과 겹치면 흡수가 일어난 가격대를 특정할 수 있다.

**심화**
- CVD는 **OBV의 결함을 원천적으로 제거한 것**이다. OBV는 봉 마감 방향으로 거래량 전체를 몰아주지만, CVD는 체결 단위로 실제 공격 방향을 센다. 정밀도 서열은 `CVD > A/D Line > OBV`이며, 이 셋을 같이 띄우는 것은 중복이다.
- **흡수(absorption)가 CVD의 존재 이유**다. 가격과 CVD가 같이 움직일 때 CVD는 확인 도구일 뿐이지만, 어긋날 때 비로소 다른 지표가 못 보는 것을 본다 — 지정가 벽이 시장가 주문을 받아내고 있다는 사실.
- **프로젝트 연결**: `automation/btc-desk-build.py`가 이미 현물 CVD와 퍼프 CVD를 7일 누적으로 수집하고 `btc-desk-template.html`이 가격·현물CVD·퍼프CVD 3단 패널로 표시한다. 위 판정 규칙이 그 패널을 읽는 방법이다.

## D-5. A/D Line — 누적 매집·분산선

**정의** — Accumulation/Distribution Line. Marc Chaikin. **봉 안에서 종가가 어디에 마감했는지**로 거래량을 배분한다. OBV(전부 아니면 전무)와 CVD(체결 단위) 사이의 절충.

**계산식**

```
MFM (Money Flow Multiplier) = ( (C - L) - (H - C) ) / (H - L)
                             ∈ [-1, +1]
   C = H  →  +1  (전부 매수)
   C = 중간 →  0
   C = L  →  -1  (전부 매도)

MFV = MFM × V
A/D_t = A/D_{t-1} + MFV_t
```

**파라미터** — 없음(누적형).

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격↑ + A/D↑ | 매집 확인 |
| **가격 신고가 + A/D 저점 절하** | 분산(distribution). OBV보다 정밀한 다이버전스 |
| 가격 횡보 + A/D 상승 | 조용한 매집 |
| A/D 기울기 급변 | 물량 방향 전환 |

**함정**
1. **갭을 완전히 무시한다.** 전봉 종가를 안 보고 당일 H·L만 쓰므로, 갭 상승 후 장중 하락한 봉이 강한 매도로 잡힌다. 갭이 없는 크립토에서는 이 결함이 거의 사라져 **주식보다 크립토에서 더 잘 맞는 지표**다.
2. **H = L이면 0으로 나눈다.** 저유동 알트에서 발생.
3. 절대값 무의미. 형태와 다이버전스만.

**궁합** — CMF(D-6)는 A/D의 기간 정규화 버전이라 **둘은 중복**이다. 하나만 고를 것. CVD(D-4)를 구할 수 있으면 A/D는 불필요하다.

**심화**
- MFM은 **봉 내부의 종가 위치**를 −1~+1로 정규화한 값으로, 스토캐스틱 %K를 −1~1 스케일로 옮긴 것과 수학적으로 같다. 즉 A/D는 **"스토캐스틱 × 거래량"의 누적**이다. 이 관점이면 A/D가 왜 가격 모멘텀과 상관이 높은지 바로 보인다.
- 크립토에서 A/D는 **현물 거래소 데이터로만** 계산해야 의미가 있다. 파생 거래량으로 계산하면 실제 물량 이동이 아니라 레버리지 회전을 세게 된다.

## D-6. CMF — 차이킨 머니 플로우

**정의** — A/D Line(D-5)을 n기간으로 잘라 거래량으로 정규화한 것. 누적형인 A/D를 **유계에 가까운 오실레이터**로 바꿔 시기 간 비교를 가능하게 했다.

**계산식**

```
CMF = Σ(MFM_i × V_i, n) / Σ(V_i, n)

MFM = ( (C-L) - (H-C) ) / (H-L)          ← A/D와 동일
값 범위: 이론상 -1 ~ +1 (실무는 대개 ±0.3 이내)
```

**파라미터** — 20 또는 21.

**판정 규칙**

| CMF | 판정 |
|---|---|
| **> +0.20** | 강한 매집 |
| +0.05 ~ +0.20 | 완만한 유입 |
| −0.05 ~ +0.05 | 중립. **대부분의 시간을 여기서 보낸다** |
| **< −0.20** | 강한 분산 |
| 0선 교차 | 자금 방향 전환 |
| 가격 신고가 + CMF 하락 | 다이버전스 |

**함정**
1. **A/D Line과 완전한 중복**이다. 같은 MFM을 쓰며 정규화 여부만 다르다.
2. **±0.20 임계는 주식 기준**이다. 크립토는 변동성이 커 ±0.3 이상도 흔하다 — 자산별로 실측해 조정할 것.
3. MFI(B-4)와 이름·목적이 비슷해 혼동되지만 계산이 다르다. MFI는 **봉 간 TP 방향**, CMF는 **봉 내 종가 위치**를 쓴다. 둘 다 띄우면 서로 다른 신호를 줘서 혼란만 생긴다 — 하나만 고르라.

**궁합** — RSI(B-1)와 조합하면 "가격 모멘텀 vs 자금 유입"의 괴리를 본다. A/D·MFI와는 중복.

**심화**
- CMF의 실질 강점은 **유계에 가까워 임계선을 고정할 수 있다는 것**이다. 누적형 지표(OBV·A/D·CVD)는 알림을 걸 수 없지만 CMF는 걸 수 있다 — 자동화 관점에서 이 차이가 크다.
- 크립토에서 CMF를 쓸 거라면 **분모의 거래량을 현물로 고정**하고, 워시 트레이딩 비중이 큰 거래소를 배제할 것. 분모가 오염되면 지표 전체가 무의미해진다.

## D-7. 거래량 오실레이터

**정의** — 단기 거래량 이동평균과 장기 거래량 이동평균의 **차이를 백분율로** 표현. 가격은 전혀 안 보고 **거래량의 상대적 활성도만** 잰다.

**계산식**

```
VO = ( SMA(V, f) - SMA(V, s) ) / SMA(V, s) × 100        [%]

f = 5, s = 20 표준
값 > 0 : 최근 거래량이 평균보다 많음
```

**파라미터** — 5 / 20 또는 14 / 28.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **VO > 0 + 가격 돌파** | 거래량이 동반된 돌파 = **유효** |
| **VO < 0 + 가격 돌파** | 거래량 없는 돌파 = **가짜 돌파 의심** |
| VO 급등 + 가격 정체 | 흡수 또는 손바뀜. CVD로 방향 확인 필요 |
| VO 지속 음수 | 관심 소멸. 추세 전략 전부 무효 |
| VO 극단 고점 | 클라이맥스 — 추세 종료 신호일 수 있음 |

**함정**
1. **방향을 전혀 모른다.** 거래량은 부호가 없다 — 급등에서도 급락에서도 오른다.
2. **거래량 데이터 품질에 전적으로 의존**한다. 워시 트레이딩이 섞이면 VO는 그 거래소의 봇 활동을 재게 된다.
3. 크립토는 요일 효과가 있다(주말 거래량 감소). **5/20 조합은 주 단위 리듬을 그대로 반영**하므로, 주말마다 VO가 음수로 가는 것을 신호로 오독하기 쉽다. 7의 배수(7/28)로 잡으면 이 왜곡이 줄어든다.

**궁합** — **돌파 전략의 필수 필터**다. 도너찬(C-6)·볼린저(C-2) 돌파에 VO > 0 조건을 붙이면 가짜 돌파가 크게 걸러진다. 방향은 CVD(D-4)로.

**심화**
- VO는 가격 지표가 아니라 **참여도 지표**다. A~C 카테고리 전부가 가격의 함수인 반면 VO는 완전히 독립된 입력을 쓴다 — 조합 규칙(부록 3)의 3단계 "독립 확인"에 정확히 해당하는 자리.
- 크립토에서 VO 급등의 원인은 셋 중 하나다: 실제 관심 유입, 청산 캐스케이드, 거래소 인센티브 이벤트. **세 번째를 걸러내지 않으면 지표가 거짓말한다** — VO 급등 시 해당 거래소 공지를 확인하는 습관이 필요하다.

## D-8. 청산 히트맵

**정의** — 강제청산이 발생할 가격대의 **밀집도 지도**. 시장에 걸린 레버리지 포지션들의 청산가를 가격축에 누적해, "어느 가격에 연료가 쌓여 있는가"를 본다. 크립토 고유 지표.

**계산식**

```
각 포지션의 청산가 근사
  롱  청산가 ≈ 진입가 × (1 - 1/레버리지 + 유지증거금률)
  숏  청산가 ≈ 진입가 × (1 + 1/레버리지 - 유지증거금률)

히트맵 = Σ (추정 포지션 규모)  를 청산가 구간별로 누적
  진입가 분포 ← 최근 봉의 거래가·거래량으로 추정
  레버리지 분포 ← 통상 10x · 25x · 50x · 100x 가중

★ 정확한 개별 포지션은 알 수 없다. 이것은 추정 모델이다.
```

**파라미터** — 집계 기간(최근 30~90봉), 레버리지 가중, 가격 구간 수. **모델 가정이 곧 결과**이므로 벤더마다 그림이 다르다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 위에 숏 청산 밀집 | **자석.** 그쪽으로 끌리는 경향(숏 스퀴즈 연료) |
| 가격 아래 롱 청산 밀집 | 하방 자석(롱 캐스케이드 연료) |
| **양쪽 비대칭** | 밀집이 두꺼운 쪽으로 움직일 유인이 크다 |
| 밀집대 통과 직후 | 연료 소진. **같은 구간 재방문 시 저항이 줄어듦** |
| 밀집대가 얇음 | 캐스케이드 위험 낮음 |

**함정**
1. **추정치다.** 거래소는 개별 포지션 청산가를 공개하지 않는다. 히트맵은 모델 산출물이며, 벤더의 레버리지 가정에 따라 그림이 크게 달라진다.
2. **"가격이 유동성을 사냥하러 간다"는 서사에 과몰입하기 쉽다.** 밀집대가 자석처럼 보이는 것은 사실 청산이 발생한 뒤의 사후 해석인 경우가 많다.
3. 격리마진·교차마진, 헤지 포지션, 옵션 헤지 물량은 모델에 안 잡힌다. **실제 청산 규모는 히트맵보다 작을 수도 클 수도 있다.**
4. CoinGlass 등 주요 소스가 로그인 게이트라 자동 수집이 어렵다 — `framework/exchange-api-access-matrix.md`에 미수집으로 기록돼 있다.

**궁합** — **OI(F-2)와 펀딩(F-1)이 필수 짝**이다. OI가 높고 펀딩이 한쪽으로 극단일 때 히트맵의 반대쪽 밀집이 실제 위험이 된다. 프로파일(D-3)과 겹치면 "매물대 + 청산대"가 동시에 있는 진짜 임계 가격이 나온다.

**심화**
- 히트맵의 본질은 **강제 시장가 주문의 예약 장부**다. 일반 매물대(프로파일)는 지정가로 기다리는 물량이지만, 청산 밀집대는 **가격이 닿는 순간 무조건 시장가로 나오는** 물량이다. 이 차이가 캐스케이드를 만든다.
- **자기무효화 성격**이 있다. 히트맵이 널리 공유되면 그 가격대에 유동성이 미리 배치되어 청산 충격이 흡수된다. 널리 알려진 밀집대일수록 실제 충격은 작아진다.
- 이 프로젝트의 파생 데스크는 청산 규모(실현된 청산액)는 수집하지만 히트맵(예상 청산가 분포)은 수집하지 못한다. **둘은 다른 것이다** — 전자는 사후, 후자는 사전.

# E. 가격 레벨 (Level)

## E-1. 피봇포인트 — 4개 변형 ⭐

**정의** — 전 기간의 고·저·종가만으로 다음 기간의 지지·저항을 **산술적으로** 도출한다. **주관이 개입하지 않는 유일한 레벨 지표**라는 점이 핵심 가치다. 원형은 1900년대 초 플로어 트레이더들이 손계산으로 쓰던 방식.

**계산식 — 4변형**

```
■ Classic (Standard / Floor)
  P  = (H + L + C) / 3
  R1 = 2P − L                 S1 = 2P − H
  R2 = P + (H − L)            S2 = P − (H − L)
  R3 = H + 2(P − L)           S3 = L − 2(H − P)

■ Fibonacci
  P  = (H + L + C) / 3
  R1 = P + 0.382(H − L)       S1 = P − 0.382(H − L)
  R2 = P + 0.618(H − L)       S2 = P − 0.618(H − L)
  R3 = P + 1.000(H − L)       S3 = P − 1.000(H − L)

■ Camarilla (Nick Scott, 1989)   ← 종가 기준, 레벨이 매우 촘촘
  R1 = C + (H − L) × 1.1/12    S1 = C − (H − L) × 1.1/12
  R2 = C + (H − L) × 1.1/6     S2 = C − (H − L) × 1.1/6
  R3 = C + (H − L) × 1.1/4     S3 = C − (H − L) × 1.1/4
  R4 = C + (H − L) × 1.1/2     S4 = C − (H − L) × 1.1/2

■ Woodie                          ← 종가에 2배 가중
  P  = (H + L + 2C) / 4
  R1 = 2P − L                 S1 = 2P − H
  R2 = P + (H − L)            S2 = P − (H − L)

■ (참고) DeMark                   ← 시가·종가 관계로 분기
  C < O :  X = H + 2L + C
  C > O :  X = 2H + L + C
  C = O :  X = H + L + 2C
  P = X/4,  R1 = X/2 − L,  S1 = X/2 − H
```

**파라미터** — 기준 기간: 일간(단타) / 주간(스윙) / 월간(포지션). **크립토는 일간 경계를 UTC 0시로 고정할 것** — KST 기준으로 잡으면 전혀 다른 레벨이 나온다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 시가 > P | 그날의 편향은 상방 |
| 시가 < P | 하방 편향 |
| R1/S1 도달 | 1차 반응 지점. 통계적으로 가장 자주 닿는 레벨 |
| R2/S2 이상 도달 | 추세일(trend day) — 레인지 전략 폐기 |
| **P를 하루 종일 관통 반복** | 방향 없음. 피봇 전략 무효 |
| 여러 변형의 레벨이 겹침 | **신뢰도 상승 — 이것이 4변형을 같이 보는 이유** |

**함정**
1. **자기실현적 성격에 의존한다.** 많은 참여자가 같은 레벨을 볼 때만 작동한다. 크립토는 주식보다 피봇 사용 비중이 낮아 효과가 약하다.
2. Camarilla는 레벨이 촘촘해 **아무 데나 닿는다.** 정보량이 낮다 — 단타 스캘핑 외에는 부적합.
3. **전일이 이상치(급등·급락)면 다음날 레벨 전체가 왜곡**된다. 청산 캐스케이드가 잦은 크립토에서 특히 자주 발생.
4. 변형 간 값이 크게 다르다. 어떤 변형을 쓰는지 밝히지 않은 "피봇 저항" 언급은 의미가 없다.

**궁합** — 거래량 프로파일(POC/VAH/VAL과 겹치는 레벨 = 최상급 신뢰), 피보나치 되돌림, 알림 라인 설정

**심화**
- Classic의 R1 = 2P − L은 **P를 축으로 저가를 반사한 값**이다("전일 저가만큼 위로"). 대칭 반사 구조라는 점을 알면 R1/S1을 외울 필요가 없다.
- Woodie가 종가에 2배 가중하는 것은 **종가가 가장 정보량이 많다**는 가정(정산·마감 물량 반영)이다. 24시간 무휴장인 크립토에서는 이 가정이 가장 약해진다 — **크립토에서 Woodie의 근거가 가장 빈약한 이유.**
- Camarilla의 1.1 상수는 Nick Scott의 경험적 최적화값으로 이론적 유도가 없다.
- **⭐ 이 프로젝트에서의 실제 사용**: `automation/coin-alert-state.md`의 BTC-DOWN 라인(79,000)이 "이전 Pivot-S 재차 하락 돌파 + 하락추세선 관통라인 이탈"을 근거로 설정돼 있다. **다만 어느 변형·어느 기간(일/주/월) 기준인지 기록돼 있지 않다.** → 다음 알림 라인 갱신 시 `변형/기간`을 반드시 병기하도록 포맷을 바꿀 것. **(부록 4 권장 2번 — 아직 미처리)**

## E-2. 피보나치 되돌림 · 확장

**정의** — 추세의 한 구간(저점→고점)을 잡고, 그 폭에 피보나치 비율을 적용해 되돌림·목표 레벨을 도출.

**계산식**

```
되돌림 (Retracement)   상승 구간 L→H 기준
  레벨 = H − (H − L) × r
  r ∈ { 0.236, 0.382, 0.500*, 0.618, 0.786 }

확장 (Extension)       되돌림 종료 후 목표
  레벨 = H + (H − L) × r
  r ∈ { 0.272, 0.618, 1.000, 1.272, 1.618, 2.618 }

* 0.5는 피보나치 수가 아니다 — 다우 이론의 절반 되돌림에서 편입된 관행
```

**비율의 출처**

```
0.618 = 1/φ          (φ = 황금비 1.618...)
0.382 = 1 − 0.618  =  φ⁻²
0.786 = √0.618
0.236 = φ⁻³
1.618 = φ
```

**파라미터** — 구간(swing) 선택. **이것이 전부이자 이 지표의 최대 약점.**

**판정 규칙**

| 레벨 | 통상 해석 |
|---|---|
| 0.236 | 얕은 되돌림 = 매우 강한 추세 |
| **0.382 ~ 0.5** | 건강한 추세 내 눌림. 가장 많이 쓰이는 대역 |
| **0.618** | "황금 되돌림". 여기서 실패하면 추세 훼손 의심 |
| 0.786 | 마지막 방어선. 이탈 시 추세 종료로 간주 |
| 1.0 이탈 | 추세 무효 |
| **여러 스윙의 되돌림이 겹치는 구간** | **컨플루언스(confluence) — 단일 레벨보다 훨씬 유의미** |

**함정**
1. **구간 선택이 자의적이다.** 다른 스윙을 잡으면 완전히 다른 레벨이 나온다. **결론을 정해놓고 구간을 고르는 것**이 이 지표의 지배적 오용 방식.
2. 이론적 근거가 없다. 시장이 황금비를 따를 이유는 없으며, 작동하는 정도만큼은 **자기실현**이다.
3. 크립토는 되돌림 폭이 주식보다 훨씬 깊다. 0.618 이탈이 추세 종료를 의미하지 않는 경우가 흔하다 — 강세장 중 0.786까지 되돌린 뒤 신고가 사례 다수.

**궁합** — 피봇포인트, 거래량 프로파일 HVN, 앵커드 VWAP. **레벨 지표는 단독으로 쓰지 말고 겹침(컨플루언스)으로만 쓴다** — 이것이 E 카테고리 전체의 사용 원칙.

**심화**
- 0.618과 0.382는 **서로 보수 관계**(0.618 + 0.382 = 1)이며 φ⁻¹과 φ⁻²다. 세 레벨(0.382/0.5/0.618)이 좁게 몰려 있어 "어딘가는 맞는" 구조적 이점이 있다 — 이것이 피보나치가 사후적으로 항상 맞아 보이는 통계적 이유다.
- 실전 가치는 비율 자체가 아니라 **다른 근거와 겹치는지**에 있다. 0.618이 동시에 주간 피봇 S1이고 프로파일 HVN이면 그 레벨은 유의미하다. 셋 중 하나뿐이면 유의미하지 않다.
- 확장 1.272 = √1.618, 2.618 = φ². 목표가로 쓰이지만 되돌림보다 근거가 더 약하다.

## E-3. 추세선 · 채널

**정의** — 두 개 이상의 고점 또는 저점을 잇는 직선. **가장 오래되고 가장 자의적인 도구**이며, 그 자의성 때문에 계산 기반 대안(선형회귀채널 A-11)이 존재한다.

**계산식**

```
두 점 (x₁,y₁), (x₂,y₂)를 지나는 직선
  기울기 m = (y₂ - y₁) / (x₂ - x₁)
  y = y₁ + m·(x - x₁)

평행 채널: 같은 기울기로 반대편 극값을 지나는 직선 추가
로그 채널: y 대신 log(y)로 계산  ← 크립토 장기 추세에는 필수
```

**파라미터** — 어느 점 두 개를 고를 것인가. **이것이 전부이며 유일한 문제다.**

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 3회 이상 터치 후 유지 | 유효한 추세선 (2점은 우연, 3점부터 의미) |
| 종가 기준 이탈 | 추세 훼손. **꼬리 이탈은 이탈로 치지 않는다** |
| 이탈 후 재테스트 실패 | 역할 전환(지지→저항) 확정 |
| 기울기가 가팔라짐 | 추세 가속 = 지속 불가능 구간 진입 |
| 채널 폭 대비 현재 위치 | 채널 내 상대 위치가 눌림/과열 판단 |

**함정**
1. **사후 편향의 온상이다.** 지나간 차트에서는 어떤 이야기에도 맞는 선을 그을 수 있다. 실시간으로 같은 선을 그었을지가 유일한 검증이다.
2. **꼬리로 그을지 종가로 그을지**에 따라 선이 달라진다. 하나로 고정하라 — 크립토는 위꼬리 스파이크가 잦아 **종가 기준이 안정적**이다.
3. **선형 스케일로 그은 장기 추세선은 크립토에서 무의미하다.** BTC는 지수적으로 움직였으므로 반드시 로그 스케일에서 그을 것.
4. 3점 터치를 억지로 만들려고 선을 미세 조정하는 순간, 그 선은 데이터가 아니라 희망이 된다.

**궁합** — **선형회귀채널(A-11)로 검증하는 것이 최선**이다. 손으로 그은 선이 회귀선과 크게 다르면 그 선은 자의적이다. 프로파일(D-3)·피봇(E-1)과 겹치는 지점만 채택하는 것도 좋은 규율.

**심화**
- 추세선이 작동하는 이유는 **자기실현**이다. 많은 사람이 같은 선을 보고 같은 곳에 주문을 넣기 때문이며, 시장의 어떤 내재적 성질 때문이 아니다. 따라서 **널리 공유된 명백한 선일수록 잘 듣고, 나만 그은 선은 안 듣는다.**
- 크립토는 24시간이라 x축이 달력일이다. 주식의 거래일 기반 추세선과 기울기 의미가 다르며, **주말 구간을 포함하느냐가 기울기를 바꾼다.**

## E-4. 갭 — 그리고 CME 갭

**정의** — 직전 봉 종가와 다음 봉 시가 사이의 **가격 공백**. 거래가 없었던 구간이므로 매물이 없고, 되메우기(fill) 경향이 있다.

**계산식**

```
갭 = (O_t - C_{t-1}) / C_{t-1} × 100      [%]

★ 크립토 현물에는 갭이 없다 — 24시간 무휴장이므로 O_t = C_{t-1}.
   이 문서의 지표 중 크립토에서 구조적으로 무력화되는 유일한 지표다.

★ CME 비트코인 선물에는 갭이 있다
   CME 마감: 금 16:00 CT  /  재개: 일 17:00 CT
   그 사이 현물이 움직인 만큼이 월요일 갭이 된다
   CME 갭 = (월요일 CME 시가 - 금요일 CME 종가) / 금요일 종가
```

**파라미터** — 없음. 갭 크기(%)와 미충족 기간이 관찰 대상.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **CME 갭 발생** | 되메움 확률 높음(역사적으로 대다수 충족) — 다만 **시점은 예측 불가** |
| 갭이 여러 개 누적 미충족 | 아래·위 목표가 후보 다수 존재 |
| 갭 되메움 직후 반등 | 목표 달성 후 방향 재개 |
| 갭 크기가 이례적으로 큼 | 주말 이벤트 발생 — 되메움보다 **원인 확인이 먼저** |

**함정**
1. **"갭은 반드시 메워진다"는 통계가 아니라 서사다.** 대부분 메워지는 것은 사실이지만, **언제**가 빠져 있으면 거래 규칙이 될 수 없다. 몇 달 뒤 메워진 갭으로 지금 포지션을 정당화할 수 없다.
2. **크립토 현물 차트에서 갭을 찾는 것은 무의미하다.** 갭처럼 보이면 그것은 거래소 데이터 결손이거나 캔들 집계 오류다.
3. CME 갭은 **CME 차트에서만** 유효하다. 현물 차트에 CME 갭 선을 그어 놓고 지지·저항으로 쓰는 것은 두 시장의 가격이 다르다는 사실을 무시하는 것이다(베이시스만큼 차이 난다).

**궁합** — 프로파일(D-3, 갭 구간은 정의상 LVN = 매물 공백), 베이시스(F-3, CME와 현물의 가격차 확인)

**심화**
- 갭이 되메워지는 이유는 **그 구간에 매물이 전혀 없기 때문**이다. 거래량 프로파일의 LVN(저거래량 노드)과 정확히 같은 원리이며, 가격이 빠르게 통과하는 성질도 같다. **갭 = 인위적으로 만들어진 LVN**이라고 보면 두 지표가 하나로 연결된다.
- **프로젝트 연결**: `framework/cme-gap-offhours-pump-2026-08-26.md`가 CME 갭과 장외 시간대 펌프의 관계를 다룬다. 이 항목의 판정 규칙은 그 문서의 요약이며, 실제 통계는 그쪽을 참조할 것.

## E-5. 시장 구조 — HH · HL · LH · LL

**정의** — 스윙 고점·저점의 **순서 관계**로 추세를 정의한다. 지표가 아니라 **추세의 정의 그 자체**이며, 다우 이론의 핵심을 형식화한 것.

**계산식**

```
스윙 고점(swing high) : 좌우 k봉보다 높은 고가
스윙 저점(swing low)  : 좌우 k봉보다 낮은 저가

라벨
  HH (Higher High)  = 직전 고점보다 높은 고점
  HL (Higher Low)   = 직전 저점보다 높은 저점
  LH (Lower High)   = 직전 고점보다 낮은 고점
  LL (Lower Low)    = 직전 저점보다 낮은 저점

상승추세 = HH + HL 반복
하락추세 = LH + LL 반복
구조 파괴(BOS/CHoCH) = 상승추세 중 HL이 깨짐 (또는 그 반대)
```

**파라미터** — k(스윙 확인 봉 수) = 3 / 5 / 10. **k가 곧 보는 시간축**이며, k를 바꾸면 구조 전체가 달라진다.

**판정 규칙**

| 구조 | 판정 |
|---|---|
| HH → HL → HH | 상승 추세 유효 |
| **HH 실패(LH 발생)** | 상승 모멘텀 훼손 — 경고 1단계 |
| **직전 HL 하향 이탈** | **구조 파괴(Break of Structure).** 추세 전환 확정 — 경고 2단계 |
| LL → LH → LL | 하락 추세 유효 |
| 직전 LH 상향 돌파 | 하락 구조 파괴 |
| 라벨이 뒤섞임 | 구조 없음 = 횡보 |

**함정**
1. **스윙 확인에는 k봉의 지연이 내재한다.** 스윙 고점은 k봉이 지나야 확정되므로, 실시간으로는 항상 "아직 확정 안 된 고점"을 다루게 된다. 이 지연을 인정하지 않으면 사후 편향에 빠진다.
2. **k를 바꿔가며 원하는 구조를 찾는 것**이 가장 흔한 오용이다. k를 먼저 고정하고 구조를 읽어라.
3. 크립토의 위꼬리 스파이크가 가짜 스윙 고점을 만든다. **종가 기준 스윙**을 병용하면 안정적이다.
4. "구조 파괴 = 즉시 반대 진입"이 아니다. 구조 파괴는 **기존 추세의 종료**를 말할 뿐 새 추세의 시작을 보장하지 않는다.

**궁합** — 프로파일(D-3)·피봇(E-1)·피보나치(E-2)와 겹치면 강력하다. 구조가 방향을, 레벨 지표가 가격을 준다. ADX(A-6)로 구조의 힘을 확인.

**심화**
- 이 개념이 **모든 추세 지표의 상위 개념**이다. 이동평균 정배열, ADX 상승, MACD 0선 위 — 전부 HH/HL 구조를 각자의 방식으로 근사한 것이다. 지표들이 서로 어긋날 때 구조로 돌아가면 판정이 정리되는 이유.
- 시간축마다 구조가 다르다. 일봉이 상승 구조(HH·HL)인데 4시간봉이 하락 구조(LH·LL)인 것은 모순이 아니라 **눌림목의 정의 그 자체**다. **상위 시간축 구조를 방향으로, 하위 시간축 구조 파괴를 진입 트리거로** 쓰는 것이 표준 조합.
- 크립토 24시간 시장은 세션 경계가 없어 스윙이 임의 시각에 형성된다. 주식처럼 "장중 고점"이 특별한 의미를 갖지 않으므로, **k 기반 프랙탈 정의가 크립토에서 오히려 더 적합**하다.

# F. 크립토 파생 (Crypto Derivatives)

> 이 카테고리는 **주식에는 존재하지 않는 정보 축**이다. A~E가 전부 가격·거래량의 함수인 반면, F는 **포지션의 함수**다. 지표를 겹칠 때 진짜 독립적인 근거는 여기서 나온다.

## F-1. 펀딩비 (Funding Rate)

**정의** — 만기 없는 무기한선물(perpetual)의 가격을 현물에 붙들어 매는 메커니즘. **롱과 숏이 서로에게 직접 지급**하며 거래소는 받지 않는다. 지표로 보면 **레버리지 방향 쏠림의 가격표**다.

**계산식**

```
펀딩비 = 프리미엄지수 + clamp( 이자율 − 프리미엄지수,  −0.05%, +0.05% )

프리미엄지수 = (퍼프 가격 − 현물 지수가) / 현물 지수가  의 시간가중 평균
이자율 = 통상 0.01% / 8시간 (거래소 고정값)

지급:   펀딩비 > 0  →  롱이 숏에게 지급
        펀딩비 < 0  →  숏이 롱에게 지급
지급액 = 포지션 명목가치 × 펀딩비   (증거금이 아니라 명목가치 기준)
```

**파라미터** — 정산 주기: Binance·OKX 8시간(00/08/16 UTC), Bybit 8시간, Hyperliquid **1시간**. **주기가 다르면 절대값 비교 불가** — 반드시 연율 또는 동일 주기로 환산할 것.

```
연율 환산:  8시간 주기  →  × 3 × 365 = × 1,095
            1시간 주기  →  × 24 × 365 = × 8,760
```

**판정 규칙 (8시간 기준)**

| 펀딩비 | 연율 | 판정 |
|---|---|---|
| > +0.05% | > 55% | 극단 과열. 롱 청산 캐스케이드 위험 |
| +0.01 ~ +0.03% | 11~33% | 정상 강세 (기준선 0.01%) |
| ≈ +0.01% | 11% | 중립(거래소 기본값) |
| 0 ~ −0.01% | 0% 이하 | 롱 수요 소멸 |
| **< −0.03%** | < −33% | 숏 과밀. **숏 스퀴즈 연료** — 바닥권에서 반등 촉매가 되는 대표 신호 |

**함정**
1. **펀딩비 자체는 방향 신호가 아니다.** 높은 펀딩이 몇 주간 유지되며 가격이 계속 오르는 경우가 흔하다. **극단값 + 다른 축(OI·CVD)의 확인**이 있을 때만 유의미.
2. **주기 혼동**이 가장 잦은 실수. Hyperliquid 0.01%/1h는 Binance 0.01%/8h의 **8배**다.
3. 명목가치 기준 지급이므로 **10배 레버리지면 증거금 대비 실질 비용도 10배**다. 장기 보유 시 캐리 비용이 수익을 잠식한다.
4. 거래소별 펀딩 차이는 차익거래 기회이자, **단일 거래소 펀딩으로 시장 전체를 판단하면 안 되는 이유**다.

**궁합** — **OI와 반드시 쌍으로**(F-2). 베이시스(펀딩은 단기 심리, 베이시스는 수개월 자금의 태도). CVD.

**심화**
- 펀딩비는 **퍼프 시장의 무위험이자율 대리 변수**다. 현물을 사고 퍼프를 숏치면(캐시앤캐리) 방향 위험 없이 펀딩을 수취한다. 연율 펀딩이 미국채 수익률을 크게 웃돌면 이 차익 자금이 유입돼 펀딩을 자동으로 눌러준다 — **펀딩비가 무한정 높게 유지될 수 없는 구조적 이유.**
- clamp 구간(±0.05%)은 프리미엄이 극단으로 갈 때 펀딩이 폭주하지 않도록 잡은 안전장치다. 이 상한에 붙어 있다는 것 자체가 극단 신호다.
- **이 프로젝트 연결**: `automation/btc-desk-template.html`이 24회 평균 펀딩 0.012%를 "과열" 임계로 쓰고 있다(연율 약 13%). 위 표의 기준선과 정합적이다.

## F-2. 미결제약정 (Open Interest, OI)

**정의** — 청산되지 않고 살아 있는 **계약의 총 수**. 거래량이 "얼마나 손바뀜했나"라면 OI는 **"얼마가 아직 시장에 걸려 있나"**다. 새 포지션이 생기면 늘고, 정리되면 준다.

**계산식**

```
OI = 미청산 계약 수  (또는 명목가치 = 계약수 × 가격)

⚠ 명목가치 OI는 가격이 오르기만 해도 증가한다.
   포지션 변화를 보려면 반드시 코인 수량 기준 OI를 쓸 것.

ΔOI% = (OI_t / OI_{t-n} − 1) × 100
```

**⭐ 판정 규칙 — 가격·OI 4분면**

| 가격 | OI | 판정 | 함의 |
|---|---|---|---|
| ↑ | ↑ | **신규 롱 진입** | 추세에 새 자금. 단 아래에 청산 연료 축적 |
| ↑ | ↓ | **숏 커버링** | 숏이 항복해서 오르는 것 — **지속력 약함** |
| ↓ | ↑ | **신규 숏 진입** | 하락에 새 자금. 숏 스퀴즈 연료도 동시 축적 |
| ↓ | ↓ | **롱 청산** | 포지션 소각. 하락 마무리 국면일 수 있음 |

| 조건 | 판정 |
|---|---|
| 가격 상승 + OI 정체 | **현물 주도 상승** — 되돌림 얕고 상승 속도 느림 |
| 가격 상승 + OI 급증 + 펀딩 상승 | **레버리지 주도 상승** — 가장 위험한 조합 |
| 가격이 오른 시간대에도 OI 감소 | **소진 국면** — 오를 때조차 신규 자금이 없음 |

**함정**
1. **OI 증가 = 강세가 아니다.** 롱이 늘었는지 숏이 늘었는지 OI만으로는 알 수 없다. **반드시 가격 방향과 함께** 4분면으로 읽어야 한다.
2. **명목가치 vs 코인 수량** 혼동. BTC가 10% 오르면 명목 OI도 10% 오른다 — 포지션은 그대로인데.
3. **집계 범위 문제.** CoinGlass의 거래소별 OI는 그 거래소의 **전 BTC 계약 합산**이라 단일 심볼 API 값과 직접 비교하면 안 된다(`framework/exchange-api-access-matrix.md` 3절 실측 확인 사항).
4. 코인마진(inverse) 계약과 USDT마진 계약은 성격이 다르다. 코인마진 OI 증가는 **BTC 보유자의 헤지**인 경우가 많다.

**궁합** — 펀딩비(F-1)와 **반드시 쌍**. CVD(신규 진입의 방향), 청산 히트맵, 베이시스.

**심화**
- OI는 **제로섬 시장의 총 노출 규모**다. 모든 롱에는 숏이 있으므로 OI 자체에 방향성이 없다 — 방향은 오직 가격과의 조합, 그리고 롱/숏 계정 비율에서 나온다.
- **OI/시가총액 비율**은 시장 레버리지의 구조적 수준을 재는 지표다. 이 비율이 역사적 고점이면 작은 충격에도 캐스케이드가 발생한다.
- **청산 캐스케이드의 물리학**: OI가 높고 펀딩이 한쪽으로 극단이면, 반대 방향 움직임 → 강제청산 → 시장가 주문 → 가격 추가 이동 → 다음 청산의 자기강화 루프가 돈다. **OI는 이 루프의 연료량을 재는 지표다.** 이것이 F 카테고리 전체에서 가장 실전적인 통찰이다.
- **이 프로젝트 연결**: `automation/btc-desk-build.py`가 이미 OKX·Hyperliquid에서 OI 시계열을 수집하고, 상승 시간대/하락 시간대 평균 ΔOI를 분리 계산해 "소진 국면"을 판정하고 있다. 위 4분면이 그 판정 로직의 이론적 근거다.

## F-3. 선물 베이시스 ⭐

**정의** — 선물 가격과 현물 가격의 차이. **연율화하면 곧 레버리지 롱 수요의 이자율**이 된다. 펀딩비(F-1)가 며칠짜리 심리라면 베이시스는 **몇 달짜리 자금의 태도**다.

**계산식**

```
단순 베이시스 = (선물가 - 현물가) / 현물가 × 100        [%]

연율 베이시스 = (선물가/현물가 - 1) × (365 / 만기까지 일수) × 100

기간구조(term structure) = 만기별 연율 베이시스를 나열
  콘탱고(정상)     : 만기가 멀수록 연율 베이시스 상승
  백워데이션(역전) : 선물 < 현물 → 연율 음수
```

**파라미터** — 만기 선택. 1~4개월물의 연율 평균이 **레짐 판정의 표준 구간**이다. 초단기물은 노이즈, 초장기물은 유동성 부족.

**판정 규칙**

| 연율 베이시스 | 판정 |
|---|---|
| **> 15%** | 과열. 캐리 트레이드가 몰림 = 레버리지 롱 포화 |
| **5 ~ 10%** | 중립. 정상적인 자금조달 비용 |
| 0 ~ 5% | 투기 수요 위축 |
| **< 0 (백워데이션)** | 투기 수요 소멸 또는 현물 부족. **역사적 바닥권 신호** |
| 근월물만 급등 | 단기 이벤트 베팅 |
| 기간구조 전체 상승 | 구조적 강세 자금 유입 |

**함정**
1. **펀딩비와 같이 보되 혼동하지 말 것.** 펀딩은 8시간 단위 심리, 베이시스는 만기까지의 자금 비용이다. 펀딩이 극단인데 베이시스가 중립이면 **단기 투기이지 구조적 강세가 아니다.**
2. **연율화를 빼먹으면 만기 간 비교가 불가능하다.** 1개월물 1%와 3개월물 1%는 완전히 다른 상태다.
3. CME 베이시스와 거래소 베이시스는 다르다. **CME는 규제권 기관 자금**, 거래소는 글로벌 투기 자금 — 둘이 벌어지는 것 자체가 정보다.
4. 백워데이션은 강세 신호로 자주 인용되지만, **현물 조달 스트레스(거래소 인출 급증 등)일 수도 있다.** 원인 확인 없이 바닥 신호로 읽지 말 것.

**궁합** — **펀딩비(F-1) · OI(F-2)와 3종 세트**다. 셋이 같은 방향을 가리키면 레버리지 상태 판정이 확정된다. 스테이블코인 순증(G-5)과 겹치면 "자금이 들어와서 오르는가, 레버리지로 오르는가"가 갈린다.

**심화**
- 연율 베이시스는 **크립토 시장의 무위험 이자율**이다. 현물 매수 + 선물 매도(캐시앤캐리)로 만기까지 확정 수익을 얻을 수 있으므로, 이 값이 미국채 수익률을 크게 웃돌면 차익 자금이 유입돼 베이시스를 눌러준다 — **베이시스가 무한정 높게 유지될 수 없는 구조적 이유**이며 펀딩비와 완전히 같은 메커니즘이다.
- 베이시스 급락은 **캐리 트레이드 청산**을 의미한다. 현물을 팔고 선물 숏을 커버하는 과정에서 현물에 매도 압력이 발생하므로, **베이시스 붕괴는 그 자체로 현물 하락 요인**이 된다.
- **프로젝트 연결**: `framework/perp-basis-regime-2026-09-01.md`와 `automation/btc-desk-template.html`이 1~4개월물 연율 평균을 계산하며 **5~10%를 중립, 15% 이상을 과열**로 판정한다. 위 표가 그 임계와 정합한다.

## F-4. 옵션 25델타 스큐

**정의** — 같은 만기의 **25델타 풋 IV와 25델타 콜 IV의 차이**. 시장이 상방과 하방 중 어느 쪽 보험에 더 값을 치르는지를 하나의 숫자로 보여준다.

**계산식**

```
25Δ 스큐 = IV(25Δ 풋) - IV(25Δ 콜)          [%p]

델타 25 = 대략 행사가가 현재가에서 ±(약 10~20%) 떨어진 외가격 옵션
        (만기·변동성에 따라 거리는 달라진다)

양수 → 풋이 비싸다 = 하방 헤지 수요
음수 → 콜이 비싸다 = 상방 투기 수요
```

**파라미터** — 만기 7일 / 30일 / 90일. **30일이 표준**이며 만기가 짧을수록 변동이 크다.

**판정 규칙**

| 25Δ 스큐 | 판정 |
|---|---|
| **> +8%p** | 하방 공포 극단. 역발상 매수 후보 구간 |
| +2 ~ +5%p | 정상. **크립토 기본 상태는 약한 양수** |
| ≈ 0 | 중립 |
| **< −3%p** | 콜이 더 비쌈 = 상방 투기 과열. **감마 스퀴즈 소지 + 고점권 경고** |
| 급격한 양수 전환 | 헤지 수요 급증 — 무언가를 대비하는 중 |
| 만기별 스큐 역전 | 단기 이벤트 리스크 집중 |

**함정**
1. **스큐는 방향 예측이 아니라 보험료 비교다.** 풋이 비싸다는 것은 하락 예측이 아니라 **하락에 대비한 수요가 많다**는 뜻이며, 이미 헤지된 시장은 오히려 덜 떨어지기도 한다.
2. **크립토 스큐의 중립점은 0이 아니다.** 주식(SPX)은 구조적으로 강한 양의 스큐지만 크립토는 상방 투기 수요 때문에 0 근처이거나 음수인 기간이 길다 — **주식 감각으로 읽으면 안 된다.**
3. Deribit이 사실상 유일한 유동성 소스다. **단일 거래소 지표**임을 감안할 것.
4. 25델타의 실제 행사가는 변동성에 따라 이동한다. 스큐 값 비교 시 **행사가 거리가 같지 않다**는 점에 유의.

**궁합** — **DVOL(F-5)과 쌍**이다. DVOL이 변동성의 수준, 스큐가 그 변동성의 방향 편향. 펀딩(F-1)·OI(F-2)와 겹치면 파생 시장 전체의 포지션 지도가 완성된다.

**심화**
- 스큐가 음수(콜이 비쌈)인 상태에서 가격이 오르면 **딜러가 콜을 숏한 채로 감마 헤지**하느라 상승을 증폭시킨다(감마 스퀴즈). 크립토 급등의 마지막 구간에서 자주 관찰되는 구조이며, **스큐 음수 + OI 급증은 상방 캐스케이드의 조건**이다 — 청산 캐스케이드의 거울상.
- 스큐는 **옵션 시장 참여자의 비대칭 인식**을 재는 것이지, 그들이 옳다는 뜻이 아니다. 극단 스큐가 역발상 지표로 쓰이는 이유가 여기 있다.
- **프로젝트 연결**: `automation/btc-desk-template.html` 8절이 25Δ 스큐와 풋/콜 OI 비율을 표시하며, 양수를 "하방 헤지 수요", 음수를 "상방 수요·감마 스퀴즈 소지"로 해석한다.

## F-5. DVOL — 내재변동성 지수

**정의** — Deribit Volatility Index. **옵션 시장이 앞으로 30일간 예상하는 연율 변동성**. 주식의 VIX에 해당하는 크립토판 공포지수.

**계산식**

```
DVOL = 30일 만기 옵션들의 IV를 행사가 전체에 걸쳐 가중평균한 값 (연율 %)
       VIX와 유사한 분산 스왑(variance swap) 방식

비교 짝:  HV(C-5) 30일 = 지나간 30일의 실현변동성
         DVOL      = 앞으로의 30일 예상변동성

변동성 위험 프리미엄(VRP) = DVOL - HV
```

**파라미터** — 30일 고정.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **DVOL ≫ HV** | 옵션이 비싸다 = 공포 프리미엄. 옵션 매도 우위 |
| **DVOL < HV** | 옵션이 싸다 = **시장이 방심 중.** 옵션 매수 우위, 동시에 경계 신호 |
| DVOL 역사적 저점 | 변동성 압축. 방향 불문 확장 임박 |
| DVOL 급등 | 이미 사건 발생 — 후행 확인 |
| DVOL 급등 후 하락 | 패닉 소화. 통상 반등 국면 |
| DVOL 낮은데 OI 높음 | **가장 위험한 조합** — 레버리지는 쌓였는데 보험은 안 샀다 |

**함정**
1. **DVOL은 방향을 모른다.** 상승 예상이든 하락 예상이든 오른다 — ATR의 옵션 버전이다.
2. **"낮으면 안전"이 아니다.** 낮은 DVOL은 시장이 방심했다는 뜻이며, 역사적으로 급락 직전에 저점인 경우가 많다. 이 프로젝트의 `framework/weekly-semi-brief-*`가 COR1M·VXN에 대해 반복해 지적하는 것과 같은 구조 — **낮은 변동성은 안전판이 아니라 화약**이다.
3. Deribit 단일 시장 기반이며 미국 상장 옵션·CME 옵션과는 다를 수 있다.
4. HV와 비교할 때 **연율화 규약을 맞출 것**(Deribit은 365일 기준).

**궁합** — **HV(C-5)와 쌍이 본체.** 25Δ 스큐(F-4)가 방향 편향을 더한다. 볼린저 밴드폭(C-2)은 실현변동성 대리이므로 DVOL과 비교하면 같은 대조를 무료로 할 수 있다.

**심화**
- DVOL − HV(변동성 위험 프리미엄)는 **장기적으로 양수인 것이 정상**이다. 보험은 원래 기댓값보다 비싸다. 이 프리미엄이 음수로 뒤집히는 구간은 시장이 실현 변동성을 체계적으로 과소평가하는 드문 상태이며, 옵션 매수의 통계적 우위 구간이다.
- VIX와 달리 **크립토 DVOL의 절대 수준이 훨씬 높다**(BTC 40~80% vs SPX 12~25%). 자산 간 절대값 비교는 무의미하고, **자기 이력 대비 백분위**로 읽어야 한다.
- 변동성이 압축될 때 DVOL·볼린저폭·ATR·CHOP이 동시에 극단으로 간다. **네 지표가 동시에 신호를 줄 때가 스퀴즈의 가장 강한 형태**이며, 각각은 같은 현상의 다른 측면이지 독립 근거 4개가 아니다.

## F-6. 롱숏 비율

**정의** — 롱 포지션과 숏 포지션의 비율. **계정 수 기준**과 **포지션 규모 기준**이 완전히 다른 이야기를 한다.

**계산식**

```
계정 기준   = 롱 계정 수 / 숏 계정 수                  ← 개미 심리
포지션 기준 = 롱 포지션 명목가치 / 숏 명목가치
상위 트레이더 = 상위 계정만 집계                        ← 큰손 편향

Binance 제공
  /futures/data/globalLongShortAccountRatio   (전체 계정)
  /futures/data/topLongShortPositionRatio     (상위 트레이더 포지션)
  /futures/data/takerlongshortRatio           (테이커 체결 비율)
```

**파라미터** — 집계 주기 5분/1시간/1일. 거래소별 정의가 달라 **절대값 비교 불가, 추이만**.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 전체 계정 롱 비율 극단 고점 | 개미 롱 쏠림 — **역발상 하방 경계** |
| **전체 계정과 상위 트레이더가 반대** | 가장 유용한 신호. 큰손과 개미가 갈림 |
| 상위 트레이더 숏 증가 + 가격 상승 | 헤지일 수도, 선행일 수도 — OI로 구분 |
| 비율이 중립 근처 | 정보 없음 |
| 급격한 비율 전환 | 청산 발생 후 강제 리밸런싱 |

**함정**
1. **롱과 숏의 총량은 항상 같다.** 모든 롱에는 숏이 있다 — 비율이 1에서 벗어나는 것은 **계정 수** 또는 **표본 정의** 때문이지 시장이 한쪽으로 기울어서가 아니다. 이 사실을 모르면 지표 전체를 오독한다.
2. **거래소마다 정의가 다르다.** 계정 기준인지 명목가치 기준인지, 상위 몇 %인지 확인 없이 숫자를 인용하면 안 된다.
3. 상위 트레이더의 숏은 **현물 보유에 대한 헤지**인 경우가 많다. 방향 베팅으로 읽으면 틀린다.
4. **자동 수집이 어렵다.** Binance 관련 엔드포인트는 클라우드에서 451 지역차단이라 브라우저 경유 수동 수집만 가능하다(`framework/exchange-api-access-matrix.md` 참조).

**궁합** — **OI(F-2)·펀딩(F-1)과 함께**여야 의미가 산다. 롱숏 비율이 극단인데 OI가 늘고 펀딩이 높으면 실제 쏠림이고, OI가 안 늘면 계정 수 착시다.

**심화**
- 이 지표의 진짜 정보는 수준이 아니라 **표본 간 괴리**다. 전체 계정은 롱인데 상위 트레이더는 숏인 상태가 반복적으로 관찰되는 구간은, 소액 계정이 다수이고 대형 계정이 반대편을 잡고 있다는 뜻이다 — **계정 수와 자본 규모의 분리**를 보여주는 유일한 지표.
- 테이커 매수/매도 비율(F-7)이 **흐름**이라면 롱숏 비율은 **잔고**다. 흐름과 잔고를 같이 봐야 "지금 누가 어느 방향으로 움직이는가"와 "누가 어느 방향에 서 있는가"가 모두 보인다.

## F-7. 테이커 매수/매도 비율

**정의** — 시장가로 **공격적으로 체결한** 매수 물량과 매도 물량의 비율. CVD(D-4)를 비율 형태로, 누적이 아니라 기간별로 본 것.

**계산식**

```
테이커 비율 = Σ(테이커 매수 거래량) / Σ(테이커 매도 거래량)

> 1  : 시장가 매수가 우세 (공격적 매수)
< 1  : 시장가 매도가 우세

관계:  CVD 델타 = 테이커매수 - 테이커매도 (차이, 누적형)
       테이커 비율 = 테이커매수 / 테이커매도 (비율, 유계형)
```

**파라미터** — 집계 주기 5분/1시간/1일.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 비율 > 1.15 지속 | 공격적 매수 우위 |
| 비율 < 0.85 지속 | 공격적 매도 우위 |
| **비율 > 1 인데 가격 하락** | 흡수. 시장가 매수를 지정가 매도벽이 받아냄 = **약세** |
| **비율 < 1 인데 가격 상승** | 역흡수. 매도를 매수벽이 받아냄 = **강세** |
| 비율 극단 + OI 급증 | 신규 레버리지 진입 — 청산 연료 축적 |

**함정**
1. **테이커 우세 = 상승이 아니다.** 위 표의 흡수 케이스가 정확히 그 반례이며, 오히려 이 어긋남이 이 지표의 존재 이유다.
2. **메이커 물량은 안 보인다.** 대형 참여자는 지정가로 조용히 채우므로 이 지표에 반대 부호로 잡히거나 안 잡힌다.
3. 청산 물량이 테이커로 집계된다. **캐스케이드 구간의 극단값은 심리가 아니라 강제 실행**이다.
4. 현물과 파생을 섞으면 안 된다. 파생 테이커 비율은 레버리지 회전이지 자금 유입이 아니다.

**궁합** — **CVD(D-4)와 같은 정보의 다른 표현**이므로 둘 다 띄우는 것은 중복이다. 하나를 고르되, **알림·자동화에는 비율(유계)이, 시각적 다이버전스 판독에는 CVD(누적)가** 적합하다. OI(F-2)와 겹쳐야 신규 진입인지 청산인지 구분된다.

**심화**
- 테이커는 **유동성을 소비**하고 메이커는 **공급**한다. 테이커 비율은 결국 "어느 쪽이 급했는가"를 재는 것이며, **급한 쪽이 반드시 옳은 쪽은 아니다** — 흡수 신호가 작동하는 이유.
- 유계 지표라는 점이 실무적으로 중요하다. CVD는 절대값이 무의미해 임계 알림을 걸 수 없지만, 테이커 비율은 `> 1.2` 같은 고정 임계로 자동화에 넣을 수 있다. `automation/coin-alert-check.py` 계열에 파생 조건을 추가한다면 이쪽이 적합한 형태다. **(부록 4 권장 4번 — 아직 미처리)**

# G. 온체인 (On-chain)

> 이 카테고리는 **거래소 밖의 데이터**다. A~F가 전부 시장(가격·거래량·포지션)의 함수인 반면, G는 **블록체인 원장 자체**를 읽는다. 주식에는 대응물이 없으며, 크립토에서만 가능한 관측이다. 공통 한계: **느리다.** 온체인 지표는 며칠~몇 주 단위이며 단기 트레이딩 신호가 아니다.
>
> G-1~G-5는 **보유자(수요측)**를, G-7~G-8은 **채굴자(공급측)**를 본다. G-6은 G-1의 다른 좌표계다.

## G-1. MVRV

**정의** — Market Value to Realized Value. **시가총액 ÷ 실현시가총액**. 전체 보유자의 평균 미실현 손익 배수이며, 사이클 위치 판정의 대표 지표.

**계산식**

```
시가총액(MV)     = 현재가 × 유통량
실현시총(RV)     = Σ (각 UTXO의 마지막 이동 시점 가격 × 수량)
                   = "모든 코인을 마지막에 움직인 가격으로 평가한 총액"

MVRV = MV / RV  =  현재가 / 실현가격(G-3)

MVRV-Z = (MV - RV) / MV의 표준편차      ← 사이클 비교용 정규화 버전
```

**파라미터** — 없음. 파생형으로 MVRV-Z, 단기보유자(STH) MVRV, 장기보유자(LTH) MVRV가 있으며 **STH-MVRV가 단기 판정에 더 유용**하다.

**판정 규칙**

| MVRV | 판정 |
|---|---|
| **> 3.5** | 역사적 과열. 사이클 고점권 |
| 2.0 ~ 3.5 | 강세장 진행 |
| 1.0 ~ 2.0 | 중립~회복 |
| **< 1.0** | 전체 보유자 평균이 손실. **역사적 바닥권** |
| STH-MVRV < 1 | 단기 보유자가 물림 = 항복 구간 |
| MVRV 하락 반전 (고점권에서) | 분배 국면 진입 |

**함정**
1. **매우 느리다.** 사이클 단위 지표이며 주·월 단위로 움직인다. 단기 매매 신호로 쓰면 안 된다.
2. **임계값이 사이클마다 낮아지고 있다.** 시장이 성숙하며 과열 임계가 하향 이동 중이므로, 과거 사이클의 3.5를 그대로 적용하면 신호가 안 나온다.
3. **ETF·거래소 내부 이동이 실현가격을 왜곡**한다. ETF 커스터디 재편 같은 대량 온체인 이동이 실제 매매 없이 RV를 바꾼다 — 2024년 이후 특히 심해진 문제.
4. 유통량 정의(소실 코인 포함 여부)에 따라 값이 달라진다.

**궁합** — 실현가격(G-3)이 분모 그 자체이고 **NUPL(G-6)은 단조변환**이므로, 셋은 같은 지표의 세 표현이다. SOPR(G-2)과 조합하면 "평균 손익 상태 + 실제 실현 여부"가 함께 보인다. 앵커드 VWAP(D-2)이 시장 버전의 같은 개념.

**심화**
- MVRV의 분모 RV는 **전체 시장의 앵커드 VWAP**과 개념적으로 같다. D-2에서 앵커드 VWAP을 "사건 이후 진입한 전체 참여자의 평균 단가"로 정의했는데, RV는 **모든 코인에 대해 각자의 마지막 이동 시점을 앵커로 잡은 것**이다.
- MVRV = 1은 "시장 전체가 본전"이라는 뜻이며, 역사적으로 이 선이 강력한 심리적 바닥이었던 이유는 그 아래에서 평균적 보유자가 손실을 확정해야 팔 수 있기 때문이다.

---

## G-2. SOPR

**정의** — Spent Output Profit Ratio. **오늘 실제로 움직인 코인들이 이익 실현인가 손실 확정인가.** MVRV가 잠재 손익이라면 SOPR은 **실현된 손익**이다.

**계산식**

```
SOPR = Σ(이동된 코인의 현재 가격) / Σ(그 코인들이 마지막에 움직였을 때 가격)

= 오늘 움직인 코인의 평균 매도 배수

SOPR > 1 : 평균적으로 이익 실현
SOPR = 1 : 본전
SOPR < 1 : 손실 확정

aSOPR  : 1시간 미만 이동(거래소 내부 이동 등) 제외
STH-SOPR : 155일 미만 보유 코인만
LTH-SOPR : 155일 이상 보유 코인만
```

**파라미터** — 155일(단기/장기 구분선)은 통계적으로 코인이 재이동될 확률이 급락하는 지점에서 왔다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **강세장에서 SOPR이 1을 지지** | 건강한 추세. 손실 확정 물량이 안 나옴 |
| **강세장에서 SOPR이 1 하향 이탈** | **경고.** 사람들이 손실을 감수하고 팔기 시작 |
| 약세장에서 SOPR이 1에서 저항 | 본전 오면 파는 국면 = 반등 제한 |
| **SOPR 극단 저점(0.9 이하)** | 항복(capitulation). 역사적 바닥 구간 |
| LTH-SOPR 급등 | 장기 보유자 분배 시작 — 사이클 고점 신호 |

**함정**
1. **1 근처에서의 미세한 등락은 노이즈다.** 하루 값이 0.99인지 1.01인지에 의미를 부여하지 말 것 — 며칠~몇 주 평활해서 볼 것.
2. **거래소 내부 이동이 값을 오염시킨다.** 반드시 aSOPR(1시간 미만 제외)을 쓸 것.
3. MVRV와 마찬가지로 **ETF 커스터디 재편**이 대량의 가짜 신호를 만든다.
4. 단기 트레이딩 신호가 아니다.

**궁합** — MVRV(G-1)와 **쌍**이다. MVRV는 "얼마나 물려 있나", SOPR은 "실제로 팔고 있나". 거래소 준비금(G-4)과 겹치면 "팔려고 옮기는 중인가"까지 확인된다.

**심화**
- SOPR의 1 지지/저항은 **가장 순수한 형태의 본전 심리**다. 기술적 지지선이 아니라 **실제 원장에 기록된 매입가**에서 나오는 선이라는 점에서, 이 문서의 어떤 레벨 지표(E)보다도 근거가 실재적이다.
- STH-SOPR과 LTH-SOPR의 **분기**가 사이클 전환의 전형적 서명이다. 장기 보유자가 팔기 시작(LTH-SOPR 급등)하는데 단기 보유자가 받는(STH 물량 증가) 구조가 사이클 고점에서 반복 관측된다.

## G-3. 실현가격

**정의** — Realized Price. **실현시가총액 ÷ 유통량.** 모든 코인의 마지막 이동 가격의 가중평균, 즉 **시장 전체의 평균 매입 단가**다.

**계산식**

```
실현가격 = 실현시가총액(RV) / 유통량
         = Σ(각 코인의 마지막 이동 가격 × 수량) / Σ수량

관계:  MVRV = 현재가 / 실현가격
       현재가 = 실현가격  ⟺  MVRV = 1

파생
  STH 실현가격 : 155일 미만 보유 코인의 평균 단가 ← 단기 지지선으로 유용
  LTH 실현가격 : 155일 이상 보유 코인의 평균 단가
```

**파라미터** — 없음. 코호트(전체 / STH / LTH) 선택이 유일한 자유도.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 가격 > 실현가격 | 시장 전체가 평균 이익 |
| **가격이 실현가격 하향 이탈** | 시장 전체가 평균 손실 = **역사적 바닥 구간 진입** |
| **STH 실현가격** | 강세장의 **1차 지지선**으로 반복 작동 |
| 실현가격 상승 중 | 신규 자금이 높은 가격에 유입 중 |
| 실현가격 정체 | 코인 이동 없음 = 홀딩 국면 |

**함정**
1. **지지선처럼 그리되 기술적 지지선이 아니다.** 매물이 쌓인 가격대가 아니라 평균값이므로, "닿으면 튄다"가 아니라 "그 아래는 통계적으로 드물다"에 가깝다.
2. 소실 코인(잃어버린 키)이 포함되어 실현가격을 **아래로 끌어내린다.** 초기 저가 코인들이 영원히 분모에 남는다.
3. ETF 도입 이후 커스터디 이동이 실현가격을 인위적으로 끌어올리는 구간이 생겼다.

**궁합** — MVRV(G-1)·NUPL(G-6)과 **같은 지표의 다른 표현**이므로 셋 다 볼 필요 없다. 앵커드 VWAP(D-2)과 겹쳐 보면 "온체인 평균 단가 vs 거래소 평균 단가"의 괴리가 보인다.

**심화**
- 실현가격은 **온체인판 앵커드 VWAP**이다. D-2의 앵커드 VWAP이 특정 사건 이후 거래소에서 체결된 평균 단가라면, 실현가격은 **각 코인이 자기 앵커를 갖는** 형태다. 두 값이 크게 벌어지면 거래소 밖(장외·OTC·커스터디)에서 대량 이동이 있었다는 뜻.
- STH 실현가격이 강세장 지지선으로 잘 작동하는 이유는 **최근 매수자의 평균 본전선**이기 때문이다. 그 아래로 가면 최근 진입자 전체가 손실이 되어 항복 물량이 나온다 — SOPR(G-2)의 1 이탈과 같은 사건을 가격 축에서 본 것.

## G-4. 거래소 준비금

**정의** — 거래소 지갑이 보유한 코인의 총량. **매도 가능한 물량의 대리 지표**이며, 감소는 자가수탁 이동(강세), 증가는 매도 준비(약세)로 해석된다.

**계산식**

```
거래소 준비금 = Σ (라벨링된 거래소 지갑 주소들의 잔고)

순유입 = 거래소 유입 - 거래소 유출
  순유입 > 0 → 준비금 증가 → 매도 압력 잠재
  순유입 < 0 → 준비금 감소 → 자가수탁 이동
```

**파라미터** — 없음. 다만 **주소 라벨링 품질이 지표 품질을 결정**한다(Glassnode·CryptoQuant·Nansen이 서로 다른 값을 낸다).

**판정 규칙**

| 조건 | 판정 |
|---|---|
| 준비금 지속 감소 | 공급 축소. 구조적 강세 |
| **급격한 유입 급증** | 매도 준비 — **가장 실전적인 단기 경고** |
| 급락 중 유입 급증 | 항복 매도 진행 중 |
| 준비금 감소 + 가격 정체 | 조용한 매집 |
| ETF 커스터디로 이동 | **해석 주의** — 매도가 아니라 보관처 변경 |

**함정**
1. **ETF 시대에 해석이 크게 흔들렸다.** 거래소 → ETF 커스터디 이동은 준비금 감소로 잡히지만 실제 수급 의미는 다르다. 2024년 이후 이 지표 단독 해석은 위험하다.
2. **라벨링 오류·거래소 내부 지갑 재편**이 대규모 가짜 신호를 만든다. 하루짜리 급변은 대개 지갑 재편이다.
3. 준비금 감소가 반드시 강세는 아니다. **거래소 신뢰 위기(FTX형 인출 러시)** 로도 감소한다 — 원인 확인 필수.
4. 파생 거래소 담보로 예치된 코인도 준비금에 잡힌다. 매도 가능 물량이 아니라 증거금인 경우가 많다.

**궁합** — SOPR(G-2)·MVRV(G-1)와 조합해 "옮겼는데 이익인가 손실인가"를 확인. **스테이블코인 순증(G-5)과 짝**이면 "코인이 나가고 달러가 들어오는가"의 양방향이 보인다.

**심화**
- 준비금 변화는 **의도의 대리 지표일 뿐 실행이 아니다.** 거래소로 옮겼다고 반드시 팔지 않으며, 옮기지 않고도 파생으로 헤지할 수 있다. **파생 시장이 커질수록 이 지표의 설명력은 구조적으로 약해진다.**
- **프로젝트 연결**: `framework/liquidity-gauges-guide.md`가 스테이블코인 거래소 준비금(약 $64B, 고점 대비 −20%)을 "매수 화력"의 지표로 쓰고 있다. 코인 준비금이 **매도 화력**이라면 스테이블 준비금은 **매수 화력**이며, 둘을 같이 봐야 수급의 양변이 완성된다.

## G-5. 스테이블코인 순증

**정의** — 달러 스테이블코인 총 공급의 변화. **크립토 내부의 M2**이며, 법정화폐가 크립토 계좌 안으로 들어온 총량을 잰다.

**계산식**

```
총 공급 = Σ (USDT, USDC, DAI, ... 각 체인별 발행량)
순증(주간) = 총공급_t - 총공급_{t-7일}

구분해야 할 두 가지
  총 공급        = 크립토 안에 있는 달러의 총량
  거래소 준비금  = 그중 실제로 즉시 매수에 쓸 수 있는 부분  ← 이쪽이 진짜 화력
```

**파라미터** — 없음. 집계 주기 주간/30일.

**판정 규칙**

| 주간 순증 | 국면 | 알트 시사점 |
|---|---|---|
| **+$4~8B** | 과열 | 알트 랠리 전제조건 충족 |
| **+$1~4B** | 완만한 유입 | 지수는 버티나 확산 제한 |
| ±$1B | 정체 | 기존 자금 내 순환만 |
| **−$1B 이하** | 수축 | 하락 시 받쳐줄 화력 없음 |

| 추가 조건 | 판정 |
|---|---|
| **총 공급은 느는데 거래소 준비금은 감소** | 진짜 매수 화력은 줄고 있음 — **레벨이 아니라 배치를 보라** |
| 전환 확정 조건 | 2주 연속 +$2B **AND** 30일 지표 +1% 초과 |

**함정**
1. **한 주 플러스는 신호가 아니다.** 분기 리밸런싱·대형 민팅 일회성으로도 나온다 — 위 전환 확정 조건을 충족해야 한다.
2. **트래커별 레벨이 $5~15B 다르다.** 체인 커버리지와 브리지 처리가 달라서다 — **레벨이 아니라 변화율로 비교할 것.**
3. **거시 유동성과 혼동하지 말 것.** 스테이블 순증은 크립토 전용 유동성이며, 거시가 좋아도 이게 안 늘면 가격은 못 올라간다. 반대로 이것만 늘고 거시가 나쁘면 크립토 내부 순환에 그친다.
4. 스테이블 발행이 반드시 매수 대기 자금은 아니다. 담보·결제·차익거래 용도가 섞여 있다.

**궁합** — 거래소 준비금(G-4)과 **양변**을 이룬다. 베이시스(F-3)·펀딩(F-1)과 조합하면 "현물 자금으로 오르는가, 레버리지로 오르는가"가 갈린다 — 이 문서 전체에서 가장 중요한 구분 중 하나.

**심화**
- 스테이블코인은 크립토와 전통 금융의 **접점**이다. 발행사가 준비금으로 미국 단기국채를 사므로, 스테이블 공급 증가는 T-bill 수요 증가와 직결된다 — 이 프로젝트의 `macro/tbill-demand-stablecoin.md`가 그 경로를 다룬다.
- 전달 순서상 **가장 후행**이다. 거시 유동성 → 준비금 → 위험자산 → 스테이블 순증 → 알트 확산. 따라서 스테이블 순증은 예측 지표가 아니라 **확산 국면의 확인 지표**로 쓰는 것이 맞다.
- **프로젝트 연결**: `framework/liquidity-gauges-guide.md` 4절과 `macro/stablecoin-netflow-2026-08-25.md`가 위 임계표의 출처이며, 총 공급과 거래소 준비금의 괴리(공급 −5.5% vs 준비금 −20%)를 핵심 관측으로 기록하고 있다.

## G-6. NUPL — 순 미실현 손익

**정의** — Net Unrealized Profit/Loss. 시장 전체의 미실현 손익을 시가총액으로 나눈 비율. **MVRV(G-1)와 같은 두 숫자로 만들며, 배수가 아니라 0을 중심으로 한 비율**이라 사이클 국면에 이름을 붙이기 쉽다.

**계산식**

```
NUPL = (시가총액 MV − 실현시총 RV) / MV

★ MVRV의 단조변환이다 — 독립된 지표가 아니다
   NUPL = 1 − 1/MVRV          MVRV = 1 / (1 − NUPL)

   MVRV 1.0 → NUPL 0.00       MVRV 2.0 → NUPL 0.50
   MVRV 1.5 → NUPL 0.33       MVRV 3.0 → NUPL 0.67
   MVRV 0.8 → NUPL −0.25      MVRV 4.0 → NUPL 0.75

코호트 분해
  LTH-NUPL : 155일 이상 보유분만  ← 사이클 고점 판정
  STH-NUPL : 155일 미만 보유분만  ← 항복 판정
```

**파라미터** — 없음. 유일한 자유도는 코호트(전체 / LTH / STH) 선택이며, **부가가치는 전부 여기서 나온다**(아래 심화).

**판정 규칙**

| NUPL | 국면 (Glassnode 명명) |
|---|---|
| **> 0.75** | 도취(euphoria/greed) — MVRV 4 이상에 해당. 역사적 고점권 |
| 0.5 ~ 0.75 | 확신(belief/denial) — 강세장 본구간 |
| 0.25 ~ 0.5 | 낙관(optimism/anxiety) |
| 0 ~ 0.25 | 희망(hope/fear) — 평균 보유자가 겨우 이익 |
| **< 0** | 항복(capitulation) — 시장 전체가 평균 손실. **MVRV < 1과 동일한 사건** |
| **LTH-NUPL 고점 후 하락** | 장기 보유자 분배 시작 — 전체 NUPL보다 먼저 꺾인다 |

**함정**
1. **MVRV와 독립된 근거가 아니다.** `NUPL = 1 − 1/MVRV`라는 완전한 함수 관계이므로, 둘을 같이 띄우고 "온체인 지표 두 개가 과열을 가리킨다"고 말하는 것은 **같은 숫자를 두 번 세는 것**이다. 이 문서에서 %R ≡ %K − 100(B-5)과 같은 급의 항등이다.
2. **구간 이름은 통계가 아니라 색칠이다.** 0.25 / 0.5 / 0.75 경계는 Glassnode의 시각적 구분에서 왔고 유도 과정이 없다. 사이클마다 도달 고점이 낮아지는 중이라 0.75는 최근 사이클에서 거의 찍히지 않는다.
3. **상단은 1에 막히고 하단은 열려 있다.** 유계처럼 보이지만 비대칭이다 — MVRV가 0.5까지 빠지면 NUPL은 −1이다. "0~1 사이 지표"로 오해하면 하락 구간의 눈금 감각이 통째로 틀어진다.
4. **고배수 구간이 압축된다.** MVRV 2→3의 변화(+1.0배)가 NUPL에서는 0.50→0.67(+0.17)에 불과하다. 과열 구간에서 NUPL이 둔해 보이는 것은 시장이 아니라 **변환 함수의 성질**이다.
5. MVRV·SOPR과 같은 병에 걸린다 — **ETF 커스터디 재편이 RV를 흔들면 NUPL도 같이 흔들린다.**

**궁합** — **MVRV(G-1)·실현가격(G-3)과는 완전 중복**이므로 셋 중 하나만. SOPR(G-2, 실현 손익)과 거래소 준비금(G-4)이 진짜 조합 상대다.

**심화**
- NUPL을 쓸 이유는 정보량이 아니라 **좌표계**다. MVRV는 배수라 "1.8이면 어느 국면인가"가 직관적이지 않지만, NUPL은 0이 본전이라 **부호만 봐도** 시장 전체의 손익 방향을 읽는다. 부록 3의 원칙대로 온체인 축에서는 둘 중 하나만 고르되, 국면에 이름을 붙여 남에게 설명할 일이 많다면 NUPL 쪽이 낫다.
- **코호트 분해가 진짜 부가가치다.** 전체 NUPL은 MVRV의 복사본이지만 LTH-NUPL / STH-NUPL은 다른 정보다 — 장기 보유자가 이익을 안고 분배를 시작하는데 단기 보유자는 손실 구간에 들어가는 **엇갈림**이 사이클 전환의 전형적 서명이며, 전체값에서는 상쇄돼 안 보인다. SOPR의 STH/LTH 분기(G-2 심화)와 정확히 같은 구조를 손익 축에서 본 것.
- **크립토 24시간 시장 특수성** — NUPL은 봉 개념이 없다. 블록 단위로 갱신되는 원장 스냅샷이므로 UTC 경계 논쟁(부록 2-3)에서 자유로운 몇 안 되는 지표다. 대신 벤더가 언제 스냅샷을 뜨는지에 따라 값이 갈리며, **MVRV 벤더 차이를 그대로 물려받는다.**

## G-7. 해시리본 (Hash Ribbons)

**정의** — 해시레이트의 30일·60일 이동평균 교차로 **채굴자 항복과 회복**을 판정한다. Charles Edwards(Capriole, 2019). 이 문서 55종 중 **시장이 아니라 생산 원가 쪽을 보는 지표는 이것과 Puell Multiple(G-8)뿐**이다.

**계산식**

```
해시레이트 HR = 난이도와 실제 블록 간격에서 역산한 추정치
              (직접 관측되는 양이 아니다 — 함정 1 참조)

항복(capitulation) : SMA(HR, 30) < SMA(HR, 60)
회복(recovery)     : SMA30이 SMA60을 상향 재교차
매수 신호(원저자)  : 회복 AND SMA(P, 10) > SMA(P, 20)
                     ↑ 두 조건이 모두 필요하다
```

**파라미터** — 30 / 60 (Edwards 원본). 가격 확인용 10 / 20. **평활 기간이 긴 것은 미학이 아니라 필수**다 — 원계열의 추정 오차가 그만큼 크다.

**판정 규칙**

| 조건 | 판정 |
|---|---|
| **SMA30 < SMA60** | 채굴자 항복 — 한계 채굴기가 꺼지는 중. **진행 중에는 신호가 아니다** |
| **SMA30이 SMA60 상향 재교차** | 회복. 원저자 정의의 1차 조건 |
| 회복 + 가격 SMA10 > SMA20 | **원저자의 완성된 매수 신호** |
| 항복 없이 리본 정배열 유지 | 채굴 경제 정상. **이 지표는 할 말이 없는 상태** |
| **반감 직후 항복** | **가격과 무관한 항복** — 보상이 절반이 된 산술적 결과. 신호로 읽으면 안 됨 |

**함정**
1. **해시레이트는 관측값이 아니라 추정값이다.** 블록 발견은 포아송 과정이라 하루치 추정에 큰 오차가 붙는다. 30·60일 평활은 **원계열을 그대로 쓸 수 없기 때문**이며, 벤더마다 역산 창(1일/3일/7일)이 달라 값이 눈에 띄게 갈린다.
2. **표본이 10여 개다.** "역사적 승률 100%"류의 주장은 비트코인 전 역사에서 신호가 열 몇 번밖에 없었다는 사실 위에 서 있다. **거래 10회짜리 백테스트는 증거가 아니다.**
3. **가격 외 요인이 항복을 만든다.** 반감, 채굴 규제(2021년 중국 금지), 전기료 급등, 신형 ASIC 교체 — 전부 리본을 꺾지만 시장 바닥과는 무관하다. **항복의 원인 확인이 먼저**다.
4. **난이도 조정에 2016블록(약 2주)의 지연**이 있다. 채굴자가 나가도 난이도는 최대 2주 뒤에야 내려가므로, 리본의 반응은 구조적으로 그만큼 늦다.
5. BTC 전용이다. PoS 체인에는 대응물이 없고, 소형 PoW 코인은 해시 임대(NiceHash) 물량이 섞여 의미가 다르다.

**궁합** — **Puell Multiple(G-8)과 짝**이다. 리본은 채굴자의 *생존*, Puell은 *수익* — 같은 축의 다른 면이므로 중복이 아니다. 실현가격(G-3)과 겹치면 "생산 원가 vs 시장 평균 원가"의 두 바닥선이 나온다.

**심화**
- 항복이 바닥과 관계있는 이유는 심리가 아니라 **현금흐름**이다. 채굴자는 전기료를 법정화폐로 내야 하므로 채굴한 코인을 강제로 판다. 한계 채굴기가 꺼지면 그 강제 매도 물량 자체가 사라진다 — **비탄력적 매도자의 소진**을 재는 지표다.
- **ASIC 효율 개선 때문에 해시레이트는 구조적 상승 추세**다. 따라서 리본은 정배열이 기본 상태이고 역배열이 이례다 — RSI처럼 "대역"으로 읽는 지표가 아니라 **사건 탐지기**로 읽어야 한다.
- **크립토 24시간 시장에서 달라지는 점** — 해시레이트에는 휴장도 주말도 없지만 **계절성은 있다.** 중국 우기(쓰촨 수력)나 텍사스 여름 급전 지시(전력망 수요 반응으로 채굴기 정지) 같은 전력 시장 일정이 리본에 그대로 찍힌다. 지리적 채굴 분포가 바뀌면 계절 패턴 자체가 바뀐다는 점에서, 이 지표는 시장이 아니라 **에너지 산업의 달력**을 따른다.

## G-8. Puell Multiple

**정의** — 오늘 채굴된 코인의 달러 가치가 **지난 1년 평균의 몇 배인가.** 채굴자 수익 관점에서 사이클 위치를 재는 지표.

**계산식**

```
일일 발행가치 = 일일 채굴 발행량(BTC) × 가격

Puell Multiple = 일일 발행가치 / SMA(일일 발행가치, 365)

★ 발행량은 고정 스케줄이므로, 반감을 빼면
    Puell ≈ P_t / SMA(P, 365)
  = 가격의 365일 상대 위치. 온체인 지표의 외피를 쓴 장기 모멘텀이다.

⚠ 수수료 수익은 빠져 있다 (coinbase 발행분만)
```

**파라미터** — 365일 고정. **이 창을 줄이면 지표의 정의 자체가 바뀐다**(사이클 위치가 아니라 단기 상대가격이 된다).

**판정 규칙**

| Puell | 판정 |
|---|---|
| **> 4** | 사이클 고점권. 채굴자 수익이 1년 평균의 4배 = 대규모 이익 실현 유인 |
| 1 ~ 4 | 정상 강세 |
| 0.5 ~ 1 | 중립~회복 |
| **< 0.5** | 바닥권. 채굴자 수익 고갈 = 항복 임박 또는 진행 중 |
| **반감 직후 급락** | **신호 아님.** 발행 스케줄의 산술 — 분모가 정상화되는 365일 동안 판정 보류 |
| Puell 저점 + 해시리본 회복 교차 | 공급 측 두 지표의 정렬. 사이클 바닥에서 반복 관측 |

**함정**
1. **반감이 지표를 통째로 왜곡한다.** 분자가 하루 만에 절반이 되므로 Puell도 절반 근처로 떨어진다. 시장이 한 일이 아니라 프로토콜이 한 일이며, 분모의 365일 창이 완전히 갈릴 때까지 **1년간 하향 편향**이 남는다.
2. **수수료 수익이 빠져 있다.** 발행분만 세므로, 수수료 비중이 커지는 국면(오디널스·룬 혼잡기)에서는 채굴자 실제 수익을 과소평가한다. **반감이 거듭될수록 이 결함은 커진다.**
3. **0.5 / 4 임계는 과거 사이클 기준**이며 MVRV(G-1)와 같은 압축을 겪고 있다 — 사이클마다 도달 고점이 낮아져 4는 최근에 거의 찍히지 않는다.
4. **온체인 지표로 세면 안 된다.** 반감을 빼면 가격의 365일 상대 위치와 거의 같으므로 **ROC(B-6)와 같은 축**이다. 부록 3의 "독립 확인" 자리에 놓으면 근거를 중복해서 세게 된다.
5. BTC 전용. 발행 스케줄이 다른 체인에는 임계값을 그대로 옮길 수 없다.

**궁합** — **해시리본(G-7)과 짝**(수익 vs 생존). MVRV(G-1)와는 사이클 위치를 교차확인할 수 있으나 **둘 다 매우 후행**이라는 점을 감안할 것. **ROC(B-6)와는 사실상 같은 축이므로 중복.**

**심화**
- 이 지표의 실제 가치는 수준이 아니라 **채굴자 관점의 번역**에 있다. 같은 "가격이 1년 평균의 0.5배"라도, Puell로 말하면 "채굴자가 1년 평균의 절반을 벌고 있다"가 되고 곧바로 **그들이 얼마나 버틸 수 있는가**라는 질문으로 이어진다. 해시리본(G-7)이 그 질문의 답이다.
- 원 아이디어는 **채굴 수익의 평균 회귀**다. 발행 스케줄이 결정론적이라는 비트코인 고유 성질이 없으면 성립하지 않는다 — 발행량이 수요에 반응하는 자산에는 이식할 수 없다.
- **크립토 24시간 시장에서 달라지는 점** — 365일 창은 달력 365일이고 무휴장이라 주식식 거래일 환산(부록 1-7)이 필요 없다. 대신 **반감이라는 계단**이 4년마다 창을 오염시킨다. 주식의 어떤 지표에도 이런 구조적 계단은 없으며, 이 문서에서 반감 보정이 필요한 유일한 지표군(G-7·G-8)이 여기다.

# 부록 2. 지표 값이 소스마다 다른 이유 — 체크리스트

같은 코인, 같은 기간, 같은 지표인데 값이 다를 때 확인할 순서:

1. **평활 방식** — RSI/ATR/ADX가 SMMA인가 EMA인가 SMA인가 (A-3 참조). 가장 잦은 원인
2. **시드값** — EMA 초기값을 SMA로 잡았나 첫 종가로 잡았나
3. **일봉 경계** — UTC 0시인가 거래소 로컬 시각인가
4. **표준편차 분모** — n인가 n−1인가 (볼린저)
5. **거래소** — 가격·거래량 소스가 어디인가
6. **펀딩 주기** — 8시간인가 1시간인가 (F-1)
7. **OI 단위** — 명목가치인가 코인 수량인가 (F-2)
8. **연율화 계수** — HV·베이시스에 √365인가 √252인가, 만기 일수를 맞게 넣었나 (C-5·F-3)
9. **잠금 로직의 시작점** — 슈퍼트렌드·SAR은 이전 상태를 기억하므로 계산 시작 봉이 다르면 값이 갈린다 (A-8·A-9)
10. **스윙 확인 봉 수 k** — 시장구조 라벨(HH/HL/LH/LL)은 k에 따라 통째로 달라진다 (E-5)
11. **온체인 벤더** — Glassnode / CryptoQuant / Nansen의 주소 라벨링이 다르다. 거래소 준비금은 특히 편차가 크다 (G-4)
12. **스테이블 트래커** — 체인 커버리지·브리지 처리 차이로 레벨이 $5~15B 다르다. **레벨 말고 변화율로** (G-5)
13. **해시레이트 역산 창** — 난이도에서 해시레이트를 되돌릴 때 1일·3일·7일 중 무엇을 썼는지에 따라 원계열이 크게 갈린다. **해시리본은 평활 전 입력이 이미 추정치**라는 점을 잊지 말 것 (G-7)
14. **Puell의 분모 창과 반감 보정** — 365일 고정인지, 반감 구간을 보정했는지, 수수료 수익을 포함했는지. 셋 다 벤더마다 다르며 반감 전후 1년은 차이가 가장 크다 (G-8)
15. **MVRV 파생 지표의 상속** — NUPL·MVRV-Z는 MVRV에서 유도되므로 **MVRV 벤더 차이를 그대로 물려받는다.** 서로 다른 벤더의 MVRV와 NUPL을 나란히 놓으면 함수 관계가 깨져 보인다 (G-6)

**원칙: 알림·자동화에 쓰는 지표는 반드시 계산 주체를 우리 쪽으로 가져온다.** 차트툴 표시값에 알림을 걸면 위 항목 중 어디서 어긋났는지 추적이 불가능하다.

# 부록 3. 조합 규칙 — 지표를 겹칠 때

```
1단계  레짐 판정      ADX + 촙피니스 (+ 볼린저 밴드폭)
       └ 추세장(ADX>25 & CHOP<38.2) → 추세추종 지표 ON, 역추세 지표 OFF
       └ 레인지(ADX<20 & CHOP>61.8) → 반대로
       └ 둘이 어긋나면 태동/소진 — C-7의 2×2 표 참조
       └ 자동화됨: automation/btc-desk-build.py §5.5

2단계  방향            추세: 이동평균 배열 + MACD
                      레인지: RSI 대역 + 스토캐스틱

3단계  독립 확인       거래량(D) 또는 파생 포지셔닝(F)
       └ 같은 축의 지표를 더 얹는 것은 확인이 아니다

4단계  레벨 배치       피봇 + 피보나치 + 프로파일의 컨플루언스
                      └ 진입가·목표가·손절선을 여기서 정한다

5단계  사이징          ATR
       └ 수량 = 허용손실액 / (2~3 × ATR)
```

### 축별로 하나씩만 — 실전 최소 세트

| 축 | 고르는 것 | 대안 | 같이 쓰면 중복 |
|---|---|---|---|
| 추세 | 이동평균 1개 (SMMA 또는 EMA) | 이치모쿠 단독(완결형) | SMA·EMA·SMMA·WMA·HMA·DEMA·TEMA·슈퍼트렌드 |
| 레짐 | ADX | 촙피니스 | 둘 다 쓰면 교차검증은 되나 근거는 1개 — 다만 **어긋남 자체는 정보**(C-7) |
| 모멘텀 | RSI | MACD | 스토캐스틱·%R·CCI·ROC·RVI·AO·TRIX |
| 변동성 | ATR (사이징) + 볼린저폭 (스퀴즈) | 켈트너·HV·표준편차 | 도너찬폭 |
| 거래량 | **CVD** (구할 수 있으면) | MFI(유계·알림용) | OBV·A/D·CMF |
| 파생 | 펀딩 + OI (2개는 필수) | 베이시스로 확인 | 테이커비 ≈ CVD |
| 옵션 | DVOL + 25Δ 스큐 | — | — |
| 온체인 (수요측) | MVRV | 실현가격 또는 **NUPL** (셋 다 같은 지표) | **NUPL·실현가격 — MVRV와 함께 세면 안 됨.** SOPR은 별개 정보 |
| **온체인 (공급측·BTC 전용)** | **해시리본** (생존) | **Puell Multiple** (수익) | 둘은 다른 면이라 중복 아님. 단 **Puell ≈ 장기 ROC**이므로 모멘텀 축과는 중복 |
| 레벨 | 컨플루언스만 — 피봇·피보나치·프로파일이 겹치는 곳 | — | 단일 레벨은 근거 아님 |

**총 8~10개면 충분하다.** 이 문서의 55종은 고르기 위한 목록이지 전부 띄우라는 목록이 아니다.
