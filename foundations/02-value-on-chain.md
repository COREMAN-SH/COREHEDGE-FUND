# 02. 블록체인에 가치가 담기는 원리

> [[01-blockchain-basics|01번 문서]]에서 "블록체인이 무엇인가"를 봤다. 이 문서는 투자자에게 훨씬 중요한 질문을 다룬다.
> **"왜 그 데이터 조각에 값이 붙는가, 그리고 언제 안 붙는가."**

---

## 1. 질문을 정확히 세우기

비트코인 1개는 결국 **블록체인 장부에 적힌 숫자**다. 만질 수 없고, 배당도 없고, 발행 기관도 없다. 그런데 값이 붙는다.

여기서 흔히 나오는 답이 **"희소하니까"** 인데, 이건 틀린 답이다.

> 내 이름으로 코인을 만들어 100개만 발행하면 그것도 희소하다. 그런데 값은 0이다.

**희소성은 가치의 필요조건이지 충분조건이 아니다.** 정확한 문장은 이것이다.

> **가치 = 희소성 × 수요**
> 그리고 투자 분석의 90%는 **"수요"** 쪽을 검증하는 일이다.

그래서 진짜 질문은 이렇게 바뀐다.

> **"이 토큰을 누가, 왜, 계속 사야만 하는가?"**

이 질문에 구체적으로 답할 수 없으면 그 자산에 대한 펀더멘탈 논거는 없는 것이다.

---

## 2. 가치의 두 원천

암호자산의 가치 원천은 크게 둘로 갈린다. 성격이 완전히 달라서 **섞어서 평가하면 반드시 틀린다.**

### 2-1. 화폐적 프리미엄 (Monetary Premium)

"다른 사람들도 이것을 가치 저장 수단으로 인정한다"는 **공통 믿음** 자체에서 나오는 가치.

금이 대표적이다. 금의 산업적 사용가치는 전체 가격의 극히 일부다. 나머지는 "수천 년간 인류가 가치 저장 수단으로 합의해왔다"는 사실에서 온다.

이런 가치는 **셸링 포인트(Schelling Point)** 로 설명된다 — 서로 상의하지 않고도 자연스럽게 모이게 되는 지점. "가치 저장용 암호자산 하나만 고르라면?"에 대다수가 같은 답을 하면, 그 답이 셸링 포인트가 되고 자기실현적으로 강화된다.

| 특징 | 내용 |
|---|---|
| 측정 | 현금흐름 모델로 평가 **불가능**. DCF를 쓸 수 없다 |
| 강점 | 한번 자리 잡으면 대체가 극히 어렵다 (네트워크 효과 + 관성) |
| 약점 | 믿음이 근거이므로, 믿음이 흔들리면 하방이 열려 있다 |
| 해당 자산 | BTC (그리고 부분적으로 ETH) |

> **BTC를 P/E나 매출로 평가하려는 시도는 범주 오류다.** BTC의 논거는 "채택률과 신뢰가 계속 확대되는가"이지 "얼마를 버는가"가 아니다.

### 2-2. 현금흐름 / 사용 가치

프로토콜이 실제로 수수료를 벌고, 그 수익이 어떤 경로로든 토큰 보유자에게 흘러가는 구조.

이건 주식과 비슷하게 평가할 수 있다.

| 특징 | 내용 |
|---|---|
| 측정 | P/F(가격/수수료), P/S 유사 지표로 비교 가능 |
| 강점 | 검증 가능하다. 온체인 데이터로 수수료가 실측된다 |
| 약점 | **수익이 토큰으로 흘러가는 경로가 없으면 아무 의미가 없다** |
| 해당 자산 | UNI, BNB, NEAR 등 |

**결정적 포인트가 위 표의 "약점"이다.** 이게 다음 장의 주제다.

## 3. 가치 포착 (Value Capture) — 가장 중요한 개념

암호자산 분석에서 초보와 경험자를 가르는 지점이 여기다.

> **네트워크가 성장하는 것과, 그 성장이 토큰 가격에 반영되는 것은 완전히 별개의 문제다.**

### 3-1. 실패 사례로 이해하기

볼트의 실제 노트에 있는 사례들이다.

**ATOM (Cosmos)** — [[../coins/minor/ATOM-cosmos|노트]]

Cosmos는 IBC라는 체인 간 통신 표준을 만들어 성공시켰다. dYdX, Celestia, Injective, Osmosis 등 대형 체인들이 이 기술을 채택했다. 기술적으로는 대성공이다.

그런데 **이 체인들은 각자 자기 토큰을 쓴다.** ATOM을 쓸 이유가 없다. 생태계가 10배 커져도 ATOM 수요는 늘지 않는다.

> 기술 채택 성공 ≠ 토큰 가치 상승. 두 문장 사이에 **"그래서 왜 이 토큰을 사야 하는가"** 가 반드시 들어가야 한다.

**LINK (Chainlink)** — [[../coins/minor/LINK-chainlink|노트]]

오라클 시장을 사실상 독점했다. 그런데 오라클 이용료를 **LINK가 아닌 스테이블코인으로도 결제할 수 있다.** 사용량이 늘어도 LINK 매수 압력으로 직결되지 않는다.

**ONDO** — [[../coins/minor/ONDO-ondofinance|노트]]

토큰화 주식 월간 이전액 점유율 1위(33%)를 달성했다. 그런데 실제 돈을 버는 상품(OUSG, USDY)의 수수료가 ONDO 보유자에게 귀속되는 구조는 제한적이다. **사업 성과와 토큰 가치가 분리되어 있다.**

### 3-2. 성공 사례

**UNI (Uniswap)** — [[../coins/minor/UNI-uniswap|노트]]

원래 UNI도 "거버넌스 투표권"뿐인 전형적 가치 포착 실패 토큰이었다. 2025년 말 **UNIfication** 업그레이드로 구조가 바뀌었다.

```
사용자가 스왑 → 수수료 발생
   → LP 몫 + 프로토콜 몫으로 분할 (v2: 0.3% 중 0.05%가 프로토콜)
   → 프로토콜 몫이 TokenJar에 집계
   → Firepit(소각 주소)으로 전송 → UNI 영구 소각
```

이제 **거래량 증가 → 수수료 증가 → 소각 증가 → 공급 감소**라는 경로가 생겼다. 실제로 일일 프로토콜 수익이 약 $11.4만 → 약 $32.5만으로 늘었다.

**BNB** — [[../coins/large-alt/BNB-bnbchain|노트]]

분기마다 자동 소각(Auto-Burn)으로 공급을 2억 → 1억 개까지 줄인다. 2026년 7월 36번째 소각에서 약 161.6만 BNB(≈$9.32억)를 태웠다. **거래소 사업 성과가 직접 공급 감소로 전환**된다.

**NEAR** — [[../coins/minor/NEAR-protocol|노트]]

가스비의 70%를 영구 소각하고, **NEAR Intents 수수료는 100% NEAR 직접 매수로 전환**한다. 일일 Intents 거래량이 약 $1.77억을 넘으면 발행량보다 소각·매수량이 커져 순 디플레이션에 진입한다. **명확한 수치 임계점**이 있어 추적 가능하다.

## 4. 가치 포착 메커니즘 4종

토큰에 가치를 흘려보내는 방법은 실무적으로 네 가지뿐이다. 어떤 코인을 보든 **"이 넷 중 무엇을 쓰는가"** 를 먼저 확인하면 된다.

### 4-1. 소각 (Burn)

수익으로 토큰을 사서 없애거나, 수수료의 일부를 직접 소각한다. 주식의 자사주 매입·소각과 같은 논리다.

- **작동:** 공급 감소 → 남은 토큰의 지분율 상승
- **사례:** BNB(분기 오토번), ETH(EIP-1559), UNI(Firepit)
- **⚠️ 함정:** **소각량만 보면 안 되고 반드시 신규 발행량과 상계해야 한다.** UNI는 소각을 하지만 연간 약 2,000만 UNI의 생태계 예산이 별도로 발행된다. ETH는 소각을 하지만 스테이킹 보상 발행이 더 커서 2026년 기준 **순 인플레이션**(연 +0.23% 내외)이다
  ```
  순공급변화 = 신규발행 − 소각    ← 이 값이 음수여야 진짜 디플레이션
  ```

### 4-2. 스테이킹 락업

토큰을 담보로 맡겨야 네트워크에 참여할 수 있게 한다.

- **작동:** 유통 물량 감소 + 보유 유인 제공
- **사례:** 모든 PoS 체인 (ETH 약 32%, SOL, ADA 등)
- **⚠️ 함정:** 스테이킹 보상은 **새로 발행한 토큰으로 지급**되는 경우가 많다. 이 경우 "수익률 5%"는 실질 수익이 아니라 **희석되지 않기 위한 방어**에 가깝다
  ```
  실질 스테이킹 수익률 = 명목 수익률 − 인플레이션율
  ```
  ADA를 예로 들면 명목 5~6%, 인플레이션 약 2% → 실질 약 3~4%. 스테이킹을 안 하면 매년 2%씩 희석된다

### 4-3. 수수료 배분 (Fee Sharing)

프로토콜 수익을 토큰 보유자·스테이커에게 직접 분배한다.

- **작동:** 배당과 유사 → DCF 평가가 가능해짐
- **⚠️ 함정:** **규제 위험이 가장 큰 구조다.** "타인의 노력으로 수익을 기대"하는 형태라 증권으로 분류될 소지가 커진다. 이 때문에 많은 프로토콜이 배분 대신 **소각**을 택한다 (소각은 배당이 아니므로 규제 노출이 낮다)

### 4-4. 담보·사용 필수성

그 토큰이 없으면 네트워크를 쓸 수 없게 만든다.

- **작동:** 사용량 증가 → 구조적 매수 수요
- **사례:** ETH 가스비, BNB의 BSC 가스비
- **⚠️ 함정:** 대체 결제 수단이 열려 있으면 무력화된다(LINK 사례). 또 수수료가 너무 싸면 필수성이 있어도 금액이 미미하다

## 5. 평가 지표 — 무엇을 계산할 것인가

### 5-1. P/F (Price to Fees)

```
P/F = FDV(완전희석시총) / 연환산 프로토콜 수수료
```

주식의 P/E에 대응한다. 절대값보다 **동종 프로토콜 간 비교**와 **추세**로 읽는다.

> UNI 예: 연환산 프로토콜 수수료 약 5억 달러 규모, 시총 대비 배수 약 4배 수준

### 5-2. 실질 매출 (Real Revenue)

```
실질 매출 = 프로토콜 수수료 − 토큰 인센티브 배출
```

이 값이 **음수면 사용량을 보조금으로 산 것**이다. 지속 불가능하다. 인센티브가 끊기면 사용자도 같이 사라진다.

### 5-3. MC/FDV — 언락 부담

```
MC/FDV = 시가총액 / 완전희석시총
```

이 비율이 **낮을수록 잠긴 물량이 많다** = 앞으로 나올 매도 압력이 크다.

볼트 노트 기준 실제 값:

| 코인 | MC/FDV | 잠긴 비중 | 해석 |
|---|---|---|---|
| WLD | 0.36 | 약 64% | 언락 부담 가장 큼 |
| SUI | 0.41 | 약 59% | 매월 약 2,200만 SUI 언락 |
| ONDO | 0.49 | 약 47% | 2029년 1월까지 선형 베스팅 |
| UNI | 0.70 | 약 30% | 상대적으로 소화됨 |

> **언락 평가 요령:** 절대 물량이 아니라 **일평균 거래대금 대비 비율**로 본다. 일평균 거래대금의 5% 이상이면 유의미한 압력이다. 다만 "언락 = 즉시 매도"는 아니다. 팀·투자자 물량은 OTC로 소화되기도 한다

### 5-4. MC/TVL (DeFi 전용)

```
MC/TVL = 시가총액 / Total Value Locked
```

⚠️ **TVL은 가격에 종속된다.** 예치된 자산의 가격이 오르면 예치 수량이 그대로여도 TVL이 오른다. 반드시 **네이티브 수량 기준 TVL**을 함께 본다.

## 6. 결정적 함정: 토큰은 지분이 아니다

가장 많이 착각하는 부분이다.

| | 주식 | 토큰 |
|---|---|---|
| 법적 지위 | 회사에 대한 소유권 | 대부분 **아무 청구권 없음** |
| 배당 | 이사회 결의로 지급 | 대부분 없음. 있으면 규제 위험 |
| 잔여재산 분배 | 청산 시 권리 있음 | 없음 |
| 발행 통제 | 주주총회 승인 필요 | 재단·거버넌스가 결정, 희석 가능 |
| 정보 공시 | 법적 의무 | **의무 없음** |

> 프로젝트가 아무리 성공해도, **가치 포착 경로가 코드에 명시되어 있지 않으면 토큰 보유자는 법적으로 아무것도 요구할 수 없다.** "회사가 잘되면 토큰도 오르겠지"는 근거 없는 추론이다.

이것이 3장의 ATOM·LINK·ONDO 사례가 반복되는 구조적 이유다.

## 7. 실전 체크리스트

새 코인을 볼 때 **이 순서대로** 확인한다.

```
[1] 수요의 원천은 무엇인가?
    □ 화폐적 프리미엄형인가, 현금흐름형인가
    □ 둘을 섞어 평가하고 있지 않은가

[2] 가치 포착 경로가 코드에 있는가?
    □ 소각 / 스테이킹 락업 / 수수료 배분 / 사용 필수성 중 무엇인가
    □ "생태계가 크면 토큰도 오른다"는 서술로 대체되어 있지 않은가

[3] 순공급 변화가 음수인가?
    □ 소각량만 보지 않았는가
    □ 신규 발행(스테이킹 보상 + 생태계 예산)을 상계했는가

[4] 실질 매출이 양수인가?
    □ 수수료 − 토큰 인센티브 배출 > 0 인가
    □ 사용량이 보조금으로 산 것은 아닌가

[5] 언락 부담은?
    □ MC/FDV 비율
    □ 향후 12개월 언락 물량 ÷ 일평균 거래대금

[6] 무효화 조건은 무엇인가?
    □ 어떤 수치가 나오면 이 논거를 폐기하는가
```

**[6]번을 못 적으면 그건 분석이 아니라 응원이다.**

## 8. 요약

1. 희소성은 가치를 만들지 않는다. **희소성 × 수요**다
2. 가치 원천은 **화폐적 프리미엄**과 **현금흐름** 둘로 갈리며, 평가 방법이 완전히 다르다
3. **가치 포착**이 핵심이다. 네트워크 성장과 토큰 가격 상승은 별개이며, 그 사이를 이어주는 코드 수준의 메커니즘이 있어야 한다
4. 메커니즘은 네 가지뿐이다: **소각 / 스테이킹 락업 / 수수료 배분 / 사용 필수성**
5. 소각을 볼 때는 **반드시 신규 발행과 상계**한다. 순공급 변화가 음수여야 진짜다
6. **토큰은 지분이 아니다.** 명시된 경로가 없으면 법적 청구권도 없다
