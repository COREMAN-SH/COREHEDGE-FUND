# 온체인 지표 사전

> 목적: 지표를 **정의 → 계산식 → 판정 규칙 → 함정** 순으로 고정해, 사후 서술이 아니라 사전 임계값으로 판정하기 위함.
> 주의: 아래 임계값은 2011–2022 사이클에서 도출된 역사적 범위다. ETF·기관 자금 유입 이후 분포가 이동(drift)했으므로 **절대값보다 자기 이력 대비 백분위**로 읽는 것이 안전하다.

---

## 카테고리 A. 가치평가 (Valuation)

### A-1. 실현시총 (Realized Cap)

**정의** — 모든 UTXO(또는 코인)를 *마지막으로 온체인에서 이동한 시점의 가격*으로 평가한 총합. 시장 참여자들이 실제로 지불한 총 원가(cost basis)에 대한 근사.

**계산식**
```
Realized Cap = Σ (코인 수량ᵢ × 해당 코인이 마지막으로 이동한 시점의 가격ᵢ)
Realized Price = Realized Cap / 유통 공급량
```

**판정 규칙**
- 가격 < 실현가격 → 시장 전체가 평균적으로 손실. 역사적으로 사이클 바닥 국면(약세장 후반)에서만 발생
- 실현시총의 **기울기**가 더 중요: 상승 = 신규 자본 유입, 횡보 = 자본 정체, 하락 = 자본 이탈(항복)

**함정**
- 거래소 내부 이동, 커스터디 재편, 자체 지갑 간 전송이 모두 "가격 갱신"으로 잡혀 원가가 최신화됨 → 실제 매수 원가가 아님
- 분실 코인(사토시 물량 등)은 초저가에 고정되어 실현시총을 구조적으로 낮춤
- 이더리움처럼 계정 기반 체인은 UTXO가 없어 근사 방식이 체인마다 다름 → 제공업체 간 값이 다르다

---

### A-2. MVRV / MVRV Z-Score

**정의** — 시장가치 대비 실현가치 비율. 미실현 손익의 규모를 정규화한 지표.

**계산식**
```
MVRV = Market Cap / Realized Cap
MVRV Z-Score = (Market Cap − Realized Cap) / σ(Market Cap)
```
σ는 시장시총의 전체 이력 표준편차.

**판정 규칙 (BTC 기준, 역사적)**
| 구간 | MVRV | Z-Score | 해석 |
|---|---|---|---|
| 과열 | > 3.7 | > 7 | 사이클 고점권 |
| 중립 | 1.0 ~ 2.5 | 1 ~ 4 | 추세 진행 |
| 저평가 | < 1.0 | < 0.1 | 사이클 바닥권 |

**함정**
- Z-Score는 전체 이력 σ를 쓰므로 **시간이 갈수록 구조적으로 낮아진다.** 과거 고점 수치를 그대로 기대하면 영원히 신호가 안 뜬다
- 알트코인 MVRV는 유통량 추정 오차가 커서 신뢰도가 급락한다
- 단독 사용 금지 — 가격 추세 확인 지표(예: 200일선)와 결합해야 한다

---

### A-3. NUPL (Net Unrealized Profit/Loss)

**정의** — 미실현 손익을 시총으로 나눈 값. MVRV와 수학적으로 등가지만 0을 중심으로 읽는다.

**계산식**
```
NUPL = (Market Cap − Realized Cap) / Market Cap = 1 − 1/MVRV
```

**판정 규칙**
| NUPL | 국면 명칭 |
|---|---|
| > 0.75 | Euphoria (분배 구간) |
| 0.5 ~ 0.75 | Belief |
| 0.25 ~ 0.5 | Optimism |
| 0 ~ 0.25 | Hope / Fear |
| < 0 | Capitulation (축적 구간) |

**함정**
- MVRV와 동일 정보 → 두 개를 함께 근거로 나열하면 **중복 계산(double counting)**
- 구간 명칭은 사후적 라벨일 뿐 인과가 아니다

---

### A-4. NVT / NVT Golden Cross

**정의** — 온체인 결제 처리량 대비 네트워크 밸류에이션. 주식의 P/E에 대응하는 개념.

**계산식**
```
NVT = Market Cap / 일간 온체인 전송액(USD)
NVT Signal = Market Cap / 90일 이동평균(일간 전송액)
NVT Golden Cross = (10일 MA − 30일 MA) / 30일 MA, 표준화
```

**판정 규칙**
- NVT Signal이 자기 2년 범위 상단 → 가격이 사용량 대비 선행 과열
- NVT Golden Cross > +2.2 → 단기 과열 / < −1.6 → 단기 과매도

**함정**
- **가장 오염이 심한 지표.** 거래소 내부 정산, 믹서, 배치 전송, 체인지 아웃풋이 전송액을 부풀린다 → 반드시 *adjusted transfer volume*을 쓸 것
- L2·사이드체인으로 활동이 이전되면 L1 전송액이 줄어 NVT가 구조적으로 상승 → 이더리움에서 특히 왜곡
- 결제 수단이 아니라 담보/저장 수단으로 쓰이는 자산에는 개념적으로 부적합

---

### A-5. Puell Multiple

**정의** — 채굴자 일일 수익이 연평균 대비 얼마나 되는지. 공급 측 압력 지표.

**계산식**
```
Puell Multiple = 일간 채굴 발행량(USD) / 365일 이동평균(일간 채굴 발행량 USD)
```

**판정 규칙**
- \> 4.0 → 채굴자 수익 과잉, 분배 압력 (사이클 고점권)
- < 0.5 → 채굴자 압박, 항복 (사이클 바닥권)

**함정**
- 반감기 직후 분자가 즉시 반토막 나지만 분모(365일 MA)는 천천히 따라옴 → **반감기 후 약 1년간 인위적으로 낮게** 나온다. 이 구간의 저값은 매수 신호가 아니다
- PoS 체인에는 적용 불가

---

### A-6. Reserve Risk

**정의** — 장기 보유자의 확신(HODL 강도) 대비 현재 가격. "확신이 높은데 가격이 싸면" 위험 대비 보상이 좋다는 논리.

**계산식**
```
HODL Bank = Σ (기회비용 누적)  ※ 제공업체별 구현 상이
Reserve Risk = Price / HODL Bank
```

**판정 규칙**
- < 0.002 → 축적 매력 구간
- \> 0.02 → 고점 경계 구간

**함정**
- 블랙박스에 가깝다. 제공업체마다 HODL Bank 정의가 달라 값이 호환되지 않는다
- 임계값이 사이클마다 크게 이동 — 백분위로만 읽을 것

## 카테고리 B. 보유자 행동 (Holder Behavior)

### B-1. SOPR / aSOPR / STH-SOPR / LTH-SOPR

**정의** — 이동된 코인이 원가 대비 이익인지 손실인지의 비율. "오늘 팔린 코인들의 평균 수익률".

**계산식**
```
SOPR = Σ(매도 시점 가치) / Σ(취득 시점 가치)
aSOPR = SOPR에서 1시간 미만 보유 코인 제외 (내부 이동 노이즈 제거)
STH-SOPR = 보유기간 155일 미만 코인만
LTH-SOPR = 보유기간 155일 이상 코인만
```

**판정 규칙**
- SOPR = 1이 **심리적 손익분기선**. 강세장에서 1은 지지선(손실 확정 회피), 약세장에서 1은 저항선(본전 탈출)
- aSOPR이 1 아래로 이탈 후 재탈환 → 강세 재개 신호
- LTH-SOPR > 3 → 장기 보유자 대량 차익실현 = 분배 국면

**함정**
- 원시 SOPR은 거래소 내부 이동에 심하게 오염 → **반드시 aSOPR을 쓸 것**
- 155일 경계는 통계적 편의일 뿐 경제적 근거가 아니다
- 단일 일자 값은 무의미. 최소 7일 MA로 볼 것

---

### B-2. Coin Days Destroyed (CDD) / Dormancy / Liveliness

**정의** — 오래 잠자던 코인이 움직였는지를 가중 측정. "누가" 움직였는지에 대한 최선의 근사.

**계산식**
```
CDD = Σ (이동 코인 수량 × 마지막 이동 이후 경과일)
Dormancy = CDD / 일간 전송 코인 수량        (코인 1개당 평균 잠자던 일수)
Liveliness = 누적 CDD / 누적 생성 코인일수   (0~1)
```

**판정 규칙**
- CDD 급등 = 고연령 물량 이동 → 대개 분배. 단, 커스터디 이전과 구분 필요
- Liveliness 상승 = 장기 보유자 이탈 우세 / 하락 = 축적(HODLing) 우세
- Liveliness는 **추세 방향**만 읽고 절대 레벨은 무시한다

**함정**
- 커스터디/ETF 이관, 거래소 콜드월렛 재편이 CDD를 폭증시킨다 → 반드시 해당 이벤트 확인 후 해석
- 분석 대상 코인 수가 적은 알트에서는 소수 지갑이 지표를 좌우

---

### B-3. LTH / STH 공급 분포, HODL Waves

**정의** — 공급량을 보유 기간별로 분해한 것.

**계산식**
```
LTH Supply = 보유기간 ≥ 155일 코인 합계
Realized Cap HODL Waves = 각 연령 밴드의 실현시총 비중
```

**판정 규칙**
- LTH 공급이 **가격 상승 중 감소** → 분배 진행
- LTH 공급이 **가격 하락 중 증가** → 축적 진행 (역사적으로 바닥권 특징)
- 1년 이상 밴드 비중이 사이클 저점 대비 크게 축소 → 후기 사이클

**함정**
- LTH ↔ STH 전환은 **시간 경과만으로도** 자동 발생한다 (매매가 없어도 155일이 지나면 LTH로 편입) → 급등락 없는 완만한 변화는 의미 없음
- ETF·거래소 물량이 어느 쪽으로 분류되는지가 제공업체마다 다르다

---

## 카테고리 C. 네트워크 활동 (Activity)

### C-1. 활성 주소 / 신규 주소 / 트랜잭션 수

**정의** — 네트워크 사용량의 원시 카운트.

**판정 규칙**
- 가격 상승 + 활성 주소 상승 → 확인(confirmation)
- 가격 상승 + 활성 주소 정체 → **다이버전스**, 투기 주도 상승 의심
- 신규 주소 7일 MA가 30일 MA를 상향 돌파 → 유입 가속

**함정**
- 주소 ≠ 사람. 봇, 더스팅 공격, 배치 처리로 쉽게 조작된다
- 무료/저가 수수료 체인(SOL, TRON 등)은 수치 자체가 다른 체인과 비교 불가
- 거래소 내부 처리는 온체인에 안 잡힘 → 실사용 과소평가

---

### C-2. 수수료 수익 / 실질 매출

**정의** — 네트워크가 실제로 벌어들인 금액. 알트코인 펀더멘탈에서 가장 방어 가능한 지표.

**계산식**
```
Fee Revenue = 사용자가 지불한 총 수수료
Real Revenue = 수수료 − 토큰 인센티브(배출)
P/F = FDV / 연환산 수수료
```

**판정 규칙**
- Real Revenue < 0 (배출 > 수수료) → 사용량이 보조금으로 매수된 상태. 지속 불가
- P/F를 동종 체인 간 비교. 절대값이 아니라 **순위와 추세**

**함정**
- 워시 트레이딩, 파밍 유인 활동이 수수료를 부풀린다
- MEV 수익을 포함/제외하는지 제공업체마다 다름

---

### C-3. 해시레이트 / 난이도 / Hash Ribbon (PoW 전용)

**계산식**
```
Hash Ribbon: 30일 MA(해시레이트) vs 60일 MA(해시레이트)
```

**판정 규칙**
- 30일 MA < 60일 MA → 채굴자 항복 진행 중
- 30일 MA가 60일 MA를 재상향 돌파 → 항복 종료 = 역사적 매수 신호

**함정**
- 해시레이트는 후행 지표이며, 지분 변화(중국 금지령 등 정책 이벤트)에 의한 이동을 시장 신호로 오독하기 쉽다
- 해시레이트 단기 추정치는 블록 발견 분산 때문에 노이즈가 크다 — 최소 7일 평활 필수

---

## 카테고리 D. 공급·유동성 (Supply & Liquidity)

### D-1. 거래소 잔고 / 순유출입

**정의** — 거래소 지갑이 보유한 코인 잔고와 그 변화.

**판정 규칙**
- 지속적 순유출 → 자가 수탁 이동, 매도 가능 물량 축소 (강세)
- 급격한 순유입 → 매도 준비 (약세)

**함정**
- **주소 라벨링에 전적으로 의존한다.** 거래소가 지갑 구조를 바꾸면 하루아침에 수십만 코인의 "유출입"이 허위로 생성된다
- ETF 커스터디 물량이 "거래소"로 분류되는지 여부가 제공업체마다 다르다 → 2024년 이후 이 지표의 비교 가능성이 크게 손상됨
- 파생 담보 이동과 현물 매도 의도를 구분할 수 없다

---

### D-2. 스테이블코인 공급 / SSR

**정의** — 시장 내 대기 구매력.

**계산식**
```
SSR = BTC Market Cap / 스테이블코인 총 시총
SSR Oscillator = SSR을 자기 이동평균 대비 표준화
```

**판정 규칙**
- SSR 하락(스테이블 공급 증가 우세) → 잠재 매수력 축적
- 스테이블코인 총 시총의 **순발행**이 플러스 전환 → 신규 자금 유입 확인

**함정**
- 스테이블코인이 DeFi 담보·차익거래·비암호화폐 결제로도 쓰인다 → "대기 매수력"이라는 해석은 상한 추정
- 체인 간 브리지 물량이 이중 계상될 수 있다

---

### D-3. 스테이킹 비율 / 언락 스케줄 (PoS·알트)

**판정 규칙**
- 스테이킹 비율 급락 → 언스테이킹 대기열 증가 → 향후 매도 압력 선행
- 언락 규모를 **일평균 거래대금 대비 %**로 환산해서 평가. 5% 이상이면 유의미한 압력

**함정**
- 언스테이킹 대기기간(쿨다운)이 체인마다 달라 압력이 실현되는 시점이 다르다
- "언락 = 매도"가 아니다. 팀·투자자 물량은 OTC로 소화되기도 한다

---

## 카테고리 E. 앱·체인 레벨 (알트 전용)

### E-1. TVL / MC-TVL

**계산식**
```
MC/TVL = 시가총액 / Total Value Locked
```

**판정 규칙**
- MC/TVL이 동종 대비 높음 → 잠긴 자본 대비 고평가
- TVL 추세와 가격 추세의 다이버전스를 본다

**함정**
- **TVL은 가격에 종속된다.** 예치 자산 가격이 오르면 예치 수량이 그대로여도 TVL이 오른다 → 반드시 **네이티브 수량 기준 TVL**을 병행 확인
- 리스테이킹·랩핑으로 같은 자본이 여러 번 계상된다
- 인센티브 파밍 자본은 보조금이 끊기면 즉시 이탈 (sticky하지 않음)

### E-2. 브리지 순유입 / 체인별 스테이블코인 잔고

**판정 규칙**
- 체인 스테이블코인 잔고 증가 = 그 체인에 실제 자본이 상주 중. TVL보다 조작 저항성이 높다

## 이론 심화

### 1. 온체인 지표의 3계층 구조

| 계층 | 성격 | 예 | 신뢰도 |
|---|---|---|---|
| **원시 계층** | 체인에 기록된 사실 | 블록, 트랜잭션, 잔고 | 높음 (검증 가능) |
| **해석 계층** | 라벨링·휴리스틱 적용 | 거래소 잔고, LTH/STH | 중간 (제공업체 의존) |
| **파생 계층** | 원시+해석을 조합한 비율 | MVRV, SOPR, Reserve Risk | 낮음 (가정 누적) |

**규칙: 판정의 무게는 계층이 낮을수록 크게 준다.** 파생 지표는 원시 계층으로 교차검증되지 않으면 근거로 쓰지 않는다.

### 2. 왜 임계값은 사이클마다 이동하는가 (Regime Drift)

온체인 임계값은 **시장 구조에 대한 함수**이지 자연 상수가 아니다. 다음이 바뀌면 임계값도 바뀐다.

- **보유 주체 구성**: 개인 → ETF·기업 재무. 기관 물량은 온체인 이동 빈도가 낮아 CDD·SOPR을 구조적으로 눌린다
- **파생상품 비중**: 현물 이동 없이 익스포저를 조정할 수 있게 되면 온체인 활동이 실제 포지션 변화를 덜 반영한다
- **L2 이전**: L1 활동 지표가 사용량 감소를 과장한다
- **σ 팽창**: Z-Score류는 이력이 길어질수록 분모가 커져 신호 발생 빈도가 감소

→ 실무 대응: **모든 임계값을 rolling 4년 백분위로 재정의**하고, 절대값은 참고로만 쓴다.

### 3. 중복 계산 회피 (Independence Check)

아래는 수학적으로 같은 정보다. 하나만 쓴다.
- MVRV ↔ NUPL (`NUPL = 1 − 1/MVRV`)
- Realized Price ↔ Realized Cap (공급량 나눈 것)
- Dormancy ↔ CDD (전송량으로 정규화한 것)
- Liveliness ↔ 누적 CDD

독립적인 축은 대략 4개다: **가치평가 / 보유자 행동 / 네트워크 활동 / 유동성**. 각 축에서 1~2개만 골라 판정 프레임을 구성한다.

### 4. 온체인이 답할 수 없는 것

- **의도**: 코인이 움직였다는 사실은 알아도 왜 움직였는지는 모른다
- **오프체인 잔고**: 거래소 장부상 포지션, ETF 내부 순매수는 온체인에 없다
- **타이밍**: 온체인 지표는 대부분 국면(regime) 지표이지 진입 타이밍 지표가 아니다. 바닥권 신호가 뜬 뒤 수개월 더 하락할 수 있다
- **알트코인 일반**: 공급 집중도가 높아 소수 지갑이 모든 지표를 결정한다. BTC에서 검증된 프레임이 알트에 이전되지 않는다

### 5. 판정 프레임 표준 (사전 고정)

각 노트에서 아래 형식을 강제한다.

```
1. 관측: 지표값과 기준일만 나열 (해석 금지)
2. 임계값 대비 판정: 사전 정의된 구간에 매핑
3. 축 간 합의 여부: 4개 축 중 몇 개가 같은 방향인지
4. 무효화 조건: 어떤 값이 나오면 이 판정을 폐기하는가
5. 포지션 시사점: 한 문단
```
